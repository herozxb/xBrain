## [Maximum Subarray Sum]
```python
# PROBLEM: Find the contiguous subarray with the largest sum
# TIME: O(n) SPACE: O(1)
def max_subarray_sum(nums):
    """
    Kadane's algorithm for maximum subarray problem.
    Tracks running sum, resets when negative.
    """
    if not nums:
        return 0
    
    max_sum = current_sum = nums[0]
    
    for num in nums[1:]:
        # Either extend current subarray or start fresh
        current_sum = max(num, current_sum + num)
        # Update global maximum
        max_sum = max(max_sum, current_sum)
    
    return max_sum
```
**Why:** Classic DP pattern - local decisions lead to global optimum. Essential for understanding subarray problems.

## [Two Sum - Sorted Array]
```python
# PROBLEM: Find two numbers that sum to target in sorted array
# TIME: O(n) SPACE: O(1)
def two_sum_sorted(nums, target):
    """
    Two pointers approach from both ends.
    Move left pointer if sum too small, right if too large.
    """
    left, right = 0, len(nums) - 1
    
    while left < right:
        current_sum = nums[left] + nums[right]
        
        if current_sum == target:
            return [left, right]  # Found the pair
        elif current_sum < target:
            left += 1  # Need larger sum
        else:
            right -= 1  # Need smaller sum
    
    return [-1, -1]  # No solution exists
```
**Why:** Fundamental two-pointer technique. Exploits sorted property for linear time without extra space.

```python
# PROBLEM: Find length of longest substring with all unique characters
# TIME: O(n) SPACE: O(min(n, m)) where m is charset size
def length_of_longest_substring(s):
    """
    Sliding window with hash map tracking last index of each char.
    Shrink window from left when duplicate found.
    """
    char_index = {}  # Maps character to its last seen index
    left = 0
    max_length = 0
    
    for right, char in enumerate(s):
        # If char seen and is within current window
        if char in char_index and char_index[char] >= left:
            # Move left pointer past the duplicate
            left = char_index[char] + 1
        
        # Update last seen index
        char_index[char] = right
        
        # Update maximum length
        max_length = max(max_length, right - left + 1)
    
    return max_length
```
**Why:** Master sliding window pattern. Window dynamically adjusts based on validity condition.

## [Permutations]

```python
# PROBLEM: Generate all permutations of an array
# TIME: O(n! * n) SPACE: O(n) for recursion depth
def permutations(nums):
    """
    Backtracking with swapping. Fix one element at a time,
    recursively permute the rest, then backtrack.
    """
    result = []
    
    def backtrack(start):
        # Base case: all positions fixed
        if start == len(nums):
            result.append(nums[:])  # Copy current state
            return
        
        for i in range(start, len(nums)):
            # Swap current element to start position
            nums[start], nums[i] = nums[i], nums[start]
            
            # Recurse on remaining elements
            backtrack(start + 1)
            
            # Backtrack: undo the swap
            nums[start], nums[i] = nums[i], nums[start]
    
    backtrack(0)
    return result
```
**Why:** Classic backtracking with in-place swapping. Demonstrates state modification and restoration.

Topics: backtracking, recursion, permutations

## [Merge Intervals]

```python
# PROBLEM: Merge all overlapping intervals
# TIME: O(n log n) SPACE: O(n)
def merge_intervals(intervals):
    """
    Sort by start time, then merge overlapping ones.
    Compare current start with previous end.
    """
    if not intervals:
        return []
    
    # Sort intervals by start time
    intervals.sort(key=lambda x: x[0])
    
    merged = [intervals[0]]
    
    for current in intervals[1:]:
        prev = merged[-1]
        
        # If overlapping (current start <= prev end)
        if current[0] <= prev[1]:
            # Merge by extending end
            prev[1] = max(prev[1], current[1])
        else:
            # No overlap, add as new interval
            merged.append(current)
    
    return merged
```
**Why:** Interval problems are common. Sorting + linear scan is the go-to pattern.

## [Binary Search]
```python
# PROBLEM: Find target in sorted array, return index or -1
# TIME: O(log n) SPACE: O(1)
def binary_search(nums, target):
    """
    Classic binary search with left-closed, right-closed interval.
    Each iteration halves the search space.
    """
    left, right = 0, len(nums) - 1
    
    while left <= right:
        # Avoid overflow: left + (right - left) // 2
        mid = left + (right - left) // 2
        
        if nums[mid] == target:
            return mid  # Found target
        elif nums[mid] < target:
            left = mid + 1  # Search right half
        else:
            right = mid - 1  # Search left half
    
    return -1  # Target not found
```
**Why:** Foundational algorithm. Logarithmic time is optimal for sorted data search.

Topics: binary_search, divide_conquer

## [Subsets]

```python
# PROBLEM: Generate all possible subsets (power set)
# TIME: O(2^n * n) SPACE: O(n) for recursion
def subsets(nums):
    """
    Backtracking: at each element, choose to include or exclude.
    Creates binary decision tree with 2^n leaf nodes.
    """
    result = []
    
    def backtrack(start, current):
        # Add current subset to result (always valid)
        result.append(current[:])
        
        # Try adding each remaining element
        for i in range(start, len(nums)):
            # Include nums[i]
            current.append(nums[i])
            
            # Recurse with next start index
            backtrack(i + 1, current)
            
            # Backtrack: exclude nums[i]
            current.pop()
    
    backtrack(0, [])
    return result
```
**Why:** Power set generation is fundamental. Shows how backtracking builds combinations incrementally.

## [Valid Parentheses]

```python
# PROBLEM: Check if parentheses string is valid (matching pairs, correct order)
# TIME: O(n) SPACE: O(n)
def is_valid_parentheses(s):
    """
    Use stack to track opening brackets.
    Each closing bracket must match top of stack.
    """
    # Map closing to opening brackets
    pairs = {')': '(', ']': '[', '}': '{'}
    stack = []
    
    for char in s:
        if char in pairs.values():
            # Opening bracket: push to stack
            stack.append(char)
        elif char in pairs:
            # Closing bracket: must match top
            if not stack or stack[-1] != pairs[char]:
                return False
            stack.pop()
        # Ignore non-bracket characters
    
    # Valid if stack is empty (all matched)
    return len(stack) == 0
```
**Why:** Stack is perfect for nested structure validation. LIFO matches bracket pairing.

Topics: stack, parsing, validation

## [Coin Change]
```python
# PROBLEM: Find minimum coins needed to make target amount
# TIME: O(amount * n) SPACE: O(amount)
def coin_change(coins, amount):
    """
    Bottom-up DP: dp[i] = min coins to make amount i.
    Try each coin, take minimum of all possibilities.
    """
    # dp[i] = min coins for amount i (inf = impossible)
    dp = [float('inf')] * (amount + 1)
    dp[0] = 0  # Base case: 0 coins for amount 0
    
    for i in range(1, amount + 1):
        for coin in coins:
            if coin <= i:
                # If we can use this coin, check if it gives better result
                dp[i] = min(dp[i], dp[i - coin] + 1)
    
    return dp[amount] if dp[amount] != float('inf') else -1
```
**Why:** Classic unbounded knapsack DP. Shows optimal substructure for minimization problems.

Topics: dynamic_programming, unbounded_knapsack, optimization

```python
# PROBLEM: Determine if linked list has a cycle
# TIME: O(n) SPACE: O(1)
def has_cycle(head):
    """
    Floyd's cycle detection: slow and fast pointers.
    If cycle exists, fast will eventually catch slow.
    """
    if not head or not head.next:
        return False
    
    slow = head
    fast = head
    
    while fast and fast.next:
        slow = slow.next       # Move 1 step
        fast = fast.next.next  # Move 2 steps
        
        # If they meet, cycle exists
        if slow == fast:
            return True
    
    # Fast reached end, no cycle
    return False
```
**Why:** Elegant O(1) space solution using two-pointer technique. Applicable to many cycle problems.

Topics: two_pointers, floyd_cycle, linked_list
