```html

<html lang="en">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>Grid Column Start</title>
    <style>
        /* PROBLEM: Position grid item at specific column start line
           TIME: O(1) SPACE: O(1) */

            display: grid;
            grid-template-columns: repeat(4, 1fr);
            gap: 10px;
            padding: 20px;
        }
        
        .grid-item {
            padding: 20px;
            background: #3498db;
            color: white;
            text-align: center;
        }

        .start-2 { grid-column-start: 2; background: #e74c3c; }
        .start-3 { grid-column-start: 3; background: #2ecc71; }
        .start-4 { grid-column-start: 4; background: #f39c12; }
    </style>
</head>
<body>
    <div class="grid-container">
        <div class="grid-item start-1">Column 1</div>
        <div class="grid-item start-2">Column 2</div>
        <div class="grid-item start-3">Column 3</div>
        <div class="grid-item start-4">Column 4</div>
    </div>

</html>
```

## css_pseudo_class_nth_of_type

```html
<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>Nth-of-Type Pseudo-Class</title>
    <style>
        /* PROBLEM: Select elements based on position among siblings of same type
           TIME: O(1) SPACE: O(1) */
        
        .container {
            padding: 20px;
        }
        
        p:nth-of-type(1) {
            background: #3498db;
            color: white;
            padding: 10px;
        }
        
        p:nth-of-type(2) {
            background: #e74c3c;
            color: white;
            padding: 10px;
        }
        
        p:nth-of-type(3) {
            background: #2ecc71;
            color: white;
            padding: 10px;
        }
        
        p:nth-of-type(odd) {
            font-weight: bold;
        }
        
        p:nth-of-type(even) {
            font-style: italic;
        }
    </style>
</head>
<body>
    <div class="container">
        <p>First paragraph - bold (odd)</p>
        <span>This span is ignored</span>
        <p>Second paragraph - italic (even)</p>
        <p>Third paragraph - bold (odd)</p>
        <p>Fourth paragraph - italic (even)</p>
    </div>
</body>
</html>
```

**Why**: Selects elements by position among same-type siblings, perfect for styling patterns.

## css_pseudo_class_empty

```html

    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>Empty Pseudo-Class</title>
    <style>
        /* PROBLEM: Select elements with no children or text content
           TIME: O(1) SPACE: O(1) */
        
        .container {
            padding: 20px;
        }
        
        .message {
            padding: 15px;
            margin: 10px 0;
            background: #ecf0f1;
            border-left: 4px solid #95a5a6;
        }
        
        .message:empty {
            background: linear-gradient(90deg, #e74c3c 0%, #c0392b 100%);

            border-left-color: #c0392b;
            position: relative;
        }
        
        .message:empty::before {
            content: "⚠️ Empty message";
            color: white;
            padding: 15px;
            display: block;
        }
        
        .box {
            width: 100px;
            height: 100px;
            border: 2px solid #3498db;
            margin: 10px;
            display: inline-block;
        }
        
        .box:empty {
            background: repeating-linear-gradient(
                45deg,
                #ffeaa7,
                #ffeaa7 10px,
                #fdcb6e 10px,
                #fdcb6e 20px
            );
        }
    </style>
</head>
<body>

        <div class="message"></div>

            <div class="box"></div>
            <div class="box">Text</div>
        </div>
    </div>
</body>
</html>
```

**Why**: Detects and styles empty elements, helpful for validation states or placeholder content.
