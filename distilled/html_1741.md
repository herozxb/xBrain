## CSS :is() Pseudo-Class Selector

```html
<!DOCTYPE html>
<html lang="en">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>CSS :is() Pseudo-Class</title>
  <style>
    /* 
     * PROBLEM: Group multiple selectors efficiently to reduce code duplication
     * TIME: O(1) SPACE: O(1)
     * 
     * The :is() pseudo-class takes a selector list as argument and
     * selects any element that can be selected by one of the selectors.
     * Zero-specificity for forgiving nature (invalid selectors are ignored).
     */
    
    /* Traditional verbose approach (before :is()):
       article h1, article h2, article h3, article h4,
       section h1, section h2, section h3, section h4,
       aside h1, aside h2, aside h3, aside h4 {
         color: navy;
       }
    */
    
    /* Elegant :is() approach - groups container selectors */
    :is(article, section, aside) :is(h1, h2, h3, h4) {
      color: navy;
      font-family: Georgia, serif;
    }
    
    /* :is() is forgiving - invalid selectors don't break the rule */
    :is(h1, h2, :unsupported-pseudo, h3) {
      margin-bottom: 0.5em;
    }
    
    /* Combining with other pseudo-classes */
    :is(ul, ol) :is(li:first-child, li:last-child) {
      font-weight: bold;
    }
    
    /* Practical example: focus styles for multiple elements */
    :is(input, textarea, select, button):focus {
      outline: 3px solid #4a90d9;
      outline-offset: 2px;
    }
    
    /* Hover states for navigation */
    nav :is(a, button):hover {
      background-color: #f0f0f0;
    }
  </style>
</head>
<body>
  <article>
    <h1>Article Title</h1>
    <h2>Section Heading</h2>
    <p>Content goes here.</p>
  </article>
  
  <nav>
    <a href="#">Home</a>
    <button>Menu</button>
  </nav>
  
  <ul>
    <li>First item (bold)</li>
    <li>Regular item</li>
    <li>Last item (bold)</li>
  </ul>
</body>
</html>
```

**Why**: The `:is()` pseudo-class dramatically reduces CSS redundancy by grouping selectors. It's "forgiving" (ignores invalid selectors) and accepts any specificity. Use for cleaner, more maintainable stylesheets.

## CSS :where() Pseudo-Class Selector

```html
<!DOCTYPE html>
<html lang="en">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>CSS :where() Pseudo-Class</title>
  <style>
    /* 
     * PROBLEM: Apply styles with zero specificity for easy overriding
     * TIME: O(1) SPACE: O(1)
     * 
     * :where() works like :is() but always has 0 specificity.
     * Perfect for base styles that should be easily overridden.
     */
    
    /* Base styles with zero specificity - easily overridden */
    :where(article, section, main) :where(h1, h2, h3) {
      margin: 0.5em 0;
      line-height: 1.3;
    }
    
    /* These overrides will work because they have higher specificity */
    article h2 {
      color: purple;
    }
    
    /* Reset with zero specificity - won't conflict with user styles */
    :where(ul, ol) {
      list-style: none;
      padding: 0;
      margin: 0;
    }
    
    /* User custom styles easily override the reset */
    .custom-list {
      list-style: disc;
      padding-left: 20px;
    }
    
    /* Safe default link styling */
    :where(a) {
      color: inherit;
      text-decoration: none;
    }
    
    /* Specific link styles override easily */
    .nav-link {
      color: blue;
      text-decoration: underline;
    }
  </style>
</head>
<body>
  <article>
    <h1>Article Title</h1>
    <h2>Purple Subheading (overrides base)</h2>
  </article>
  
  <ul class="custom-list">
    <li>Item with disc</li>
  </ul>
  
  <a href="#" class="nav-link">Styled Link</a>
</body>
</html>
```

**Why**: `:where()` provides zero-specificity styling, making it ideal for CSS resets and base styles. Unlike `:is()`, it never increases specificity, ensuring user styles can always override defaults.

## CSS :has() Parent Selector

```html
<!DOCTYPE html>
<html lang="en">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>CSS :has() Parent Selector</title>
  <style>
    /* 
     * PROBLEM: Select parent elements based on their children (previously impossible in CSS)
     * TIME: O(1) SPACE: O(1)
     * 
     * :has() allows selecting a parent based on its children or
     * siblings based on adjacent elements. Called the "parent selector".
     */
    
    /* Style card that contains an image */
    .card:has(img) {
      border: 2px solid #4a90d9;
      padding: 10px;
    }
    
    /* Card with warning icon gets red border */
    .card:has(.warning-icon) {
      border-color: #e74c3c;
      background-color: #ffeaea;
    }
    
    /* Form field styling based on validation state */
    .form-group:has(input:invalid) {
      background-color: #fff5f5;
    }
    
    .form-group:has(input:valid) {
      background-color: #f0fff0;
    }
    
    /* Select label when input is focused */
    label:has(+ input:focus) {
      font-weight: bold;
      color: #4a90d9;
    }
    
    /* Figure with caption gets different styling */
    figure:has(figcaption) {
      background: #f5f5f5;
      padding: 15px;
    }
    
    /* Navigation item containing active link */
    nav li:has(a.active) {
      background-color: #e0e0e0;
    }
    
    /* Table row with empty cells */
    tr:has(td:empty) {
      background-color: #ffffcc;
    }
    
    /* List item containing nested list */
    li:has(ul, ol) {
      font-weight: bold;
    }
  </style>
</head>
<body>
  <!-- Card with image gets blue border -->
  <div class="card">
    <img src="photo.jpg" alt="Photo" width="100">
    <p>Card with image</p>
  </div>
  
  <!-- Card with warning gets red styling -->
  <div class="card">
    <span class="warning-icon">⚠️</span>
    <p>Warning card</p>
  </div>
  
  <!-- Form with validation styling -->
  <div class="form-group">
    <label>Email:</label>
    <input type="email" required>
  </div>
  
  <!-- Figure with caption -->
  <figure>
    <img src="diagram.png" alt="Diagram">
    <figcaption>Figure 1: System Architecture</figcaption>
  </figure>
</body>
</html>
```

**Why**: `:has()` revolutionizes CSS by enabling parent selection based on children. Use for contextual styling (forms with errors, cards with images), eliminating JavaScript for visual state changes.

## CSS margin Shorthand Property

```html
<!DOCTYPE html>
<html lang="en">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>CSS margin Shorthand Property</title>
  <style>
    /* 
     * PROBLEM: Efficiently set element outer spacing on multiple sides
     * TIME: O(1) SPACE: O(1)
     * 
     * margin shorthand sets outer spacing in 1-4 values:
     * - 1 value: all sides
     * - 2 values: vertical | horizontal
     * - 3 values: top | horizontal | bottom
     * - 4 values: top | right | bottom | left (clockwise)
     */
    
    .box {
      background-color: #e0e0e0;
      border: 1px solid #999;
    }
    
    /* Single value - all sides */
    .margin-all {
      margin: 20px;
    }
    
    /* Two values - vertical | horizontal */
    .margin-vh {
      margin: 10px 30px; /* top/bottom: 10px, left/right: 30px */
    }
    
    /* Three values - top | horizontal | bottom */
    .margin-three {
      margin: 5px 20px 15px;
    }
    
    /* Four values - clockwise: top right bottom left */
    .margin-clockwise {
      margin: 10px 20px 30px 40px;
    }
    
    /* auto for horizontal centering (block elements) */
    .centered {
      width: 200px;
      margin: 0 auto; /* top/bottom: 0, left/right: auto */
    }
    
    /* Negative margins for overlap effects */
    .overlap {
      margin-top: -20px;
      background-color: #ffeb3b;
    }
    
    /* Percentage margins (relative to container width) */
    .percent-margin {
      margin: 5%;
    }
    
    /* Individual properties vs shorthand */
    .individual {
      margin-top: 10px;
      margin-right: 15px;
      margin-bottom: 10px;
      margin-left: 15px;
    }
    
    /* Logical properties (direction-independent) */
    .logical {
      margin-block: 10px 20px; /* start end */
      margin-inline: auto;
    }
    
    /* Vertical margin collapse demonstration */
    .collapse-demo div {
      margin: 20px 0;
      background-color: #4a90d9;
      color: white;
    }
  </style>
</head>
<body>
  <div class="box margin-all">All sides: 20px</div>
  
  <div class="box margin-vh">Vertical: 10px, Horizontal: 30px</div>
  
  <div class="box margin-clockwise">10px 20px 30px 40px (clockwise)</div>
  
  <div class="box centered">Centered with margin: 0 auto</div>
  
  <div class="box overlap">Negative margin (overlaps above)</div>
  
  <section class="collapse-demo">
    <div>Box 1 (margin: 20px)</div>
    <div>Box 2 (margins collapse to 20px, not 40px)</div>
  </section>
</body>
</html>
```

**Why**: `margin` shorthand efficiently sets outer spacing with 1-4 values. Remember clockwise order (TRouBLe). Use `auto` for centering, negative values for overlap. Note: vertical margins collapse between siblings.

## CSS transform: translate3d()

```html
<!DOCTYPE html>
```

## CSS @media all Query

```html
<!DOCTYPE html>
<html lang="en">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>CSS @media all Query</title>
  <style>
    /* 
     * PROBLEM: Apply styles based on media type and features
     * TIME: O(1) SPACE: O(1)
     * 
     * @media all is the default media type, matching all devices.
     * Combined with media features, it creates responsive designs.
     * Other types: screen, print, speech.
     */
    
    /* Base styles (apply to all) */
    .responsive-box {
      padding: 20px;
      background-color: #f0f0f0;
      margin-bottom: 10px;
    }
    
    /* @media all is implicit, can be omitted */
    @media all {
      .implicit-all {
        border: 2px solid blue;
      }
    }
    
    /* Combine with features for responsive design */
    @media all and (min-width: 768px) {
      .tablet-up {
        background-color: #d4edda;
        font-size: 1.2em;
      }
    }
    
    /* Screen-specific styles */
    @media screen {
      .screen-only {
        border: 3px solid purple;
      }
    }
    
    /* Print-specific styles */
    @media print {
      .no-print {
        display: none;
      }
      
      body {
        font-size: 12pt;
        color: black;
        background: white;
      }
      
      .page-break {
        page-break-before: always;
      }
    }
    
    /* Speech/audio styles */
    @media speech {
      .emphasis {
        voice-stress: strong;
      }
    }
    
    /* Complex query with multiple conditions */
    @media all and (min-width: 768px) and (max-width: 1024px) and (orientation: portrait) {
      .tablet-portrait {
        background-color: #fff3cd;
      }
    }
    
    /* Dark mode preference */
    @media all and (prefers-color-scheme: dark) {
      body {
        background-color: #1a1a1a;
        color: #ffffff;
      }
      
      .responsive-box {
        background-color: #2d2d2d;
      }
    }
    
    /* Reduced motion preference */
    @media all and (prefers-reduced-motion: reduce) {
      * {
        animation-duration: 0.01ms !important;
        transition-duration: 0.01ms !important;
      }
    }
    
    /* High contrast mode */
    @media all and (prefers-contrast: high) {
      .responsive-box {
        border: 3px solid black;
        background-color: white;
        color: black;
      }
    }
  </style>
</head>
<body>
  <div class="responsive-box implicit-all">
    Blue border (implicit @media all)
  </div>
  
  <div class="responsive-box tablet-up">
    Green on tablets and up (min-width: 768px)
  </div>
  
  <div class="responsive-box screen-only">
    Purple border on screens only
  </div>
  
  <div class="responsive-box no-print">
    This hides when printing
  </div>
  
  <button onclick="window.print()" class="no-print">Print Page</button>
  
  <div class="page-break"></div>
  
  <p>Content after page break (print only)</p>
</body>
</html>
```

**Why**: `@media all` is the default media type, rarely written explicitly. Use media queries with features (width, color-scheme, motion preference) for responsive, accessible designs. Separate screen, print, and speech styles.
