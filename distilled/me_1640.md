## [Maximum Sum Subarray]
```python
# PROBLEM: Find the contiguous subarray with the largest sum
# TIME: O(n) SPACE: O(1)
def max_subarray(nums):
    """
    Kadane's algorithm for maximum subarray sum.
    Tracks local maximum at each position, global maximum overall.
    """
    if not nums:
        return 0
    
    max_current = max_global = nums[0]
    
    for num in nums[1:]:
        # Either extend previous subarray or start new one
        max_current = max(num, max_current + num)
        # Update global maximum if current is larger
        max_global = max(max_global, max_current)
    
    return max_global
```
**Why**: Classic sliding_window technique. Efficiently finds optimal contiguous segment without nested loops.

## [Two Sum - Sorted Array]
```python
# PROBLEM: Find two numbers in sorted array that sum to target
# TIME: O(n) SPACE: O(1)
def two_sum_sorted(nums, target):
    """
    Two pointers approach on sorted array.
    Move pointers inward based on sum comparison with target.
    """
    left, right = 0, len(nums) - 1
    
    while left < right:
        current_sum = nums[left] + nums[right]
        
        if current_sum == target:
            return [left, right]
        elif current_sum < target:
            left += 1  # Need larger sum, move left pointer right
        else:
            right -= 1  # Need smaller sum, move right pointer left
    
    return [-1, -1]  # Not found
```
**Why**: Two pointers technique. Leverages sorted property to eliminate nested loop, achieving linear time.

## [Generate Parentheses]
```python
# PROBLEM: Generate all valid combinations of n pairs of parentheses
# TIME: O(4^n / sqrt(n)) SPACE: O(4^n / sqrt(n))
def generate_parentheses(n):
    """
    Backtracking with pruning.
    Only add '(' when open < n, only add ')' when close < open.
    """
    result = []
    
    def backtrack(current, open_count, close_count):
        # Base case: complete valid combination
        if len(current) == 2 * n:
            result.append(current)
            return
        
        # Add opening parenthesis if we haven't used all n
        if open_count < n:
            backtrack(current + '(', open_count + 1, close_count)
        
        # Add closing parenthesis if it won't invalidate
        if close_count < open_count:
            backtrack(current + ')', open_count, close_count + 1)
    
    backtrack('', 0, 0)
    return result
```
**Why**: Backtracking with smart pruning. Explores valid paths only, avoiding invalid states early.

## [Number of Connected Components]
```python
# PROBLEM: Count connected components in undirected graph
# TIME: O(n * α(n)) SPACE: O(n)
class UnionFind:
    def __init__(self, n):
        self.parent = list(range(n))
        self.rank = [0] * n
        self.components = n
    
    def find(self, x):
        # Path compression: point directly to root
        if self.parent[x] != x:
            self.parent[x] = self.find(self.parent[x])
        return self.parent[x]
    
    def union(self, x, y):
        # Union by rank: attach smaller tree to larger
        px, py = self.find(x), self.find(y)
        if px == py:
            return False  # Already connected
        
        if self.rank[px] < self.rank[py]:
            px, py = py, px
        self.parent[py] = px
        if self.rank[px] == self.rank[py]:
            self.rank[px] += 1
        
        self.components -= 1
        return True

def count_components(n, edges):
    """
    Union-Find to count connected components.
    Each successful union decrements component count.
    """
    uf = UnionFind(n)
    for u, v in edges:
        uf.union(u, v)
    return uf.components
```
**Why**: Union-Find with path compression and union by rank. Near-constant time per operation, ideal for connectivity queries.

## [Longest Increasing Subsequence]
```python
# PROBLEM: Find length of longest increasing subsequence
# TIME: O(n log n) SPACE: O(n)
def longest_increasing_subsequence(nums):
    """
    Binary search approach on patience sorting.
    Maintain smallest tail of all increasing subsequences of each length.
    """
    if not nums:
        return 0
    
    tails = []  # tails[i] = smallest tail of LIS of length i+1
    
    for num in nums:
        # Binary search for first tail >= num
        left, right = 0, len(tails)
        while left < right:
            mid = (left + right) // 2
            if tails[mid] < num:
                left = mid + 1
            else:
                right = mid
        
        # Extend or replace
        if left == len(tails):
            tails.append(num)
        else:
            tails[left] = num
    
    return len(tails)
```
**Why**: DP optimization using binary search. Reduces from O(n²) to O(n log n) by maintaining greedy tails.

## [Course Schedule - Detect Cycle]
```python
# PROBLEM: Determine if all courses can be finished (detect cycle in DAG)
# TIME: O(V + E) SPACE: O(V + E)
from collections import defaultdict, deque

def can_finish_courses(num_courses, prerequisites):
    """
    Topological sort using Kahn's algorithm (BFS).
    If we can process all nodes, no cycle exists.
    """
    # Build graph and in-degree count
    graph = defaultdict(list)
    in_degree = [0] * num_courses
    
    for course, prereq in prerequisites:
        graph[prereq].append(course)
        in_degree[course] += 1
    
    # Start with all nodes having no dependencies
    queue = deque([i for i in range(num_courses) if in_degree[i] == 0])
    completed = 0
    
    while queue:
        node = queue.popleft()
        completed += 1
        
        # Reduce in-degree of neighbors
        for neighbor in graph[node]:
            in_degree[neighbor] -= 1
            if in_degree[neighbor] == 0:
                queue.append(neighbor)
    
    return completed == num_courses
```
**Why**: Graph topological sort using BFS. Detects cycles by checking if all nodes can be processed.

## [Lowest Common Ancestor in BST]
```python
# PROBLEM: Find lowest common ancestor of two nodes in BST
# TIME: O(h) SPACE: O(1)
def lowest_common_ancestor(root, p, q):
    """
    Leverage BST property: left < root < right.
    First node where p and q diverge is LCA.
    """
    while root:
        # Both nodes in left subtree
        if p.val < root.val and q.val < root.val:
            root = root.left
        # Both nodes in right subtree
        elif p.val > root.val and q.val > root.val:
            root = root.right
        # Divergence point or one is ancestor of other
        else:
            return root
    
    return None
```
**Why**: Tree traversal leveraging BST property. No need for parent pointers or recursion stack.

## [Implement Trie]
```python
# PROBLEM: Implement trie with insert, search, and startsWith
# TIME: O(m) per operation SPACE: O(total characters)
class TrieNode:
    def __init__(self):
        self.children = {}
        self.is_end = False

class Trie:
    def __init__(self):
        self.root = TrieNode()
    
    def insert(self, word):
        """Insert word into trie."""
        node = self.root
        for char in word:
            if char not in node.children:
                node.children[char] = TrieNode()
            node = node.children[char]
        node.is_end = True
    
    def search(self, word):
        """Check if word exists in trie."""
        node = self.root
        for char in word:
            if char not in node.children:
                return False
            node = node.children[char]
        return node.is_end
    
    def starts_with(self, prefix):
        """Check if any word starts with prefix."""
        node = self.root
        for char in prefix:
            if char not in node.children:
                return False
            node = node.children[char]
        return True
```
**Why**: Trie provides efficient prefix-based operations. Optimal for autocomplete, dictionary, and prefix matching.

## [Climbing Stairs with Memoization]
```python
# PROBLEM: Count ways to climb n stairs (1 or 2 steps at a time)
# TIME: O(n) SPACE: O(n) with cache, O(1) optimized
from functools import lru_cache

@lru_cache(maxsize=None)
def climb_stairs_memo(n):
    """
    Recursion with LRU cache (memoization).
    Same as Fibonacci: f(n) = f(n-1) + f(n-2).
    """
    if n <= 2:
        return n
    return climb_stairs_memo(n - 1) + climb_stairs_memo(n - 2)

def climb_stairs_dp(n):
    """
    Iterative DP with O(1) space.
    Only need previous two values.
    """
    if n <= 2:
        return n
    
    prev, curr = 1, 2
    for i in range(3, n + 1):
        prev, curr = curr, prev + curr
    
    return curr
```
**Why**: LRU_cache decorator provides automatic memoization. Transforms exponential recursion to linear time with clean syntax.
