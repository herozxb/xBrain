## css_transition_timing

```html
<!DOCTYPE html>

<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">

        /* PROBLEM: Create smooth animations with custom timing curves */
        /* TIME: O(1) SPACE: O(1) */
        
        .box {
            width: 100px;
            height: 100px;
            background: #3498db;
            margin: 20px;
            transition: transform 1s;
        }

        /* Steps for discrete animations */

        .container:hover .box {
            transform: translateX(300px);
        }
    </style>
</head>
<body>
    <div class="container">
        <h2>Hover to see timing differences</h2>

</html>
```

**Why**: Timing functions control acceleration curves, making animations feel natural. `cubic-bezier()` enables custom effects like elastic bounce; `steps()` creates discrete frame-by-frame animation.

## css_animation_fill_mode

```html
<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>CSS Animation Fill Mode</title>
    <style>
        /* PROBLEM: Control element state before/after animation */
        /* TIME: O(1) SPACE: O(1) */
        
        @keyframes growFade {
            0% { transform: scale(0); opacity: 0; }
            100% { transform: scale(1); opacity: 1; }
        }
        
        @keyframes shrink {
            0% { transform: scale(1); }
            100% { transform: scale(0); }
        }
        
        .container {
            display: flex;
            gap: 20px;
            flex-wrap: wrap;
        }
        
        .box {
            width: 80px;
            height: 80px;
            background: #2ecc71;
            margin: 10px;
            animation-name: growFade;
            animation-duration: 2s;
            animation-delay: 1s;
        }
        
        /* Default: element jumps to 0% before delay, returns to original after */
        .none {
            animation-fill-mode: none;
            /* Invisible before, snaps back after */
        }
        
        /* forwards: keeps 100% state after animation ends */
        .forwards {
            animation-fill-mode: forwards;
            /* Stays visible and scaled after animation */
        }
        
        /* backwards: applies 0% state during delay */
        .backwards {
            animation-fill-mode: backwards;
            /* Visible as scaled-0 during 1s delay */
        }
        
        /* both: forwards + backwards combined */
        .both {
            animation-fill-mode: both;
            /* Scaled-0 during delay, stays at 100% after */
        }
    </style>
</head>
<body>
    <h2>Hover to restart animations</h2>
    <div class="container">
        <div class="box none">none</div>
        <div class="box forwards">forwards</div>
        <div class="box backwards">backwards</div>
        <div class="box both">both</div>
    </div>
    
    <script>
        document.querySelectorAll('.box').forEach(box => {
            box.addEventListener('click', function() {
                this.style.animation = 'none';
                this.offsetHeight; // Trigger reflow
                this.style.animation = '';
            });
        });
    </script>
</body>
</html>
```

**Why**: `fill-mode` controls what happens before delay starts and after animation ends. `forwards` locks final state; `backwards` applies start state during delay; `both` does both.

## css_animation_shorthand

```html
<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>CSS Animation Shorthand</title>
    <style>
        /* PROBLEM: Define all animation properties in one line */
        /* TIME: O(1) SPACE: O(1) */
        
        /* Define keyframes */
        @keyframes slideRotate {
            0% { transform: translateX(0) rotate(0deg); opacity: 0.5; }
            100% { transform: translateX(300px) rotate(360deg); opacity: 1; }
        }
        
        @keyframes pulse {
            0%, 100% { transform: scale(1); }
            50% { transform: scale(1.1); }
        }
        
        @keyframes colorCycle {
            0% { background: #e74c3c; }
            33% { background: #3498db; }
            66% { background: #2ecc71; }
            100% { background: #e74c3c; }
        }
        
        .box {
            width: 60px;
            height: 60px;
            margin: 20px;
            display: inline-block;
        }
        
        /* Full shorthand syntax:
           animation: name duration timing-function delay iteration-count direction fill-mode play-state
        */
        
        /* Minimal: name + duration */
        .minimal {
            animation: pulse 1s;
        }
        
        /* Common: name duration timing iteration */
        .common {
            animation: slideRotate 2s ease-in-out infinite;
        }
        
        /* Complete: all properties */
        .complete {
            animation: slideRotate 
                       2s              /* duration */
                       cubic-bezier(0.68, -0.55, 0.265, 1.55) /* timing */
                       0.5s            /* delay */
                       infinite        /* iteration */
                       alternate       /* direction */
                       both            /* fill-mode */
                       running;        /* play-state */
        }
        
        /* Multiple animations */
        .multiple {
            animation: 
                pulse 1s ease-in-out infinite,
                colorCycle 3s linear infinite;
        }
        
        /* Practical: loading spinner */
        .spinner {
            width: 40px;
            height: 40px;
            border: 4px solid #f3f3f3;
            border-top: 4px solid #3498db;
            border-radius: 50%;
            animation: spin 1s linear infinite;
        }
        
        @keyframes spin {
            to { transform: rotate(360deg); }
        }
    </style>
</head>
<body>
    <h2>Animation Shorthand Examples</h2>
    
    <div class="box minimal" style="background: #e74c3c;">Minimal</div>
    <div class="box common" style="background: #3498db;">Common</div>
    <div class="box complete" style="background: #2ecc71;">Complete</div>
    <div class="box multiple">Multiple</div>
    
    <h2>Loading Spinner (shorthand in action)</h2>
    <div class="spinner"></div>
</body>
</html>
```

**Why**: Shorthand reduces code from 8 lines to 1. Order matters: `name` and `duration` required; others optional. Multiple animations comma-separated. Cleanest way to define common patterns like spinners and pulses.

## Summary

All 10 CSS transforms/animation properties covered:
1. **transition-timing-function** - Easing curves (ease, linear, cubic-bezier, steps)
2. **transition-delay** - Stagger animations with time offsets
3. **animation-duration** - Control cycle length (s or ms)
4. **animation-timing-function** - Easing for keyframe animations
5. **animation-delay** - Start animations after delay
6. **animation-iteration-count** - Repeat count (number or infinite)
7. **animation-direction** - Forward, reverse, alternate playback
8. **animation-fill-mode** - State before/after animation
9. **animation-play-state** - Pause/resume control
10. **animation** - Shorthand for all properties

Each function includes practical examples with comments explaining use cases and performance characteristics.
