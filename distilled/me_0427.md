## [Maximum Sum Subarray of Size K]

```python
# PROBLEM: Find maximum sum of any contiguous subarray of size k
# TIME: O(n) SPACE: O(1)
def max_sum_subarray_k(arr, k):
    # Edge case: array smaller than window
    if len(arr) < k:
        return -1
    
    # Compute sum of first window
    window_sum = sum(arr[:k])
    max_sum = window_sum
    
    # Slide window: subtract element leaving, add element entering
    for i in range(len(arr) - k):
        window_sum = window_sum - arr[i] + arr[i + k]
        max_sum = max(max_sum, window_sum)
    
    return max_sum
```
**Why**: Classic sliding window pattern. Reduces nested loop O(nk) to O(n) by reusing computations.

## [Two Sum II - Sorted Array]

```python
# PROBLEM: Find two numbers in sorted array that sum to target
# TIME: O(n) SPACE: O(1)
def two_sum_sorted(arr, target):
    # Two pointers: one at start, one at end
    left, right = 0, len(arr) - 1
    
    while left < right:
        current_sum = arr[left] + arr[right]
        
        if current_sum == target:
            return [left, right]  # Found the pair
        elif current_sum < target:
            left += 1  # Need larger sum, move left pointer right
        else:
            right -= 1  # Need smaller sum, move right pointer left
    
    return [-1, -1]  # No solution exists
```
**Why**: Two pointers exploits sorted property. Each step eliminates half the remaining search space.

## [Subsets]

```python
# PROBLEM: Generate all possible subsets of a set
# TIME: O(n * 2^n) SPACE: O(n) for recursion stack
def subsets(nums):
    result = []
    
    def backtrack(start, current):
        # Add copy of current subset to result
        result.append(current[:])
        
        # Try adding each remaining element
        for i in range(start, len(nums)):
            current.append(nums[i])      # Choose
            backtrack(i + 1, current)    # Explore
            current.pop()                # Unchoose (backtrack)
    
    backtrack(0, [])
    return result
```
**Why**: Backtracking explores all possibilities by building incrementally and undoing choices.

## [Number of Connected Components]

```python
# PROBLEM: Count connected components in undirected graph
# TIME: O(n * α(n)) ≈ O(n) SPACE: O(n)
class UnionFind:
    def __init__(self, n):
        self.parent = list(range(n))
        self.rank = [0] * n
        self.components = n
    
    def find(self, x):
        # Path compression: point to root directly
        if self.parent[x] != x:
            self.parent[x] = self.find(self.parent[x])
        return self.parent[x]
    
    def union(self, x, y):
        px, py = self.find(x), self.find(y)
        if px == py:
            return  # Already connected
        
        # Union by rank: attach smaller tree to larger
        if self.rank[px] < self.rank[py]:
            px, py = py, px
        self.parent[py] = px
        if self.rank[px] == self.rank[py]:
            self.rank[px] += 1
        self.components -= 1

def count_components(n, edges):
    uf = UnionFind(n)
    for u, v in edges:
        uf.union(u, v)
    return uf.components
```
**Why**: Union-Find efficiently handles dynamic connectivity. Path compression + rank gives near-constant amortized time.

## [Longest Common Subsequence]

```python
# PROBLEM: Find length of longest common subsequence between two strings
# TIME: O(m * n) SPACE: O(m * n)
def lcs(text1, text2):
    m, n = len(text1), len(text2)
    # dp[i][j] = LCS length of text1[:i] and text2[:j]
    dp = [[0] * (n + 1) for _ in range(m + 1)]
    
    for i in range(1, m + 1):
        for j in range(1, n + 1):
            if text1[i-1] == text2[j-1]:
                # Characters match: extend LCS
                dp[i][j] = dp[i-1][j-1] + 1
            else:
                # Take max of skipping either character
                dp[i][j] = max(dp[i-1][j], dp[i][j-1])
    
    return dp[m][n]
```
**Why**: DP breaks problem into overlapping subproblems. Each cell represents optimal substructure solution.

## [Course Schedule - Cycle Detection]

```python
# PROBLEM: Determine if all courses can be finished given prerequisites
# TIME: O(V + E) SPACE: O(V + E)
def can_finish(num_courses, prerequisites):
    # Build adjacency list
    graph = {i: [] for i in range(num_courses)}
    for course, prereq in prerequisites:
        graph[course].append(prereq)
    
    # States: 0=unvisited, 1=visiting, 2=visited
    state = [0] * num_courses
    
    def has_cycle(node):
        if state[node] == 1:  # Back edge found
            return True
        if state[node] == 2:  # Already processed
            return False
        
        state[node] = 1  # Mark as visiting
        
        for neighbor in graph[node]:
            if has_cycle(neighbor):
                return True
        
        state[node] = 2  # Mark as visited
        return False
    
    # Check each course for cycles
    for course in range(num_courses):
        if has_cycle(course):
            return False
    
    return True
```
**Why**: DFS cycle detection using 3-state coloring. Essential for dependency resolution problems.

## [Binary Tree Level Order Traversal]

```python
# PROBLEM: Return nodes level by level from left to right
# TIME: O(n) SPACE: O(n)
from collections import deque

def level_order(root):
    if not root:
        return []
    
    result = []
    queue = deque([root])
    
    while queue:
        level_size = len(queue)
        current_level = []
        
        # Process all nodes at current level
        for _ in range(level_size):
            node = queue.popleft()
            current_level.append(node.val)
            
            # Add children for next level
            if node.left:
                queue.append(node.left)
            if node.right:
                queue.append(node.right)
        
        result.append(current_level)
    
    return result
```
**Why**: BFS with level-size tracking processes tree breadth-first. Queue ensures FIFO order per level.

## [Kth Largest Element]

```python
# PROBLEM: Find kth largest element in unsorted array
# TIME: O(n log k) SPACE: O(k)
import heapq

def find_kth_largest(nums, k):
    # Min-heap of size k keeps k largest elements
    # Root is smallest among k largest = kth largest overall
    min_heap = []
    
    for num in nums:
        heapq.heappush(min_heap, num)
        
        # Maintain heap size k
        if len(min_heap) > k:
            heapq.heappop(min_heap)
    
    return min_heap[0]  # Root is kth largest
```
**Why**: Min-heap of size k efficiently tracks top k elements. Avoids sorting entire array O(n log n).

## [Implement Trie]

```python
# PROBLEM: Implement trie with insert, search, and startsWith
# TIME: O(m) per operation where m = word length SPACE: O(alphabet_size * total_chars)
class TrieNode:
    def __init__(self):
        self.children = {}  # char -> TrieNode
        self.is_end = False

class Trie:
    def __init__(self):
        self.root = TrieNode()
    
    def insert(self, word):
        node = self.root
        for char in word:
            if char not in node.children:
                node.children[char] = TrieNode()
            node = node.children[char]
        node.is_end = True
    
    def search(self, word):
        node = self._traverse(word)
        return node is not None and node.is_end
    
    def startsWith(self, prefix):
        return self._traverse(prefix) is not None
    
    def _traverse(self, prefix):
        node = self.root
        for char in prefix:
            if char not in node.children:
                return None
            node = node.children[char]
        return node
```
**Why**: Trie provides O(m) prefix operations. Essential for autocomplete, spell checkers, and word games.

## [Climbing Stairs with Memoization]

```python
# PROBLEM: Count ways to climb n stairs taking 1 or 2 steps
# TIME: O(n) SPACE: O(n)
from functools import lru_cache

@lru_cache(maxsize=None)
def climb_stairs(n):
    # Base cases: 1 way for 0/1 stairs
    if n <= 1:
        return 1
    
    # Recursive case: sum of ways from 1 or 2 steps back
    return climb_stairs(n - 1) + climb_stairs(n - 2)

# Alternative: iterative DP with O(1) space
def climb_stairs_iterative(n):
    if n <= 1:
        return 1
    
    prev, curr = 1, 1
    for _ in range(2, n + 1):
        prev, curr = curr, prev + curr
    
    return curr
```
**Why**: LRU cache memoization eliminates redundant recursion. Transforms O(2^n) to O(n). Classic Fibonacci pattern.
