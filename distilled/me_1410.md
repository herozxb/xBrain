## Maximum Sum Subarray of Size K

```python
# PROBLEM: Given an array of integers and an integer k, find the maximum sum
# of any contiguous subarray of size k.
# TIME: O(n) SPACE: O(1)
def max_sum_subarray_k(arr, k):
    """
    Uses sliding window technique to efficiently compute maximum sum.
    Instead of recalculating sum for each window, we slide and adjust.
    """
    if len(arr) < k:
        return None
    
    # Compute sum of first window
    window_sum = sum(arr[:k])
    max_sum = window_sum
    
    # Slide the window: subtract leftmost, add new rightmost
    for i in range(k, len(arr)):
        window_sum = window_sum - arr[i - k] + arr[i]
        max_sum = max(max_sum, window_sum)
    
    return max_sum
```
**Why**: Classic sliding window pattern. Avoids O(n*k) brute force by reusing previous computation. Useful for all fixed-window subarray problems.

**Topics**: `sliding_window`

## 3Sum

```python
# PROBLEM: Find all unique triplets in an array that sum to zero.
# TIME: O(n²) SPACE: O(1) excluding output
def three_sum(nums):
    """
    Sort array, fix one element, then use two pointers for remaining two.
    Two pointers converge from both ends to find pairs summing to target.
    """
    nums.sort()
    result = []
    n = len(nums)
    
    for i in range(n - 2):
        # Skip duplicates for first element
        if i > 0 and nums[i] == nums[i - 1]:
            continue
        
        # Two pointers: left starts after i, right at end
        left, right = i + 1, n - 1
        
        while left < right:
            total = nums[i] + nums[left] + nums[right]
            
            if total == 0:
                result.append([nums[i], nums[left], nums[right]])
                # Skip duplicates
                while left < right and nums[left] == nums[left + 1]:
                    left += 1
                while left < right and nums[right] == nums[right - 1]:
                    right -= 1
                left += 1
                right -= 1
            elif total < 0:
                left += 1  # Need larger sum
            else:
                right -= 1  # Need smaller sum
    
    return result
```
**Why**: Two pointers reduce O(n³) brute force to O(n²). Sorting enables the pointer strategy and easy duplicate skipping.

**Topics**: `two_pointers`

## N-Queens

```python
# PROBLEM: Place N queens on an N×N chessboard so no two queens attack each other.
# TIME: O(N!) SPACE: O(N²)
def solve_n_queens(n):
    """
    Backtracking: try placing queen row by row, backtrack when conflict found.
    Track columns and diagonals to check validity in O(1).
    """
    def is_safe(board, row, col):
        # Check column
        for i in range(row):
            if board[i][col]:
                return False
        # Check upper-left diagonal
        i, j = row - 1, col - 1
        while i >= 0 and j >= 0:
            if board[i][j]:
                return False
            i -= 1
            j -= 1
        # Check upper-right diagonal
        i, j = row - 1, col + 1
        while i >= 0 and j < n:
            if board[i][j]:
                return False
            i -= 1
            j += 1
        return True
    
    def backtrack(row, board, solutions):
        if row == n:
            # Convert board to output format
            solutions.append([''.join('Q' if c else '.' for c in r) for r in board])
            return
        
        for col in range(n):
            if is_safe(board, row, col):
                board[row][col] = True
                backtrack(row + 1, board, solutions)
                board[row][col] = False  # Undo (backtrack)
    
    board = [[False] * n for _ in range(n)]
    solutions = []
    backtrack(0, board, solutions)
    return solutions
```
**Why**: Prototypical backtracking problem. Demonstrates constraint checking, state exploration, and pruning. Foundation for all constraint satisfaction problems.

**Topics**: `backtracking`

## Number of Connected Components (Union-Find)

```python
# PROBLEM: Count connected components in an undirected graph with n nodes.
# TIME: O(n * α(n)) ≈ O(n) SPACE: O(n)
class UnionFind:
    """Union-Find (Disjoint Set Union) with path compression and union by rank."""
    
    def __init__(self, n):
        self.parent = list(range(n))
        self.rank = [0] * n
        self.components = n
    
    def find(self, x):
        """Find root with path compression."""
        if self.parent[x] != x:
            self.parent[x] = self.find(self.parent[x])
        return self.parent[x]
    
    def union(self, x, y):
        """Union by rank. Returns True if merged, False if already connected."""
        px, py = self.find(x), self.find(y)
        if px == py:
            return False
        
        # Merge lower rank into higher rank
        if self.rank[px] < self.rank[py]:
            px, py = py, px
        self.parent[py] = px
        if self.rank[px] == self.rank[py]:
            self.rank[px] += 1
        
        self.components -= 1
        return True

def count_components(n, edges):
    """
    Use Union-Find to merge nodes connected by edges.
    Number of components = initial nodes - successful unions.
    """
    uf = UnionFind(n)
    for u, v in edges:
        uf.union(u, v)
    return uf.components
```
**Why**: Union-Find is essential for connectivity problems, cycle detection, and Kruskal's MST. Path compression + rank gives near-constant amortized time.

**Topics**: `union_find`

## Longest Common Subsequence

```python
# PROBLEM: Find the length of the longest common subsequence of two strings.
# TIME: O(m*n) SPACE: O(min(m, n)) with optimization
def longest_common_subsequence(text1, text2):
    """
    Classic 2D DP. dp[i][j] = LCS length of text1[:i] and text2[:j].
    If chars match, extend previous LCS; otherwise, take max of skipping either char.
    Space can be optimized to O(min(m, n)) using two rows.
    """
    # Ensure text1 is shorter for space optimization
    if len(text1) < len(text2):
        text1, text2 = text2, text1
    
    m, n = len(text1), len(text2)
    # Only need previous row and current row
    prev = [0] * (n + 1)
    
    for i in range(1, m + 1):
        curr = [0] * (n + 1)
        for j in range(1, n + 1):
            if text1[i - 1] == text2[j - 1]:
                # Characters match: extend LCS
                curr[j] = prev[j - 1] + 1
            else:
                # Take maximum of skipping char from either string
                curr[j] = max(prev[j], curr[j - 1])
        prev = curr
    
    return prev[n]
```
**Why**: Foundational DP pattern. The "match → diagonal+1, mismatch → max(adjacent)" pattern appears in edit distance, string alignment, and many sequence problems.

**Topics**: `dp`

## Dijkstra's Shortest Path

```python
# PROBLEM: Find shortest path from source to all nodes in weighted graph.
# TIME: O((V + E) log V) SPACE: O(V)
import heapq

def dijkstra(n, edges, source):
    """
    Greedy BFS with min-heap. Always process closest unvisited node.
    Works only with non-negative edge weights.
    """
    # Build adjacency list
    graph = [[] for _ in range(n)]
    for u, v, w in edges:
        graph[u].append((v, w))
    
    # Distance array: initialize to infinity
    dist = [float('inf')] * n
    dist[source] = 0
    
    # Min-heap: (distance, node)
    heap = [(0, source)]
    
    while heap:
        d, u = heapq.heappop(heap)
        
        # Skip if we've already found a better path
        if d > dist[u]:
            continue
        
        # Relax all neighbors
        for v, w in graph[u]:
            new_dist = dist[u] + w
            if new_dist < dist[v]:
                dist[v] = new_dist
                heapq.heappush(heap, (dist[v], v))
    
    return dist
```
**Why**: Fundamental graph algorithm for shortest paths with non-negative weights. Heap-based implementation is efficient and widely used in navigation, networking, and pathfinding.

**Topics**: `graphs`

## Lowest Common Ancestor in Binary Tree

```python
# PROBLEM: Find the lowest common ancestor of two nodes in a binary tree.
# TIME: O(n) SPACE: O(h) where h is tree height
class TreeNode:
    def __init__(self, val=0, left=None, right=None):
        self.val = val
        self.left = left
        self.right = right

def lowest_common_ancestor(root, p, q):
    """
    Recursively search for p and q. LCA is where paths diverge.
    If one node is ancestor of other, that node is the LCA.
    """
    # Base case: reached end or found one of the targets
    if root is None or root == p or root == q:
        return root
    
    # Search in both subtrees
    left = lowest_common_ancestor(root.left, p, q)
    right = lowest_common_ancestor(root.right, p, q)
    
    # If both sides returned non-null, current node is LCA
    if left and right:
        return root
    
    # Otherwise, return the non-null side (or None if both null)
    return left if left else right
```
**Why**: Essential tree operation used in many problems. Pattern: recursive search returning "found" status upward, combining results at divergence point.

**Topics**: `trees`

## Merge K Sorted Lists

```python
# PROBLEM: Merge k sorted linked lists into one sorted list.
# TIME: O(n log k) where n = total nodes, k = number of lists
# SPACE: O(k) for heap
import heapq

class ListNode:
    def __init__(self, val=0, next=None):
        self.val = val
        self.next = next
    
    # For heap comparison
    def __lt__(self, other):
        return self.val < other.val

def merge_k_sorted_lists(lists):
    """
    Use min-heap to always get smallest among k list heads.
    Each pop is O(log k), done n times total.
    """
    # Initialize heap with first node from each non-empty list
    heap = []
    for node in lists:
        if node:
            heapq.heappush(heap, node)
    
    dummy = ListNode()
    current = dummy
    
    while heap:
        # Get smallest node
        smallest = heapq.heappop(heap)
        current.next = smallest
        current = current.next
        
        # Push next node from same list if exists
        if smallest.next:
            heapq.heappush(heap, smallest.next)
    
    return dummy.next
```
**Why**: Classic heap application. Demonstrates efficient k-way merge pattern used in external sorting, streaming, and distributed systems.

**Topics**: `heap`

## Word Dictionary with Wildcard Search

```python
# PROBLEM: Design a data structure that supports adding words and searching 
# for words including wildcard '.' matches.
# TIME: O(L) add, O(26^L) search worst case with all wildcards
# SPACE: O(N * L) where N = number of words, L = average length
class TrieNode:
    def __init__(self):
        self.children = {}  # char -> TrieNode
        self.is_word = False

class WordDictionary:
    """
    Trie structure where each node has children dict and word-end flag.
    Wildcard search requires DFS through all children at '.' positions.
    """
    
    def __init__(self):
        self.root = TrieNode()
    
    def add_word(self, word):
        """Insert word into trie character by character."""
        node = self.root
        for ch in word:
            if ch not in node.children:
                node.children[ch] = TrieNode()
            node = node.children[ch]
        node.is_word = True
    
    def search(self, word):
        """Search with wildcard support via recursive DFS."""
        def dfs(node, i):
            if i == len(word):
                return node.is_word
            
            ch = word[i]
            if ch != '.':
                # Exact match required
                if ch not in node.children:
                    return False
                return dfs(node.children[ch], i + 1)
            else:
                # Wildcard: try all children
                for child in node.children.values():
                    if dfs(child, i + 1):
                        return True
                return False
        
        return dfs(self.root, 0)
```
**Why**: Trie enables efficient prefix-based search. Adding wildcard support shows how tries combine with DFS for pattern matching. Foundation for autocomplete, spell checkers.

**Topics**: `trie`

## LRU Cache

```python
# PROBLEM: Design a cache that stores at most capacity items and evicts 
# least recently used when full. Get and put must be O(1).
# TIME: O(1) get/put SPACE: O(capacity)
class Node:
    """Doubly linked list node for O(1) removal/insertion."""
    def __init__(self, key=0, val=0):
        self.key = key
        self.val = val
        self.prev = None
        self.next = None

class LRUCache:
    """
    Hash map for O(1) key lookup + doubly linked list for O(1) ordering.
    Most recent at head (right), least recent at tail (left).
    """
    
    def __init__(self, capacity):
        self.capacity = capacity
        self.cache = {}  # key -> Node
        
        # Dummy head/tail for easier list manipulation
        self.head = Node()  # Least recent (dummy tail)
        self.tail = Node()  # Most recent (dummy head)
        self.head.next = self.tail
        self.tail.prev = self.head
    
    def _remove(self, node):
        """Remove node from list."""
        prev, nxt = node.prev, node.next
        prev.next = nxt
        nxt.prev = prev
    
    def _add_to_tail(self, node):
        """Add node right before tail (most recent position)."""
        node.prev = self.tail.prev
        node.next = self.tail
        self.tail.prev.next = node
        self.tail.prev = node
    
    def get(self, key):
        """Get value and move to most recent. Return -1 if not found."""
        if key not in self.cache:
            return -1
        
        node = self.cache[key]
        # Move to most recent position
        self._remove(node)
        self._add_to_tail(node)
        return node.val
    
    def put(self, key, value):
        """Insert/update key. Evict LRU if over capacity."""
        if key in self.cache:
            # Update existing node
            node = self.cache[key]
            node.val = value
            self._remove(node)
            self._add_to_tail(node)
        else:
            # Insert new node
            if len(self.cache) >= self.capacity:
                # Evict LRU (node after head dummy)
                lru = self.head.next
                self._remove(lru)
                del self.cache[lru.key]
            
            new_node = Node(key, value)
            self.cache[key] = new_node
            self._add_to_tail(new_node)
```
**Why**: Combines hash map O(1) lookup with doubly linked list O(1) reordering. Standard pattern for implementing ordered caches. Appears frequently in systems design.

**Topics**: `lru_cache`

**Key Insights:**
- **Sliding Window**: Reuse computation when window moves
- **Two Pointers**: Exploit sorted structure to avoid nested loops
- **Backtracking**: Explore + undo; prune invalid paths early
- **Union-Find**: Path compression + rank = near-constant ops
- **DP**: Overlapping subproblems + optimal substructure
- **Graphs**: BFS/DFS for unweighted, Dijkstra for weighted
- **Trees**: Recursive decomposition; post-order for ancestor problems
- **Heap**: K-way merge via always selecting minimum
- **Trie**: Character-by-character search with shared prefixes
- **LRU Cache**: HashMap + DoublyLinkedList = O(1) ordered access
