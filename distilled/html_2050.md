## css_background_shorthand

```html
<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>CSS Background Shorthand</title>
    <style>
        /* PROBLEM: Apply multiple background properties efficiently
           TIME: O(1) SPACE: O(1) */
        
        /* Shorthand syntax: 
           background: [color] [image] [position] / [size] [repeat] [attachment] [origin] [clip] */
        
        .box {
            width: 300px;
            height: 200px;
            
            /* Longhand version (7 separate properties) */
            background-color: #3498db;
            background-image: url('pattern.png');
            background-position: center center;
            background-size: cover;
            background-repeat: no-repeat;
            background-attachment: scroll;
            background-origin: padding-box;
        }
        
        .box-shorthand {
            width: 300px;
            height: 200px;
            
            /* Shorthand - all properties in one declaration */
            background: #3498db url('pattern.png') center/cover no-repeat scroll padding-box;
        }
        
        /* Minimal shorthand with defaults */
        .minimal {
            background: #e74c3c;  /* Only color, others default */
        }
        
        /* Gradient shorthand */
        .gradient {
            background: linear-gradient(135deg, #667eea 0%, #764ba2 100%);
        }
        
        /* Multiple backgrounds */
        .multiple {
            background: 
                url('overlay.png') top right no-repeat,
                url('main-bg.jpg') center/cover no-repeat,
                #2c3e50;
        }
    </style>
</head>
<body>
    <div class="box-shorthand">Background Shorthand</div>
</body>
</html>
```

**Why**: The shorthand property reduces CSS file size and improves readability. It allows setting all background properties in one declaration, with browsers applying defaults for omitted values. Order is flexible except that background-size must follow background-position separated by `/`.

## css_multiple_backgrounds

```html
<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>CSS Multiple Backgrounds</title>
    <style>
        /* PROBLEM: Layer multiple background images on a single element
           TIME: O(1) SPACE: O(1) */
        
        .hero {
            width: 100%;
            height: 400px;
            position: relative;
            
            /* Stack backgrounds: first image is on top, last is at bottom */
            background: 
                /* Top layer: decorative icon */
                url('icon.svg') 20px 20px no-repeat,
                
                /* Middle layer: gradient overlay */
                linear-gradient(135deg, rgba(0,0,0,0.5) 0%, transparent 100%) center/cover,
                
                /* Bottom layer: main image */
                url('hero-bg.jpg') center/cover no-repeat;
        }
        
        /* Complex example with different blend modes */
        .blended {
            width: 500px;
            height: 300px;
            background: 
                radial-gradient(circle at 50% 50%, rgba(255,255,255,0.3) 0%, transparent 70%),
                linear-gradient(45deg, #ff6b6b, #4ecdc4),
                url('texture.png') repeat,
                #2c3e50;
            background-blend-mode: overlay, multiply, normal;
        }
        
        /* Parallax-style effect */
        .parallax {
            height: 600px;
            background: 
                url('clouds.png') 0 0 repeat-x,
                url('mountains.png') 0 bottom repeat-x,
                linear-gradient(180deg, #87ceeb 0%, #e0f6ff 100%);
            background-attachment: fixed, fixed, scroll;
        }
    </style>
</head>
<body>
    <div class="hero">
        <h1>Welcome</h1>
    </div>
    <div class="blended">Multiple Backgrounds with Blend Modes</div>
</body>
</html>
```

**Why**: Multiple backgrounds eliminate the need for wrapper divs, reducing DOM complexity. Each layer can have independent positioning, sizing, and repetition. The stacking order (first = top) mimics z-index behavior for natural composition.

## css_opacity

```html
<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>CSS Opacity</title>
    <style>
        /* PROBLEM: Control transparency of elements
           TIME: O(1) SPACE: O(1) */
        
        .parent {
            width: 300px;
            height: 200px;
            background: #3498db;
            padding: 20px;
        }
        
        /* Opacity affects entire element including children */
        .opacity-example {
            opacity: 0.5;  /* Range: 0.0 (invisible) to 1.0 (opaque) */
            background: #e74c3c;
            padding: 20px;
            color: white;
        }
        
        /* WARNING: Children inherit the opacity */
        .child {
            background: #2ecc71;
            opacity: 1;  /* Won't work - already affected by parent */
        }
        
        /* Better approach: use rgba for background only */
        .rgba-example {
            background: rgba(231, 76, 60, 0.5);  /* Only background is semi-transparent */
            padding: 20px;
            color: white;  /* Text remains fully opaque */
        }
        
        /* Animation with opacity */
        .fade-hover {
            width: 200px;
            height: 200px;
            background: #9b59b6;
            opacity: 1;
            transition: opacity 0.3s ease;
        }
        
        .fade-hover:hover {
            opacity: 0.3;
        }
        
        /* Visibility vs Opacity */
        .hidden-opacity {
            opacity: 0;
            pointer-events: none;  /* Prevents interaction */
        }
        
        .hidden-visibility {
            visibility: hidden;  /* Maintains layout space */
        }
    </style>
</head>
<body>
    <div class="parent">
        <div class="opacity-example">
            <p>Semi-transparent (affects text too)</p>
            <div class="child">Cannot override parent opacity</div>
        </div>
    </div>
    
    <div class="rgba-example">
        Only background is transparent
    </div>
    
    <div class="fade-hover">Hover to fade</div>
</body>
</html>
```

**Why**: Opacity provides simple transparency but affects all descendants. Use `rgba()` or `hsla()` colors when you need transparency only on backgrounds or borders. Opacity animations are performant (GPU-accelerated) and ideal for fade effects.

## css_rgba_transparency

```html
<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>CSS RGBA Transparency</title>
    <style>
        /* PROBLEM: Apply transparency to specific properties only
           TIME: O(1) SPACE: O(1) */
        
        .container {
            background: url('background.jpg') center/cover;
            padding: 40px;
        }
        
        /* RGBA format: rgba(red, green, blue, alpha)
           Alpha range: 0 (transparent) to 1 (opaque) */
        
        .card {
            /* Semi-transparent white background */
            background: rgba(255, 255, 255, 0.9);
            border: 2px solid rgba(0, 0, 0, 0.1);
            box-shadow: 0 4px 20px rgba(0, 0, 0, 0.15);
            padding: 30px;
            border-radius: 8px;
            color: #333;  /* Text is fully opaque */
        }
        
        /* Common transparency patterns */
        .overlay {
            background: rgba(0, 0, 0, 0.7);  /* Dark overlay */
            color: rgba(255, 255, 255, 0.9);  /* Slightly transparent text */
        }
        
        .highlight {
            background: rgba(255, 235, 59, 0.3);  /* Yellow highlight */
            border-left: 4px solid rgba(255, 193, 7, 1);
        }
        
        /* Hover with transition */
        .interactive {
            background: rgba(52, 152, 219, 0.5);
            transition: background 0.3s ease;
        }
        
        .interactive:hover {
            background: rgba(52, 152, 219, 0.9);  /* Darker on hover */
        }
        
        /* Gradient with transparency */
        .gradient-transparent {
            background: linear-gradient(
                180deg,
                rgba(255, 255, 255, 0) 0%,      /* Fully transparent */
                rgba(255, 255, 255, 0.8) 50%,   /* Semi-transparent */
                rgba(255, 255, 255, 1) 100%     /* Fully opaque */
            );
        }
    </style>
</head>
<body>
    <div class="container">
        <div class="card">
            <h2>RGBA Example</h2>
            <p>Background is transparent but text is solid.</p>
        </div>
    </div>
    
    <button class="interactive">Hover me</button>
</body>
</html>
```

**Why**: RGBA provides granular control over transparency per-property. Unlike `opacity`, it doesn't affect child elements. The alpha channel allows for sophisticated layering effects, glassmorphism, and modern UI designs with see-through elements.

## css_mix_blend_mode

```html
<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>CSS Mix Blend Mode</title>

        /* PROBLEM: Blend element colors with background
           TIME: O(1) SPACE: O(1) */
        
        .container {
            position: relative;
            width: 400px;
            height: 300px;
            background: linear-gradient(135deg, #667eea, #764ba2);
        }
        
        .blended {
            width: 200px;
            height: 200px;
            background: #ffffff;
            padding: 20px;
            
            /* Blend modes: normal, multiply, screen, overlay, darken, lighten,
               color-dodge, color-burn, hard-light, soft-light, difference,
               exclusion, hue, saturation, color, luminosity */
            mix-blend-mode: multiply;
        }
        
        /* Text blend effects */
        .text-blend {
            font-size: 80px;
            font-weight: bold;
            color: white;
            mix-blend-mode: screen;
        }
        
        /* Overlay effect */
        .overlay-multiply {
            position: absolute;
            top: 0;
            left: 0;
            width: 100%;
            height: 100%;
            background: rgba(0, 0, 0, 0.5);
            mix-blend-mode: multiply;
        }
        
        /* Comparison grid */
        .blend-grid {
            display: grid;
            grid-template-columns: repeat(4, 150px);
            gap: 10px;
        }
        
        .blend-item {
            height: 150px;
            background: #3498db;
            display: flex;
            align-items: center;
            justify-content: center;
        }
        
        .blend-item::after {
            content: '';
            width: 100px;
            height: 100px;
            background: #e74c3c;
            border-radius: 50%;
        }
        
        .blend-item.multiply::after { mix-blend-mode: multiply; }
        .blend-item.screen::after { mix-blend-mode: screen; }
        .blend-item.overlay::after { mix-blend-mode: overlay; }
        .blend-item.difference::after { mix-blend-mode: difference; }
    </style>
</head>
<body>
    <div class="container">
        <div class="blended">Multiplied content</div>
    </div>
    
    <h1 class="text-blend">Screened Text</h1>
    
    <div class="blend-grid">
        <div class="blend-item multiply"></div>
        <div class="blend-item screen"></div>
        <div class="blend-item overlay"></div>
        <div class="blend-item difference"></div>
    </div>
</body>
</html>
```

**Why**: Mix-blend-mode enables Photoshop-like compositing in CSS. It's perfect for creative effects, text treatments, and overlaying content on images/video. Unlike opacity, it creates interaction between overlapping colors for dynamic visual results.

## css_background_blend_mode

```html
<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>CSS Background Blend Mode</title>

        /* PROBLEM: Blend multiple background layers together
           TIME: O(1) SPACE: O(1) */
        
        /* Unlike mix-blend-mode (blends element with parent),
           background-blend-mode blends background layers within same element */
        
        .hero {
            width: 100%;
            height: 500px;
            
            /* Stack: gradient over image */
            background: 
                linear-gradient(180deg, rgba(0,0,0,0.8) 0%, transparent 100%),

            background-blend-mode: overlay;

                #3498db,  /* Color tint */

            background: 
                url('pattern.png') repeat,
                linear-gradient(45deg, #ff6b6b, #4ecdc4),
                url('texture.jpg') center/cover;

            background-blend-mode: soft-light, multiply;

        /* Vintage photo effect */
        .vintage {
            width: 300px;
            height: 300px;
            background: 
                rgba(222, 184, 135, 0.3),  /* Sepia overlay */
```

**Why**: Background-blend-mode is specifically for blending background layers without affecting child elements. It's ideal for image treatments, duotone effects, and creating textured backgrounds. Combines with gradients for infinite creative possibilities.

## css_border_shorthand

```html
<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>CSS Border Shorthand</title>
    <style>
        /* PROBLEM: Define borders concisely
           TIME: O(1) SPACE: O(1) */
        
        /* Shorthand syntax: border: [width] [style] [color]
           Order doesn't matter, but style is required */
        
        .basic {
            border: 1px solid #333;
        }
        
        .thick {
            border: 4px dashed #e74c3c;
        }
        
        .fancy {
            border: medium double #3498db;
        }
        
        /* Individual side shorthands */
        .sides {
            border-top: 3px solid #2ecc71;
            border-right: 2px dotted #e74c3c;
            border-bottom: 4px double #f39c12;
            border-left: 1px dashed #9b59b6;
        }
        
        /* Setting all, then overriding */
        .override {
            border: 2px solid #333;  /* All sides */
            border-bottom: none;      /* Remove bottom */
            /* OR */
            border-bottom-color: transparent;
        }
        
        /* Common patterns */
        .divider {
            border-bottom: 1px solid #eee;
        }
        
        .highlight {
            border-left: 4px solid #3498db;
            padding-left: 15px;
        }
        
        /* Border styles:
           none, hidden, dotted, dashed, solid, double, 
           groove, ridge, inset, outset */
        
        .styles-demo div {
            margin: 10px;
            padding: 10px;
            width: 200px;
        }
        
        .groove { border: 5px groove #999; }
        .ridge { border: 5px ridge #999; }
        .inset { border: 5px inset #999; }
        .outset { border: 5px outset #999; }
    </style>
</head>
<body>
    <div class="basic">Basic border</div>
    <div class="thick">Dashed border</div>
    <div class="sides">Different per side</div>
    <div class="highlight">Highlight border</div>

        <div class="groove">Groove</div>

        <div class="inset">Inset</div>
        <div class="outset">Outset</div>
    </div>
</body>
</html>
```

**Why**: Border shorthand reduces code from 3 properties to 1. Style is required (defaults vary by browser), while width defaults to medium and color defaults to currentColor. Individual side shorthands enable targeted styling without repeating all properties.

```html
            border-top-left-radius: 20px;

            border-bottom-right-radius: 20px;

```

**Why**: Border-radius shorthand follows TRBL clockwise pattern. The `/` separator allows independent horizontal/vertical radii for complex shapes. Percentage values create responsive curves. Combined with `overflow: hidden`, it clips content to rounded bounds.

## css_outline_vs_border

```html
<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>CSS Outline vs Border</title>
    <style>
        /* PROBLEM: Visual difference between outline and border
           TIME: O(1) SPACE: O(1) */
        
        .container {
            display: flex;
            gap: 30px;
        }
        
        /* BORDER:
           - Part of box model (affects layout)
           - Adds to element dimensions
           - Can have individual sides
           - Can be rounded with border-radius
        */
        .border-box {
            width: 150px;
            height: 150px;
            border: 5px solid #3498db;
            border-radius: 10px;
            /* Total size: 160px x 160px (border adds to dimensions) */
        }
        
        /* OUTLINE:
           - Outside box model (doesn't affect layout)
           - Overlays adjacent elements
           - All sides only (no individual sides)
           - Doesn't follow border-radius
        */
        .outline-box {
            width: 150px;
            height: 150px;
            outline: 5px solid #e74c3c;
            /* Total visual: 160px but layout remains 150px */
        }
        
        /* Focus states use outline (accessible) */
        .focusable:focus {
            outline: 3px solid #2ecc71;
            outline-offset: 2px;  /* Gap between element and outline */
        }
        
        /* Multiple borders effect */
        .multi-border {
            border: 3px solid #3498db;
            outline: 3px solid #2ecc71;
            outline-offset: 5px;  /* Creates gap */
        }
        
        /* Box-shadow alternative for rounded outline */
        .rounded-outline {
            border-radius: 20px;
            box-shadow: 0 0 0 5px #9b59b6;  /* Simulates outline */
        }
        
        /* When to use each:
           Border:  layout affects, rounded corners, individual sides
           Outline: focus states, debug visual, non-layout decorative borders
           Box-shadow: rounded "outline", multiple layered effects
        */
        
        /* Hidden outline for accessibility */
        .sr-only-focus:focus {
            outline: 2px solid currentColor;
            outline-offset: 2px;
        }
    </style>
</head>
<body>
    <div class="container">
        <div class="border-box">Border (affects layout)</div>
        <div class="outline-box">Outline (no layout impact)</div>
        <div class="multi-border">Both border + outline</div>
    </div>
    
    <button class="focusable">Tab to focus me</button>
    
    <div class="rounded-outline">Rounded "outline" with box-shadow</div>
</body>
</html>
```

**Why**: Outline doesn't affect layout, making it perfect for focus indicators and debugging. Border is part of the box model and affects element dimensions. Use box-shadow for rounded "outlines" since outline doesn't follow border-radius.

## html_input_step_validation

