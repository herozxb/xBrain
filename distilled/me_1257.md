## Selection Sort
```python
# PROBLEM: Sort an array by repeatedly finding the minimum element and placing it at the beginning
# TIME: O(n²) SPACE: O(1)
def selection_sort(arr):
    """
    Selection Sort Algorithm
    
    Strategy: Divide array into sorted and unsorted regions.
    Repeatedly select the smallest element from unsorted region
    and swap it to the end of sorted region.
    
    Advantages:
    - Simple implementation
    - In-place sorting (O(1) space)
    - Minimum number of swaps (at most n-1)
    
    Disadvantages:
    - O(n²) time complexity even for sorted array
    - Not stable (equal elements may change order)
    """
    n = len(arr)
    
    # Iterate through array, leaving last element (already sorted)
    for i in range(n - 1):
        # Assume current position holds minimum
        min_idx = i
        
        # Find actual minimum in unsorted region [i, n)
        for j in range(i + 1, n):
            if arr[j] < arr[min_idx]:
                min_idx = j
        
        # Swap minimum element to correct position
        if min_idx != i:
            arr[i], arr[min_idx] = arr[min_idx], arr[i]
    
    return arr
```
**Why**: Foundation for understanding comparison-based sorting; useful when swaps are expensive but comparisons are cheap.

## Bubble Sort
```python
# PROBLEM: Sort an array by repeatedly swapping adjacent elements if they are in wrong order
# TIME: O(n²) SPACE: O(1)
def bubble_sort(arr):
    """
    Bubble Sort Algorithm
    
    Strategy: Repeatedly step through the list, compare adjacent elements,
    and swap them if they are in wrong order. Larger elements "bubble up"
    to the end of the array with each pass.
    
    Advantages:
    - Simple to understand and implement
    - Stable sort (preserves order of equal elements)
    - Can detect already-sorted array (optimized version)
    
    Disadvantages:
    - O(n²) time complexity
    - Many unnecessary swaps compared to selection sort
    """
    n = len(arr)
    
    # Each pass bubbles largest unsorted element to end
    for i in range(n - 1):
        # Track if any swap occurred in this pass
        swapped = False
        
        # Compare adjacent pairs in unsorted region [0, n-i-1)
        for j in range(n - i - 1):
            # Swap if elements are in wrong order
            if arr[j] > arr[j + 1]:
                arr[j], arr[j + 1] = arr[j + 1], arr[j]
                swapped = True
        
        # If no swaps, array is already sorted (early termination)
        if not swapped:
            break
    
    return arr
```
**Why**: Demonstrates stable sorting and early termination optimization; educational for understanding sorting concepts.

## Floyd-Warshall Algorithm
```python
# PROBLEM: Find shortest paths between all pairs of vertices in a weighted graph
# TIME: O(V³) SPACE: O(V²)
def floyd_warshall(graph):
    """
    Floyd-Warshall Algorithm for All-Pairs Shortest Paths
    
    Strategy: Dynamic programming approach that gradually improves
    shortest path estimates by considering each vertex as an intermediate
    point. Works with negative edges (no negative cycles).
    
    Key insight: shortest path from i to j through vertex k is either:
    - The direct path i→j, or
    - The path i→k→j (composed of two shortest subpaths)
    
    Advantages:
    - Handles negative edge weights
    - Computes all pairs in one run
    - Simple implementation
    
    Disadvantages:
    - O(V³) time complexity
    - Not suitable for sparse graphs with many vertices
    """
    n = len(graph)
    
    # Initialize distance matrix with given graph
    # dist[i][j] = shortest distance from vertex i to vertex j
    dist = [[graph[i][j] for j in range(n)] for i in range(n)]
    
    # Try each vertex k as intermediate vertex
    for k in range(n):
        # Consider all pairs (i, j)
        for i in range(n):
            for j in range(n):
                # If vertex k is on shortest path from i to j,
                # update the distance
                if dist[i][k] != float('inf') and dist[k][j] != float('inf'):
                    dist[i][j] = min(dist[i][j], dist[i][k] + dist[k][j])
    
    return dist


def floyd_warshall_with_path(graph):
    """
    Floyd-Warshall with path reconstruction
    Returns both distance matrix and next vertex matrix for path reconstruction
    """
    n = len(graph)
    dist = [[graph[i][j] for j in range(n)] for i in range(n)]
    
    # next[i][j] stores the next vertex on path from i to j
    next_vertex = [[j if graph[i][j] != float('inf') else None 
                    for j in range(n)] for i in range(n)]
    
    for k in range(n):
        for i in range(n):
            for j in range(n):
                if dist[i][k] != float('inf') and dist[k][j] != float('inf'):
                    if dist[i][k] + dist[k][j] < dist[i][j]:
                        dist[i][j] = dist[i][k] + dist[k][j]
                        next_vertex[i][j] = next_vertex[i][k]
    
    return dist, next_vertex
```
**Why**: Essential for applications requiring all-pairs shortest paths (network routing, transitive closure, etc.).

## Circular Queue
```python
# PROBLEM: Implement a fixed-size queue using circular buffer for efficient space usage
# TIME: O(1) for enqueue/dequeue SPACE: O(n) for n elements
class CircularQueue:
    """
    Circular Queue (Ring Buffer) Implementation
    
    Strategy: Use a fixed-size array with circular indexing to reuse
    space freed by dequeued elements. Front and rear pointers wrap
    around when reaching array bounds.
    
    Advantages:
    - Constant time O(1) enqueue and dequeue
    - No need to shift elements
    - Efficient memory usage (reuses freed space)
    
    Use cases:
    - CPU scheduling
    - Memory management
    - Data buffering (audio/video streams)
    """
    
    def __init__(self, capacity):
        """Initialize circular queue with given capacity"""
        self.capacity = capacity
        self.queue = [None] * capacity
        self.front = 0  # Index of first element
        self.rear = -1  # Index of last element
        self.size = 0   # Current number of elements
    
    def enqueue(self, item):
        """Add item to rear of queue"""
        if self.is_full():
            raise OverflowError("Queue is full")
        
        # Move rear pointer circularly
        self.rear = (self.rear + 1) % self.capacity
        self.queue[self.rear] = item
        self.size += 1
    
    def dequeue(self):
        """Remove and return item from front of queue"""
        if self.is_empty():
            raise IndexError("Queue is empty")
        
        # Get front item
        item = self.queue[self.front]
        self.queue[self.front] = None  # Clear reference
        
        # Move front pointer circularly
        self.front = (self.front + 1) % self.capacity
        self.size -= 1
        
        return item
    
    def peek(self):
        """View front item without removing"""
        if self.is_empty():
            raise IndexError("Queue is empty")
        return self.queue[self.front]
    
    def is_empty(self):
        """Check if queue is empty"""
        return self.size == 0
    
    def is_full(self):
        """Check if queue is full"""
        return self.size == self.capacity
    
    def __len__(self):
        """Return current size of queue"""
        return self.size
    
    def __repr__(self):
        """String representation"""
        if self.is_empty():
            return "CircularQueue([])"
        
        items = []
        idx = self.front
        for _ in range(self.size):
            items.append(self.queue[idx])
            idx = (idx + 1) % self.capacity
        
        return f"CircularQueue({items})"
```
**Why**: Memory-efficient queue implementation ideal for streaming data and bounded buffer scenarios.

## Adapter Pattern
```python
# PROBLEM: Allow incompatible interfaces to work together without modifying their code
# TIME: O(1) SPACE: O(1)
class MediaPlayer:
    """Target interface that client expects"""
    
    def play_audio(self, filename):
        """Play audio file"""
        raise NotImplementedError


class MP3Player:
    """Adaptee: Existing class with incompatible interface"""
    
    def play_mp3(self, filename):
        """Plays MP3 files"""
        print(f"Playing MP3: {filename}")


class WAVPlayer:
    """Adaptee: Another existing class with incompatible interface"""
    
    def play_wav(self, filename):
        """Plays WAV files"""
        print(f"Playing WAV: {filename}")


class MP3Adapter(MediaPlayer):
    """
    Adapter: Makes MP3Player compatible with MediaPlayer interface
    
    Strategy: Wrap the adaptee and translate calls from target interface
    to adaptee's interface.
    """
    
    def __init__(self, mp3_player):
        self.mp3_player = mp3_player
    
    def play_audio(self, filename):
        """Adapts play_audio to play_mp3"""
        self.mp3_player.play_mp3(filename)


class WAVAdapter(MediaPlayer):
    """
    Adapter: Makes WAVPlayer compatible with MediaPlayer interface
    
    This is an object adapter (uses composition).
    Alternative: class adapter using multiple inheritance.
    """
    
    def __init__(self, wav_player):
        self.wav_player = wav_player
    
    def play_audio(self, filename):
        """Adapts play_audio to play_wav"""
        self.wav_player.play_wav(filename)


class AudioPlayer:
    """
    Client class that works with MediaPlayer interface
    Can play different formats through adapters
    """
    
    def __init__(self):
        self.players = {}
    
    def register_player(self, format_type, player):
        """Register a media player for a specific format"""
        self.players[format_type] = player
    
    def play(self, format_type, filename):
        """Play file using appropriate player"""
        if format_type not in self.players:
            print(f"Unsupported format: {format_type}")
            return
        
        # Client only knows about MediaPlayer interface
        # Adapters handle translation to specific players
        self.players[format_type].play_audio(filename)
```
**Why**: Enables code reuse and system integration without modifying existing code; follows Open/Closed Principle.

## Round Robin Load Balancer
```python
# PROBLEM: Distribute requests evenly across multiple servers using round-robin algorithm
# TIME: O(1) SPACE: O(n)
import itertools
from typing import List, Dict


class Server:
    """Represents a backend server"""
    
    def __init__(self, name: str, address: str):
        self.name = name
        self.address = address
        self.request_count = 0
    
    def handle_request(self, request_id: str):
        """Process incoming request"""
        self.request_count += 1
        print(f"Server {self.name} handling request {request_id}")


class RoundRobinLoadBalancer:
    """
    Round Robin Load Balancer
    
    Strategy: Distribute requests sequentially across servers in circular order.
    Each server gets requests in turn, ensuring even distribution.
    
    Advantages:
    - Simple implementation
    - Equal distribution (assuming equal server capacity)
    - Stateless - no need to track request history
    
    Disadvantages:
    - Doesn't consider server load or capacity
    - No health checking
    - Not optimal for heterogeneous server pools
    """
    
    def __init__(self):
        self.servers: List[Server] = []
        self.current_index = 0
    
    def add_server(self, server: Server):
        """Add server to pool"""
        self.servers.append(server)
    
    def remove_server(self, server_name: str):
        """Remove server from pool"""
        self.servers = [s for s in self.servers if s.name != server_name]
        # Adjust index if necessary
        if self.current_index >= len(self.servers):
            self.current_index = 0
    
    def get_next_server(self) -> Server:
        """Get next server using round-robin"""
        if not self.servers:
            raise RuntimeError("No servers available")
        
        # Get current server
        server = self.servers[self.current_index]
        
        # Move to next server (wrap around)
        self.current_index = (self.current_index + 1) % len(self.servers)
        
        return server
    
    def distribute_request(self, request_id: str):
        """Distribute request to next server"""
        server = self.get_next_server()
        server.handle_request(request_id)
        return server


class WeightedRoundRobinLoadBalancer:
    """
    Weighted Round Robin Load Balancer
    
    Strategy: Servers with higher weights receive more requests proportionally.
    Useful when servers have different capacities.
    
    Example:
    - Server A (weight=5): handles 5 requests per cycle
    - Server B (weight=3): handles 3 requests per cycle
    - Server C (weight=2): handles 2 requests per cycle
    """
    
    def __init__(self):
        self.servers: Dict[str, tuple] = {}  # name -> (server, weight)
        self.current_weights: Dict[str, int] = {}
        self.server_cycle = []  # Expanded list based on weights
        self.current_index = 0
    
    def add_server(self, server: Server, weight: int):
        """Add server with specified weight"""
        self.servers[server.name] = (server, weight)
        self._rebuild_cycle()
    
    def _rebuild_cycle(self):
        """Rebuild server cycle based on weights"""
        self.server_cycle = []
        for name, (server, weight) in self.servers.items():
            # Add server to cycle 'weight' times
            self.server_cycle.extend([server] * weight)
    
    def get_next_server(self) -> Server:
        """Get next server using weighted round-robin"""
        if not self.server_cycle:
            raise RuntimeError("No servers available")
        
        server = self.server_cycle[self.current_index]
        self.current_index = (self.current_index + 1) % len(self.server_cycle)
        
        return server
```
**Why**: Simple, effective load balancing for homogeneous server pools; foundation for more complex algorithms.

## MVCC (Multi-Version Concurrency Control)
```python
# PROBLEM: Allow concurrent read/write operations without blocking readers
# TIME: O(log n) for version lookup SPACE: O(n * v) where v is number of versions
import threading
import time
from typing import Dict, List, Optional
from dataclasses import dataclass
from collections import defaultdict


@dataclass
class Version:
    """Represents a version of a data item"""
    value: any
    timestamp: int
    created_by: int  # Transaction ID


class Transaction:
    """Represents a database transaction"""
    
    def __init__(self, txn_id: int):
        self.txn_id = txn_id
        self.start_time = time.time_ns()
        self.read_set: List[str] = []
        self.write_set: Dict[str, any] = {}
        self.is_committed = False
    
    def read(self, key: str):
        """Add key to read set"""
        if key not in self.read_set:
            self.read_set.append(key)
    
    def write(self, key: str, value: any):
        """Add key-value to write set"""
        self.write_set[key] = value


class MVCCStore:
    """
    Multi-Version Concurrency Control Implementation
    
    Strategy: Store multiple versions of each data item, each tagged with
    a timestamp. Readers access the latest committed version before their
    start time, while writers create new versions.
    
    Key Concepts:
    - Each write creates a new version (never overwrites)
    - Each version has a commit timestamp
    - Readers find version with largest timestamp <= reader's start time
    - Writers check for conflicts before committing
    
    Advantages:
    - Readers don't block writers
    - Writers don't block readers
    - Serializable isolation level
    - No lost updates
    
    Disadvantages:
    - Storage overhead for multiple versions
    - Need garbage collection for old versions
    - Write-write conflicts require rollback
    """
    
    def __init__(self):
        # key -> list of versions (sorted by timestamp)
        self.data: Dict[str, List[Version]] = defaultdict(list)
        self.lock = threading.RLock()
        self.next_txn_id = 1
    
    def begin_transaction(self) -> Transaction:
        """Start a new transaction"""
        with self.lock:
            txn = Transaction(self.next_txn_id)
            self.next_txn_id += 1
            return txn
    
    def read(self, txn: Transaction, key: str) -> Optional[any]:
        """
        Read value visible to transaction
        
        Returns latest committed version with timestamp <= txn.start_time
        """
        txn.read(key)
        
        with self.lock:
            versions = self.data.get(key, [])
            
            # Find latest version visible to this transaction
            visible_versions = [
                v for v in versions
                if v.timestamp <= txn.start_time and v.timestamp > 0
            ]
            
            if not visible_versions:
                return None
            
            # Return most recent visible version
            latest = max(visible_versions, key=lambda v: v.timestamp)
            return latest.value
    
    def write(self, txn: Transaction, key: str, value: any):
        """
        Stage a write operation
        
        Writes are buffered in transaction's write set until commit
        """
        txn.write(key, value)
    
    def commit(self, txn: Transaction) -> bool:
        """
        Commit transaction with MVCC validation
        
        Returns True if committed successfully, False if conflict detected
        """
        with self.lock:
            commit_time = time.time_ns()
            
            # Check for write-write conflicts
            # Conflict: another transaction committed writes to our write set
            # after we started
            for key in txn.write_set.keys():
                versions = self.data.get(key, [])
                
                # Check if any committed version has timestamp > our start time
                conflicting = [
                    v for v in versions
                    if v.timestamp > txn.start_time and v.timestamp > 0
                ]
                
                if conflicting:
                    # Write-write conflict detected
                    print(f"Transaction {txn.txn_id}: Conflict detected on key {key}")
                    return False
            
            # No conflicts - apply writes as new versions
            for key, value in txn.write_set.items():
                version = Version(
                    value=value,
                    timestamp=commit_time,
                    created_by=txn.txn_id
                )
                self.data[key].append(version)
            
            txn.is_committed = True
            print(f"Transaction {txn.txn_id}: Committed successfully")
            return True
    
    def rollback(self, txn: Transaction):
        """Rollback transaction (discard write set)"""
        print(f"Transaction {txn.txn_id}: Rolled back")
    
    def get_version_count(self, key: str) -> int:
        """Get number of versions for a key (for monitoring)"""
        return len(self.data.get(key, []))
    
    def garbage_collect(self, min_active_time: int):
        """
        Remove old versions that are no longer visible
        
        min_active_time: timestamp of oldest active transaction
        Versions with timestamp < min_active_time can be removed
        (except the most recent one)
        """
        with self.lock:
            for key in self.data:
                versions = self.data[key]
                if len(versions) <= 1:
                    continue
                
                # Keep only versions visible to oldest active transaction
                # plus the most recent version
                visible = [v for v in versions if v.timestamp >= min_active_time]
                if not visible and versions:
                    visible = [max(versions, key=lambda v: v.timestamp)]
                
                self.data[key] = visible
```
**Why**: Industry-standard for database concurrency control; enables high throughput with strong consistency guarantees.
