## [css_pseudo_class_nth_of_type]

```html
<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>nth-of-type Pseudo-class</title>
    <style>
        /* PROBLEM: Select elements based on their position among siblings of the same type
           TIME: O(1) SPACE: O(1) */
        
        /* Style every 2nd paragraph */
        p:nth-of-type(2) {
            background-color: #ffe0e0;
            padding: 10px;
        }
        
        /* Style odd-numbered list items */
        li:nth-of-type(odd) {
            color: #d32f2f;
        }
        
        /* Style every 3rd div starting from the first */
        .container div:nth-of-type(3n+1) {
            border-left: 4px solid #1976d2;
        }
    </style>
</head>
<body>
    <div class="container">
        <p>First paragraph - not styled by nth-of-type(2)</p>
        <p>Second paragraph - highlighted (nth-of-type(2))</p>
        <p>Third paragraph</p>
        <div>Div 1 - left border (3n+1)</div>
        <div>Div 2 - no border</div>
        <div>Div 3 - no border</div>
        <div>Div 4 - left border (3n+1)</div>
    </div>
    
    <ul>
        <li>Item 1 (odd - red)</li>
        <li>Item 2</li>
        <li>Item 3 (odd - red)</li>
        <li>Item 4</li>
    </ul>
</body>
</html>
```

**Why**: `nth-of-type()` enables pattern-based styling without adding classes. Useful for zebra-striping tables, alternating layouts, and creating visual rhythms in lists or grids without JavaScript.

## [css_margin_collapsing]

```html
<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>Margin Collapsing</title>
    <style>
        /* PROBLEM: Adjacent vertical margins collapse into the larger one
           TIME: O(1) SPACE: O(1) */
        
        .demo-section {
            border: 1px dashed #999;
            margin: 20px;
            padding: 10px;
        }
        
        /* Collapsing example: 30px margin, not 50px */
        .collapse-a {
            margin-bottom: 30px;
            background: #ffcdd2;
            padding: 10px;
        }
        
        .collapse-b {
            margin-top: 20px;
            background: #c8e6c9;
            padding: 10px;
        }
        
        /* Prevent collapse with overflow (creates BFC) */
        .no-collapse-wrapper {
            overflow: hidden;
            background: #e3f2fd;
        }
        
        .no-collapse-a {
            margin-bottom: 30px;
            background: #bbdefb;
            padding: 10px;
        }
        
        .no-collapse-b {
            margin-top: 20px;
            background: #90caf9;
            padding: 10px;
        }
        
        /* Parent-child collapse prevention */
        .parent {
            background: #fff3e0;
            padding-top: 1px; /* Prevents collapse */
        }
        
        .child {
            margin-top: 40px;
            background: #ffe0b2;
            padding: 10px;
        }
        
        /* Using flexbox prevents collapse */
        .flex-container {
            display: flex;
            flex-direction: column;
            background: #f3e5f5;
        }
    </style>
</head>
<body>
    <div class="demo-section">
        <h3>Collapsing Margins (30px gap, not 50px)</h3>
        <div class="collapse-a">Box A - margin-bottom: 30px</div>
        <div class="collapse-b">Box B - margin-top: 20px</div>
    </div>
    
    <div class="demo-section">
        <h3>Prevented with overflow:hidden</h3>
        <div class="no-collapse-wrapper">
            <div class="no-collapse-a">Box A - margin-bottom: 30px</div>
            <div class="no-collapse-b">Box B - margin-top: 20px (50px total)</div>
        </div>
    </div>
    
    <div class="demo-section">
        <h3>Parent with padding prevents collapse</h3>
        <div class="parent">
            <div class="child">Child with margin-top: 40px preserved</div>
        </div>
    </div>
</body>
</html>
```

**Why**: Understanding margin collapse prevents unexpected spacing bugs. Only vertical margins collapse between adjacent siblings or parent-child. Use BFC (overflow, display:flex/grid) or padding/borders to prevent it when needed.

## [js_template_literals_basic]

```html
<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>Template Literals (ES6)</title>
</head>
<body>
    <div id="output"></div>
    
    <script>
        // PROBLEM: Create strings with embedded expressions and multiline support
        // TIME: O(n) SPACE: O(n) where n is string length
        
        // Basic interpolation with ${}
        const name = 'Alice';
        const age = 28;
        const greeting = `Hello, ${name}! You are ${age} years old.`;
        console.log(greeting);
        // Output: "Hello, Alice! You are 28 years old."
        
        // Multiline strings (no \n needed)
        const poem = `
            Roses are red,
            Violets are blue,
            Template literals are great,
            And JavaScript too!
        `;
        console.log(poem);
        
        // Expressions inside ${}
        const a = 5;
        const b = 10;
        const math = `The sum of ${a} and ${b} is ${a + b}.`;
        console.log(math);
        // Output: "The sum of 5 and 10 is 15."
        
        // Function calls in template literals
        const toUpper = (str) => str.toUpperCase();
        const message = `Welcome, ${toUpper(name)}!`;
        console.log(message);
        // Output: "Welcome, ALICE!"
        
        // Ternary expressions
        const score = 85;
        const result = `You ${score >= 60 ? 'passed' : 'failed'} the exam.`;
        console.log(result);
        // Output: "You passed the exam."
        
        // Nested template literals
        const items = ['Apple', 'Banana', 'Orange'];
        const list = `
            <ul>
                ${items.map(item => `<li>${item}</li>`).join('\n                ')}
            </ul>
        `;
        console.log(list);
        
        // Escaping backticks
        const escaped = `Use backticks like this: \`\`\``;
        console.log(escaped);
        // Output: "Use backticks like this: ```"
        
        // Building HTML dynamically
        const users = [
            { name: 'Bob', role: 'Admin' },
            { name: 'Carol', role: 'User' },
            { name: 'Dave', role: 'User' }
        ];
        
        const userCards = users.map(user => `
            <div class="card">
                <h3>${user.name}</h3>
                <span class="badge">${user.role}</span>
            </div>
        `).join('');
        
        // Render to page
        document.getElementById('output').innerHTML = `
            <h2>Template Literals Demo</h2>
            <p>${greeting}</p>
            <pre>${poem}</pre>
            <p>${math}</p>
            <p>${message}</p>
            <p>${result}</p>
            ${list}
            ${userCards}
        `;
        
        // Comparison with string concatenation
        const oldWay = 'Hello, ' + name + '! You are ' + age + ' years old.';
        const newWay = `Hello, ${name}! You are ${age} years old.`;
        console.log('Both equal:', oldWay === newWay); // true
    </script>
    
    <style>
        .card {
            border: 1px solid #ddd;
            padding: 10px;
            margin: 5px;
            display: inline-block;
            border-radius: 4px;
        }
        .badge {
            background: #1976d2;
            color: white;
            padding: 2px 8px;
            border-radius: 12px;
            font-size: 0.8em;
        }
        ul { list-style: none; padding: 0; }
        li { padding: 5px; background: #f5f5f5; margin: 2px 0; }
        pre { background: #f5f5f5; padding: 10px; }
    </style>
</body>
</html>
```

**Why**: Template literals provide cleaner string interpolation, automatic multiline support, and expression embedding with `${}`. They replace messy string concatenation and make HTML generation readable. Use backticks (\`) instead of quotes.
