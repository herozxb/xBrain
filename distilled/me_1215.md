## [Maximum Sum Subarray (Kadane's Algorithm)]
```python
# PROBLEM: Find the maximum sum of any contiguous subarray in an array
# TIME: O(n) SPACE: O(1)
def max_subarray_sum(nums):
    """
    Kadane's algorithm: track the maximum sum ending at each position.
    At each step, decide whether to extend the previous subarray or start fresh.
    """
    if not nums:
        return 0
    
    max_sum = nums[0]      # Global maximum sum found
    current_sum = nums[0]  # Maximum sum ending at current position
    
    for i in range(1, len(nums)):
        # Either extend previous subarray or start new from current element
        current_sum = max(nums[i], current_sum + nums[i])
        # Update global maximum if current is better
        max_sum = max(max_sum, current_sum)
    
    return max_sum
```
**Why**: Classic sliding window pattern. Essential for subarray problems and the foundation for many DP solutions.

## [Container With Most Water]
```python
# PROBLEM: Find two lines that form a container holding the maximum water
# TIME: O(n) SPACE: O(1)
def max_area(height):
    """
    Two pointers approach: start from both ends, move the shorter line inward.
    Moving the taller line can only decrease area (width shrinks, height capped).
    Moving the shorter line might find a taller line and increase area.
    """
    left, right = 0, len(height) - 1
    max_water = 0
    
    while left < right:
        # Calculate current container area
        width = right - left
        container_height = min(height[left], height[right])
        max_water = max(max_water, width * container_height)
        
        # Move the shorter line pointer inward
        if height[left] < height[right]:
            left += 1
        else:
            right -= 1
    
    return max_water
```
**Why**: Demonstrates greedy two-pointer strategy. Key insight: eliminating suboptimal choices systematically.

## [Generate Permutations]
```python
# PROBLEM: Generate all possible permutations of an array
# TIME: O(n! × n) SPACE: O(n) for recursion depth
def permute(nums):
    """
    Backtracking: build permutations by choosing each unused element.
    Track used elements to avoid duplicates in the current path.
    """
    result = []
    
    def backtrack(path, used):
        # Base case: permutation complete
        if len(path) == len(nums):
            result.append(path[:])  # Copy current permutation
            return
        
        # Try each unused number
        for i in range(len(nums)):
            if used[i]:
                continue
            
            # Choose
            path.append(nums[i])
            used[i] = True
            
            # Explore
            backtrack(path, used)
            
            # Unchoose (backtrack)
            path.pop()
            used[i] = False
    
    backtrack([], [False] * len(nums))
    return result
```
**Why**: Fundamental backtracking template. Master this pattern for combinations, subsets, and constraint satisfaction problems.

## [Number of Connected Components]
```python
# PROBLEM: Count the number of connected components in an undirected graph
# TIME: O(n × α(n)) ≈ O(n) SPACE: O(n)
class UnionFind:
    def __init__(self, n):
        self.parent = list(range(n))
        self.rank = [0] * n
        self.components = n  # Track number of separate components
    
    def find(self, x):
        # Path compression: point directly to root
        if self.parent[x] != x:
            self.parent[x] = self.find(self.parent[x])
        return self.parent[x]
    
    def union(self, x, y):
        # Union by rank: attach smaller tree under larger
        px, py = self.find(x), self.find(y)
        if px == py:
            return  # Already connected
        
        if self.rank[px] < self.rank[py]:
            px, py = py, px
        self.parent[py] = px
        if self.rank[px] == self.rank[py]:
            self.rank[px] += 1
        
        self.components -= 1  # Merge reduces component count

def count_components(n, edges):
    """
    Union-Find: each edge potentially merges two components.
    Final component count is the answer.
    """
    uf = UnionFind(n)
    for u, v in edges:
        uf.union(u, v)
    return uf.components
```
**Why**: Union-Find is optimal for dynamic connectivity problems. Path compression + union by rank gives near-constant time operations.

## [Longest Increasing Subsequence]
```python
# PROBLEM: Find the length of the longest strictly increasing subsequence
# TIME: O(n log n) SPACE: O(n)
def length_of_lis(nums):
    """
    Patience sorting approach: maintain the smallest possible tail for each
    subsequence length. Binary search to find insertion position.
    """
    if not nums:
        return 0
    
    # tails[i] = smallest tail of all increasing subsequences of length i+1
    tails = []
    
    for num in nums:
        # Binary search for the first tail >= num
        left, right = 0, len(tails)
        while left < right:
            mid = (left + right) // 2
            if tails[mid] < num:
                left = mid + 1
            else:
                right = mid
        
        # If num is larger than all tails, extend the longest subsequence
        if left == len(tails):
            tails.append(num)
        else:
            # Replace tail to maintain smallest possible values
            tails[left] = num
    
    return len(tails)
```
**Why**: Shows how binary search optimizes DP from O(n²) to O(n log n). Essential pattern for sequence problems.

## [Dijkstra's Shortest Path]
```python
# PROBLEM: Find shortest paths from source to all vertices in weighted graph
# TIME: O((V + E) log V) SPACE: O(V)
import heapq

def dijkstra(graph, start, n):
    """
    Graph as adjacency list: {node: [(neighbor, weight), ...]}
    Use min-heap to always process the closest unvisited node.
    """
    distances = [float('inf')] * n
    distances[start] = 0
    
    # Priority queue: (distance, node)
    pq = [(0, start)]
    
    while pq:
        dist, node = heapq.heappop(pq)
        
        # Skip if we already found a shorter path
        if dist > distances[node]:
            continue
        
        # Explore neighbors
        for neighbor, weight in graph[node]:
            new_dist = distances[node] + weight
            if new_dist < distances[neighbor]:
                distances[neighbor] = new_dist
                heapq.heappush(pq, (new_dist, neighbor))
    
    return distances
```
**Why**: Fundamental graph algorithm. Heap-based approach is efficient for sparse graphs. Foundation for A* and other pathfinding.

## [Lowest Common Ancestor in Binary Tree]
```python
# PROBLEM: Find the lowest common ancestor of two nodes in a binary tree
# TIME: O(n) SPACE: O(h) where h is tree height
def lowest_common_ancestor(root, p, q):
    """
    Recursive approach: LCA is the node where p and q diverge to different
    subtrees, or where one is the ancestor of the other.
    """
    # Base case: reached end or found one of the targets
    if not root or root == p or root == q:
        return root
    
    # Search both subtrees
    left = lowest_common_ancestor(root.left, p, q)
    right = lowest_common_ancestor(root.right, p, q)
    
    # If both sides returned non-null, current node is LCA
    if left and right:
        return root
    
    # Otherwise, return the non-null side (or None if both null)
    return left if left else right
```
**Why**: Tree recursion pattern. Understanding how information bubbles up from subtrees is key to all tree problems.

```python
def merge_k_lists(lists):
    """

    Each of N nodes is pushed/popped from heap of size k.

    current = dummy

        current = current.next

```

## [Trie - Word Dictionary]
```python
# PROBLEM: Implement a word dictionary with add and search (supports '.' wildcard)
# TIME: O(m) for add, O(26^m) worst case for search with wildcards
# SPACE: O(alphabet_size × m × n) where m = average word length, n = words
class TrieNode:
    def __init__(self):
        self.children = {}  # char -> TrieNode
        self.is_word = False

class WordDictionary:
    def __init__(self):
        self.root = TrieNode()
    
    def add_word(self, word):
        """Insert word character by character into trie."""
        node = self.root
        for char in word:
            if char not in node.children:
                node.children[char] = TrieNode()
            node = node.children[char]
        node.is_word = True
    
    def search(self, word):
        """Search with support for '.' wildcard matching any character."""
        def search_in_node(word, node):
            for i, char in enumerate(word):
                if char == '.':
                    # Try all possible children for wildcard
                    for child in node.children.values():
                        if search_in_node(word[i+1:], child):
                            return True
                    return False  # No match found for this wildcard
                else:
                    if char not in node.children:
                        return False
                    node = node.children[char]
            return node.is_word
        
        return search_in_node(word, self.root)
```
**Why**: Trie is optimal for prefix-based operations and autocomplete. Wildcard search shows recursive trie traversal.

## [LRU Cache]
```python
# PROBLEM: Design a cache with O(1) get and put operations
# TIME: O(1) for both operations SPACE: O(capacity)
class Node:
    """Doubly linked list node for O(1) removal."""
    def __init__(self, key=0, val=0):
        self.key = key
        self.val = val
        self.prev = None
        self.next = None

class LRUCache:
    def __init__(self, capacity):
        self.capacity = capacity
        self.cache = {}  # key -> Node
        
        # Dummy head and tail for easier list manipulation
        self.head = Node()
        self.tail = Node()
        self.head.next = self.tail
        self.tail.prev = self.head
    
    def _remove(self, node):
        """Remove node from linked list."""
        node.prev.next = node.next
        node.next.prev = node.prev
    
    def _add_to_front(self, node):
        """Add node right after head (most recently used)."""
        node.prev = self.head
        node.next = self.head.next
        self.head.next.prev = node
        self.head.next = node
    
    def get(self, key):
        """Return value if exists, else -1. Move to front if found."""
        if key not in self.cache:
            return -1
        
        node = self.cache[key]
        # Move to front (mark as recently used)
        self._remove(node)
        self._add_to_front(node)
        return node.val
    
    def put(self, key, value):
        """Add/update key. Evict LRU if over capacity."""
        if key in self.cache:
            # Update existing node
            node = self.cache[key]
            node.val = value
            self._remove(node)
            self._add_to_front(node)
        else:
            # Add new node
            if len(self.cache) >= self.capacity:
                # Evict LRU (node before tail)
                lru = self.tail.prev
                self._remove(lru)
                del self.cache[lru.key]
            
            node = Node(key, value)
            self.cache[key] = node
            self._add_to_front(node)
```
**Why**: Combines hash map with doubly linked list for O(1) operations. Essential system design pattern for caching strategies.
