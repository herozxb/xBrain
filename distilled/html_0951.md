# JavaScript DOM Basics - Node Manipulation

## insertBefore
```html
<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>insertBefore Example</title>
</head>
<body>
    <ul id="myList">
        <li>Existing Item 1</li>
        <li>Existing Item 2</li>
    </ul>
    
    <script>
        // PROBLEM: Insert a new element before a specific existing element
        // TIME: O(1) SPACE: O(1)
        
        /**
         * Why: insertBefore allows precise placement of new nodes in the DOM tree
         * by specifying both the new node and the reference node before which it should be inserted.
         * Essential for maintaining specific order in lists, tables, or any ordered content.
         */
        
        // Get parent element
        const list = document.getElementById('myList');
        
        // Create new element to insert
        const newItem = document.createElement('li');
        newItem.textContent = 'New Inserted Item';
        
        // Get reference element (the one we want to insert before)
        const referenceItem = list.children[1]; // Second item
        
        // Insert new item before the reference item
        // Syntax: parentNode.insertBefore(newNode, referenceNode)
        list.insertBefore(newItem, referenceItem);
        
        // If referenceNode is null, inserts at the end (like appendChild)
        const anotherItem = document.createElement('li');
        anotherItem.textContent = 'Added at End';
        list.insertBefore(anotherItem, null);
        
        // Example with first child
        const firstItem = document.createElement('li');
        firstItem.textContent = 'New First Item';
        list.insertBefore(firstItem, list.firstChild);
    </script>
</body>
</html>
```

## removeChild
```html
<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>removeChild Example</title>
</head>
<body>
    <ul id="fruits">
        <li>Apple</li>
        <li id="banana">Banana</li>
        <li>Cherry</li>
    </ul>
    
    <script>
        // PROBLEM: Remove a specific child element from its parent
        // TIME: O(1) SPACE: O(1)
        
        /**
         * Why: removeChild is the standard DOM method for removing elements.
         * It returns the removed node, allowing for potential re-insertion elsewhere.
         * Must be called on the parent of the node to remove.
         */
        
        // Method 1: Remove by selecting parent and child
        const fruitList = document.getElementById('fruits');
        const banana = document.getElementById('banana');
        const removedNode = fruitList.removeChild(banana);
        
        console.log('Removed:', removedNode.textContent); // "Banana"
        
        // Method 2: Remove using parentNode property
        const apple = fruitList.firstElementChild;
        apple.parentNode.removeChild(apple);
        
        // Method 3: Remove all children
        function clearList(parent) {
            while (parent.firstChild) {
                parent.removeChild(parent.firstChild);
            }
        }
        
        // Note: Modern alternative - element.remove()
        // But removeChild is more widely supported and returns the node
    </script>
</body>
</html>
```

## replaceChild
```html
<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>replaceChild Example</title>
</head>
<body>
    <div id="container">
        <p id="old-paragraph">This is the old content.</p>
    </div>
    
    <script>
        // PROBLEM: Replace an existing child element with a new one
        // TIME: O(1) SPACE: O(1)
        
        /**
         * Why: replaceChild swaps an existing node with a new node in the DOM tree.
         * Useful for updating content, changing element types, or refreshing components.
         * Returns the replaced node in case you need to keep a reference.
         */
        
        const container = document.getElementById('container');
        const oldParagraph = document.getElementById('old-paragraph');
        
        // Create new element
        const newHeading = document.createElement('h2');
        newHeading.textContent = 'This is the new heading!';
        newHeading.style.color = 'blue';
        
        // Replace old paragraph with new heading
        const replacedNode = container.replaceChild(newHeading, oldParagraph);
        
        console.log('Replaced node:', replacedNode.textContent);
        
        // Example: Replace all paragraphs with divs
        function replaceParagraphsWithDivs(parent) {
            const paragraphs = parent.getElementsByTagName('p');
            
            // Convert to array since collection is live
            Array.from(paragraphs).forEach(p => {
                const div = document.createElement('div');
                div.innerHTML = p.innerHTML;
                div.className = 'converted-div';
                p.parentNode.replaceChild(div, p);
            });
        }
    </script>
</body>
</html>
```

## cloneNode
```html
<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>cloneNode Example</title>
</head>
<body>
    <div id="template" class="card">
        <h3>Template Title</h3>
        <p>Template content goes here.</p>
        <button>Action</button>
    </div>
    
    <div id="container"></div>
    
    <script>
        // PROBLEM: Create a copy of an existing DOM node
        // TIME: O(n) where n is descendants SPACE: O(n)
        
        /**
         * Why: cloneNode duplicates elements efficiently without manual recreation.
         * The deep parameter (true/false) determines if child nodes are also cloned.
         * Note: Event listeners and IDs are not cloned (IDs would create duplicates).
         */
        
        const template = document.getElementById('template');
        const container = document.getElementById('container');
        
        // Shallow clone (only the element itself, no children)
        const shallowClone = template.cloneNode(false);
        console.log(shallowClone.children.length); // 0
        
        // Deep clone (element + all descendants)
        const deepClone = template.cloneNode(true);
        
        // Important: Remove or change ID to avoid duplicates
        deepClone.removeAttribute('id');
        deepClone.classList.add('cloned-card');
        
        // Customize cloned content
        deepClone.querySelector('h3').textContent = 'Cloned Title';
        deepClone.querySelector('p').textContent = 'This is a cloned card.';
        
        // Add to container
        container.appendChild(deepClone);
        
        // Create multiple clones with variations
        const data = ['First', 'Second', 'Third'];
        data.forEach((text, index) => {
            const clone = template.cloneNode(true);
            clone.removeAttribute('id');
            clone.querySelector('h3').textContent = `${text} Card`;
            clone.querySelector('button').addEventListener('click', () => {
                alert(`Card ${index + 1} clicked!`);
            });
            container.appendChild(clone);
        });
    </script>
</body>
</html>
```

## hasChildNodes
```html
<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>hasChildNodes Example</title>
</head>
<body>
    <div id="empty"></div>
    <div id="withContent">
        <p>Some content</p>
    </div>
    <div id="withText">Text only</div>
    <div id="withWhitespace">  </div>
    
    <script>
        // PROBLEM: Check if an element contains any child nodes
        // TIME: O(1) SPACE: O(1)
        
        /**
         * Why: hasChildNodes quickly determines if an element has children,
         * including text nodes (whitespace counts). Useful for conditional
         * logic when manipulating the DOM.
         */
        
        const empty = document.getElementById('empty');
        const withContent = document.getElementById('withContent');
        const withText = document.getElementById('withText');
        const withWhitespace = document.getElementById('withWhitespace');
        
        console.log('Empty:', empty.hasChildNodes()); // false
        console.log('With content:', withContent.hasChildNodes()); // true
        console.log('With text:', withText.hasChildNodes()); // true
        console.log('With whitespace:', withWhitespace.hasChildNodes()); // true!
        
        // Practical example: Clear element only if it has children
        function safeClear(element) {
            if (element.hasChildNodes()) {
                console.log('Clearing element with children');
                while (element.firstChild) {
                    element.removeChild(element.firstChild);
                }
            } else {
                console.log('Element already empty');
            }
        }
        
        // Check before appending to avoid duplicates
        function appendOnce(parent, child) {
            if (!parent.hasChildNodes()) {
                parent.appendChild(child);
                return true;
            }
            
            // Check if child already exists
            const children = Array.from(parent.children);
            if (!children.includes(child)) {
                parent.appendChild(child);
                return true;
            }
            
            return false;
        }
        
        // Example: Toggle content
        function toggleContent(element) {
            if (element.hasChildNodes()) {
                element.innerHTML = '';
            } else {
                element.textContent = 'Content added';
            }
        }
    </script>
</body>
</html>
```

## parentNode
```html
<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>parentNode Example</title>
</head>
<body>
    <div id="grandparent">
        <div id="parent">
            <p id="child">Child element</p>
        </div>
    </div>
    
    <script>
        // PROBLEM: Access the parent node of an element
        // TIME: O(1) SPACE: O(1)
        
        /**
         * Why: parentNode traverses up the DOM tree to access the parent element.
         * Returns null if the node has no parent (root or detached).
         * Includes all node types (elements, text, comments).
         */
        
        const child = document.getElementById('child');
        const parent = child.parentNode;
        const grandparent = parent.parentNode;
        const body = grandparent.parentNode;
        const html = body.parentNode;
        const documentNode = html.parentNode; // Document node
        
        console.log('Parent:', parent.id); // "parent"
        console.log('Grandparent:', grandparent.id); // "grandparent"
        console.log('Document:', documentNode.nodeName); // "#document"
        
        // Practical example: Remove element's parent
        function removeParent(element) {
            const parent = element.parentNode;
            if (parent && parent.parentNode) {
                parent.parentNode.removeChild(parent);
            }
        }
        
        // Traverse up to find specific ancestor
        function findAncestor(element, tagName) {
            let current = element;
            while (current) {
                if (current.tagName === tagName.toUpperCase()) {
                    return current;
                }
                current = current.parentNode;
            }
            return null;
        }
        
        const div = findAncestor(child, 'DIV');
        console.log('Found ancestor DIV:', div.id);
        
        // Example: Highlight all ancestors
        function highlightAncestors(element) {
            let current = element.parentNode;
            while (current && current !== document) {
                if (current.style) {
                    current.style.outline = '2px solid red';
                }
                current = current.parentNode;
            }
        }
        
        highlightAncestors(child);
    </script>
</body>
</html>
```

## childNodes
```html
<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>childNodes Example</title>
</head>
<body>
    <div id="container">
        <p>First paragraph</p>
        Text node
        <p>Second paragraph</p>
        <!-- Comment -->
    </div>
    
    <script>
        // PROBLEM: Access all child nodes of an element (including text and comments)
        // TIME: O(1) to access, O(n) to iterate SPACE: O(1)
        
        /**
         * Why: childNodes returns a NodeList of ALL child nodes, not just elements.
         * Includes element nodes, text nodes (even whitespace), and comment nodes.
         * Use children property if you only want element nodes.
         */
        
        const container = document.getElementById('container');
        const allNodes = container.childNodes;
        
        console.log('Total child nodes:', allNodes.length);
        
        // Iterate through all nodes
        allNodes.forEach((node, index) => {
            console.log(`Node ${index}: ${node.nodeName}`, node);
            // Results:
            // Node 0: #text (whitespace)
            // Node 1: P (element)
            // Node 2: #text (whitespace + "Text node")
            // Node 3: P (element)
            // Node 4: #text (whitespace)
            // Node 5: #comment
            // Node 6: #text (whitespace)
        });
        
        // Filter only element nodes
        const elementNodes = Array.from(allNodes).filter(
            node => node.nodeType === Node.ELEMENT_NODE
        );
        console.log('Element nodes only:', elementNodes.length); // 2
        
        // Filter text nodes
        const textNodes = Array.from(allNodes).filter(
            node => node.nodeType === Node.TEXT_NODE
        );
        
        // Get text content from all text nodes
        const allText = textNodes.map(node => node.textContent.trim())
                                  .filter(text => text.length > 0)
                                  .join(' ');
        console.log('All text:', allText);
        
        // Practical example: Count different node types
        function countNodeTypes(element) {
            const counts = {
                elements: 0,
                text: 0,
                comments: 0,
                other: 0
            };
            
            element.childNodes.forEach(node => {
                switch(node.nodeType) {
                    case Node.ELEMENT_NODE:
                        counts.elements++;
                        break;
                    case Node.TEXT_NODE:
                        counts.text++;
                        break;
                    case Node.COMMENT_NODE:
                        counts.comments++;
                        break;
                    default:
                        counts.other++;
                }
            });
            
            return counts;
        }
        
        console.log(countNodeTypes(container));
    </script>
</body>
</html>
```

## firstChild
```html
<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>firstChild Example</title>
</head>
<body>
    <ul id="list">
        <li>First</li>
        <li>Second</li>
        <li>Third</li>
    </ul>
    
    <div id="empty"></div>
    
    <script>
        // PROBLEM: Access the first child node of an element
        // TIME: O(1) SPACE: O(1)
        
        /**
         * Why: firstChild returns the first node in the child list, which may be
         * a text node (whitespace). Use firstElementChild for first element only.
         * Returns null if no children exist.
         */
        
        const list = document.getElementById('list');
        const empty = document.getElementById('empty');
        
        // May be a text node (whitespace) before the first <li>
        let firstNode = list.firstChild;
        console.log('First node type:', firstNode.nodeName); // Could be #text
        
        // Skip text nodes to find first element
        function getFirstElement(parent) {
            let node = parent.firstChild;
            while (node && node.nodeType !== Node.ELEMENT_NODE) {
                node = node.nextSibling;
            }
            return node;
        }
        
        const firstElement = getFirstElement(list);
        console.log('First element:', firstElement.textContent);
        
        // Or use firstElementChild (modern approach)
        const firstLi = list.firstElementChild;
        console.log('First li:', firstLi.textContent); // "First"
        
        // Check if element is empty
        function isEmpty(element) {
            return element.firstChild === null;
        }
        
        console.log('List empty?', isEmpty(list)); // false
        console.log('Empty div?', isEmpty(empty)); // true
        
        // Practical example: Prepend new item
        function prependItem(list, text) {
            const newItem = document.createElement('li');
            newItem.textContent = text;
            
            // Insert at beginning
            if (list.firstChild) {
                list.insertBefore(newItem, list.firstChild);
            } else {
                list.appendChild(newItem);
            }
        }
        
        prependItem(list, 'New First');
        
        // Example: Get first text node content
        function getFirstTextContent(element) {
            let node = element.firstChild;
            while (node) {
                if (node.nodeType === Node.TEXT_NODE && node.textContent.trim()) {
                    return node.textContent.trim();
                }
                node = node.nextSibling;
            }
            return null;
        }
    </script>
</body>
</html>
```

## lastChild
```html
<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>lastChild Example</title>
</head>
<body>
    <ol id="steps">
        <li>Step One</li>
        <li>Step Two</li>
        <li>Step Three</li>
    </ol>
    
    <script>
        // PROBLEM: Access the last child node of an element
        // TIME: O(1) SPACE: O(1)
        
        /**
         * Why: lastChild returns the last node in the child list, which may be
         * a text node (whitespace). Use lastElementChild for last element only.
         * Useful for appending or manipulating the end of a list.
         */
        
        const steps = document.getElementById('steps');
        
        // May be a text node (whitespace) after the last <li>
        let lastNode = steps.lastChild;
        console.log('Last node type:', lastNode.nodeName);
        
        // Get last element node
        const lastElement = steps.lastElementChild;
        console.log('Last element:', lastElement.textContent); // "Step Three"
        
        // Skip text nodes to find last element
        function getLastElement(parent) {
            let node = parent.lastChild;
            while (node && node.nodeType !== Node.ELEMENT_NODE) {
                node = node.previousSibling;
            }
            return node;
        }
        
        // Practical example: Append new item
        function appendItem(list, text) {
            const newItem = document.createElement('li');
            newItem.textContent = text;
            
            // Insert before lastChild (which might be whitespace text node)
            if (list.lastChild && list.lastChild.nodeType === Node.TEXT_NODE) {
                list.insertBefore(newItem, list.lastChild);
            } else {
                list.appendChild(newItem);
            }
        }
        
        appendItem(steps, 'Step Four');
        
        // Example: Remove last item
        function removeLastItem(list) {
            const lastElement = list.lastElementChild;
            if (lastElement) {
                list.removeChild(lastElement);
                return true;
            }
            return false;
        }
        
        // Example: Update last item
        function updateLastItem(list, newText) {
            const last = list.lastElementChild;
            if (last) {
                last.textContent = newText;
                return true;
            }
            return false;
        }
        
        // Check if last child is a text node
        function hasTrailingWhitespace(element) {
            const last = element.lastChild;
            return last && 
                   last.nodeType === Node.TEXT_NODE && 
                   !last.textContent.trim();
        }
        
        console.log('Has trailing whitespace:', hasTrailingWhitespace(steps));
    </script>
</body>
</html>
```

## nextSibling
```html
<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>nextSibling Example</title>
</head>
<body>
    <table id="data-table">
        <tr>
            <td>Row 1, Cell 1</td>
            <td>Row 1, Cell 2</td>
            <td>Row 1, Cell 3</td>
        </tr>
        <tr>
            <td>Row 2, Cell 1</td>
            <td>Row 2, Cell 2</td>
            <td>Row 2, Cell 3</td>
        </tr>
    </table>
    
    <ul id="items">
        <li class="item">Item 1</li>
        <li class="item">Item 2</li>
        <li class="item">Item 3</li>
        <li class="item">Item 4</li>
    </ul>
    
    <script>
        // PROBLEM: Access the next sibling node in the DOM tree
        // TIME: O(1) SPACE: O(1)
        
        /**
         * Why: nextSibling traverses horizontally through the DOM at the same level.
         * Returns all node types including text nodes. Use nextElementSibling
         * for element nodes only. Essential for navigation and iteration.
         */
        
        const table = document.getElementById('data-table');
        const firstRow = table.rows[0];
        const firstCell = firstRow.cells[0];
        
        // Navigate through cells using nextSibling
        let currentCell = firstCell;
        while (currentCell) {
            console.log('Cell:', currentCell.textContent);
            currentCell = currentCell.nextSibling;
            // Note: This includes text nodes (whitespace)
        }
        
        // Navigate only through element nodes
        let currentElement = firstCell;
        while (currentElement) {
            console.log('Element:', currentElement.textContent);
            currentElement = currentElement.nextElementSibling;
        }
        
        // Practical example: Highlight next sibling on click
        const items = document.querySelectorAll('.item');
        items.forEach(item => {
            item.addEventListener('click', function() {
                // Reset all
                items.forEach(i => i.style.background = '');
                
                // Highlight current
                this.style.background = 'yellow';
                
                // Highlight next
                let next = this.nextElementSibling;
                if (next) {
                    next.style.background = 'lightgreen';
                }
            });
        });
        
        // Example: Get all following siblings
        function getAllNextSiblings(element) {
            const siblings = [];
            let current = element.nextSibling;
            
            while (current) {
                if (current.nodeType === Node.ELEMENT_NODE) {
                    siblings.push(current);
                }
                current = current.nextSibling;
            }
            
            return siblings;
        }
        
        // Example: Find next sibling with specific class
        function findNextSiblingWithClass(element, className) {
            let current = element.nextElementSibling;
            
            while (current) {
                if (current.classList.contains(className)) {
                    return current;
                }
                current = current.nextElementSibling;
            }
            
            return null;
        }
        
        // Example: Swap with next sibling
        function swapWithNext(element) {
            const next = element.nextElementSibling;
            if (next) {
                element.parentNode.insertBefore(next, element);
                return true;
            }
            return false;
        }
        
        // Example: Remove all following siblings
        function removeFollowingSiblings(element) {
            const parent = element.parentNode;
            while (element.nextSibling) {
                parent.removeChild(element.nextSibling);
            }
        }
    </script>
</body>
</html>
```

## Summary

These 10 DOM manipulation methods form the foundation of JavaScript DOM traversal and manipulation:

**Node Navigation:**
- `parentNode` - Move up the tree
- `childNodes` - Access all children
- `firstChild` / `lastChild` - Access ends of child list
- `nextSibling` - Move horizontally to next sibling

**Node Manipulation:**
- `insertBefore` - Insert at specific position
- `removeChild` - Remove specific child
- `replaceChild` - Swap nodes
- `cloneNode` - Duplicate nodes

**Node Inspection:**
- `hasChildNodes` - Check for children

**Key Differences:**
- `*Child` methods may return text nodes (whitespace)
- `*ElementChild` methods return only element nodes
- Most methods are O(1) except `cloneNode` with deep clone

**Best Practices:**
1. Use `*ElementChild` variants when you only need elements
2. Check for `null` before using returned nodes
3. Remember that `childNodes` includes text and comment nodes
4. Use `cloneNode(true)` for deep cloning
5. Remove IDs from cloned nodes to avoid duplicates
