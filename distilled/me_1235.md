## Insertion Sort

```python
# PROBLEM: Sort an array by building a sorted portion one element at a time
# TIME: O(n²) SPACE: O(1)
def insertion_sort(arr):
    """
    Insertion sort builds the final sorted array one item at a time.
    
    Algorithm:
    1. Start from the second element (index 1)
    2. Compare with elements in the sorted portion (left side)
    3. Shift larger elements to the right
    4. Insert the current element in its correct position
    
    Best for: Small datasets, nearly sorted arrays, online sorting
    """
    # Iterate through array starting from second element
    for i in range(1, len(arr)):
        # Store the current element to be inserted
        key = arr[i]
        # Initialize j to point to the element before i
        j = i - 1
        
        # Move elements greater than key one position ahead
        # This creates the correct position for key
        while j >= 0 and arr[j] > key:
            arr[j + 1] = arr[j]  # Shift element right
            j -= 1
        
        # Insert key at its correct position
        arr[j + 1] = key
    
    return arr

# Example usage
if __name__ == "__main__":
    data = [64, 34, 25, 12, 22, 11, 90]
    print(f"Original: {data}")
    print(f"Sorted: {insertion_sort(data.copy())}")
```

**Why**: Simple, stable, in-place sorting algorithm. Excellent for small or nearly-sorted datasets. Adaptive - runs in O(n) for already sorted arrays.

## Radix Sort

```python
# PROBLEM: Sort numbers digit by digit from least to most significant
# TIME: O(d * (n + k)) where d=digits, n=elements, k=radix SPACE: O(n + k)
def radix_sort(arr):
    """
    Radix sort processes digits from LSD to MSD using counting sort.
    
    Algorithm:
    1. Find the maximum number to determine digit count
    2. For each digit position (ones, tens, hundreds...):
       a. Count occurrences of each digit (0-9)
       b. Convert counts to positions
       c. Build output array placing elements at correct positions
    3. Repeat for all digit positions
    
    Best for: Integer sorting, fixed-length strings
    """
    if not arr:
        return arr
    
    # Handle negative numbers by separating them
    neg = [-x for x in arr if x < 0]
    pos = [x for x in arr if x >= 0]
    
    def counting_sort_by_digit(arr, exp):
        """Sort array based on digit at given exponent (1, 10, 100...)"""
        n = len(arr)
        output = [0] * n  # Output array
        count = [0] * 10  # Count array for digits 0-9
        
        # Count occurrences of each digit
        for num in arr:
            digit = (num // exp) % 10
            count[digit] += 1
        
        # Convert count to cumulative count (actual positions)
        for i in range(1, 10):
            count[i] += count[i - 1]
        
        # Build output array (traverse in reverse for stability)
        for i in range(n - 1, -1, -1):
            digit = (arr[i] // exp) % 10
            output[count[digit] - 1] = arr[i]
            count[digit] -= 1
        
        return output
    
    def radix_sort_positive(arr):
        """Sort non-negative numbers using radix sort"""
        if not arr:
            return arr
        
        # Find maximum to know number of digits
        max_num = max(arr)
        
        # Apply counting sort for each digit
        exp = 1  # Start with ones place
        while max_num // exp > 0:
            arr = counting_sort_by_digit(arr, exp)
            exp *= 10  # Move to next digit
        
        return arr
    
    # Sort positive and negative parts separately
    pos = radix_sort_positive(pos)
    neg = radix_sort_positive(neg)
    
    # Combine: reverse negative (since -5 > -10), then positive
    return [-x for x in reversed(neg)] + pos

# Example usage
if __name__ == "__main__":
    data = [170, 45, 75, 90, 802, 24, 2, 66, -5, -100]
    print(f"Original: {data}")
    print(f"Sorted: {radix_sort(data)}")
```

**Why**: Linear time complexity for fixed-width integers. Non-comparative sorting - bypasses O(n log n) lower bound by exploiting digit structure.

## Subset Sum (Dynamic Programming)

```python
# PROBLEM: Determine if there exists a subset that sums to target value
# TIME: O(n * target) SPACE: O(n * target) or O(target) optimized
def subset_sum(nums, target):
    """
    Find if there's a subset of nums that sums exactly to target.
    
    Approach: Dynamic Programming
    - dp[i][j] = True if subset of first i elements can sum to j
    - For each element, either include it or don't
    
    Recurrence:
    dp[i][j] = dp[i-1][j] or dp[i-1][j-nums[i-1]]
    
    Returns: (exists, subset) tuple
    """
    n = len(nums)
    
    # Handle edge cases
    if target == 0:
        return True, []
    if not nums:
        return False, []
    
    # Create DP table
    # dp[i][j] = True if sum j is possible with first i elements
    dp = [[False] * (target + 1) for _ in range(n + 1)]
    
    # Base case: sum 0 is always possible (empty subset)
    for i in range(n + 1):
        dp[i][0] = True
    
    # Fill the DP table
    for i in range(1, n + 1):
        for j in range(1, target + 1):
            # Don't include current element
            dp[i][j] = dp[i - 1][j]
            
            # Include current element if it doesn't exceed target
            if j >= nums[i - 1] and not dp[i][j]:
                dp[i][j] = dp[i - 1][j - nums[i - 1]]
    
    # If target is not achievable
    if not dp[n][target]:
        return False, []
    
    # Backtrack to find the actual subset
    subset = []
    i, j = n, target
    while i > 0 and j > 0:
        # If this element was included
        if not dp[i - 1][j]:
            subset.append(nums[i - 1])
            j -= nums[i - 1]
        i -= 1
    
    return True, subset

def subset_sum_optimized(nums, target):
    """
    Space-optimized version using 1D array.
    Only checks existence, doesn't track the subset.
    
    TIME: O(n * target) SPACE: O(target)
    """
    # dp[j] = True if sum j is achievable
    dp = [False] * (target + 1)
    dp[0] = True  # Empty subset sums to 0
    
    for num in nums:
        # Traverse in reverse to avoid using same element twice
        for j in range(target, num - 1, -1):
            dp[j] = dp[j] or dp[j - num]
    
    return dp[target]

# Example usage
if __name__ == "__main__":
    nums = [3, 34, 4, 12, 5, 2]
    target = 9
    
    exists, subset = subset_sum(nums, target)
    print(f"Array: {nums}")
    print(f"Target: {target}")
    print(f"Subset exists: {exists}")
    print(f"Subset: {subset} (sum = {sum(subset)})")
    print(f"Optimized check: {subset_sum_optimized(nums, target)}")
```

**Why**: Classic DP problem demonstrating state transition. Space optimization technique (reverse traversal) is widely applicable. Foundation for partition problems.

## Interval Tree

```python
# PROBLEM: Store intervals and efficiently find all intervals overlapping a point/range
# TIME: O(log n + k) for search where k=results, O(n log n) to build SPACE: O(n)
class IntervalTree:
    """
    An augmented BST for efficient interval operations.
    
    Each node stores:
    - interval: (low, high)
    - max: maximum high value in subtree (augmentation)
    
    This allows pruning: if point > node.max, no overlap in subtree.
    """
    
    class Node:
        def __init__(self, interval):
            self.interval = interval  # (low, high)
            self.max = interval[1]    # Max high in subtree
            self.left = None
            self.right = None
    
    def __init__(self):
        self.root = None
    
    def insert(self, interval):
        """Insert an interval into the tree"""
        self.root = self._insert(self.root, interval)
    
    def _insert(self, node, interval):
        """Recursively insert and update max values"""
        if node is None:
            return self.Node(interval)
        
        low, high = interval
        
        # Insert based on low value (BST property)
        if low < node.interval[0]:
            node.left = self._insert(node.left, interval)
        else:
            node.right = self._insert(node.right, interval)
        
        # Update max value for this subtree
        node.max = max(node.max, high)
        
        return node
    
    def overlap(self, point):
        """Find all intervals containing the given point"""
        results = []
        self._overlap_point(self.root, point, results)
        return results
    
    def _overlap_point(self, node, point, results):
        """Find all intervals containing point"""
        if node is None:
            return
        
        low, high = node.interval
        
        # If point is within this interval, add it
        if low <= point <= high:
            results.append(node.interval)
        
        # If left subtree might have overlapping intervals
        # (left.max >= point means some interval might contain point)
        if node.left and node.left.max >= point:
            self._overlap_point(node.left, point, results)
        
        # If right subtree might have overlapping intervals
        # (point >= low means we need to check right side too)
        if node.right and point >= low:
            self._overlap_point(node.right, point, results)
    
    def overlap_interval(self, query_interval):
        """Find all intervals overlapping with query interval"""
        results = []
        self._overlap_interval(self.root, query_interval, results)
        return results
    
    def _overlap_interval(self, node, query, results):
        """Find all intervals overlapping with query interval"""
        if node is None:
            return
        
        low, high = node.interval
        q_low, q_high = query
        
        # Check if intervals overlap
        # Overlap: not (high < q_low or low > q_high)
        if not (high < q_low or low > q_high):
            results.append(node.interval)
        
        # Check left subtree if it might have overlaps
        if node.left and node.left.max >= q_low:
            self._overlap_interval(node.left, query, results)
        
        # Check right subtree
        if node.right and q_high >= low:
            self._overlap_interval(node.right, query, results)

# Example usage
if __name__ == "__main__":
    tree = IntervalTree()
    intervals = [(15, 20), (10, 30), (17, 19), (5, 20), (12, 15), (30, 40)]
    
    for interval in intervals:
        tree.insert(interval)
    
    print(f"Intervals: {intervals}")
    print(f"Point 14 overlaps: {tree.overlap(14)}")
    print(f"Point 25 overlaps: {tree.overlap(25)}")
    print(f"Interval (14, 16) overlaps: {tree.overlap_interval((14, 16))}")
```

**Why**: Augmented data structure showing how to add info for efficient queries. Used in scheduling systems, computational geometry, and genomic analysis.

## Fibonacci Heap

```python
# PROBLEM: Priority queue with O(1) amortized insert and decrease-key
# TIME: Insert O(1), Delete-min O(log n), Decrease-key O(1) amortized SPACE: O(n)
class FibonacciHeap:
    """
    Fibonacci Heap: A priority queue with excellent amortized complexity.
    
    Structure:
    - Collection of heap-ordered trees (min-heap property)
    - Trees stored in circular doubly-linked list at root level
    - Marked nodes: lost a child since becoming child of another node
    
    Key operations amortized complexity:
    - insert: O(1)
    - find_min: O(1)
    - delete_min: O(log n)
    - decrease_key: O(1) - crucial for Dijkstra's algorithm!
    
    Why "Fibonacci": Number of trees is bounded by Fibonacci numbers
    """
    
    class Node:
        def __init__(self, key, value=None):
            self.key = key
            self.value = value
            self.parent = None
            self.child = None
            self.left = self    # Circular doubly-linked list
            self.right = self
            self.degree = 0     # Number of children
            self.mark = False   # Has this node lost a child?
    
    def __init__(self):
        self.min_node = None
        self.num_nodes = 0
    
    def insert(self, key, value=None):
        """Insert a new node - O(1)"""
        node = self.Node(key, value)
        
        if self.min_node is None:
            self.min_node = node
        else:
            # Add to root list
            self._add_to_root_list(node)
            # Update min if necessary
            if node.key < self.min_node.key:
                self.min_node = node
        
        self.num_nodes += 1
        return node
    
    def find_min(self):
        """Return minimum key - O(1)"""
        return self.min_node.key if self.min_node else None
    
    def delete_min(self):
        """Remove and return minimum node - O(log n) amortized"""
        z = self.min_node
        if z is not None:
            # Add all children to root list
            if z.child is not None:
                children = self._get_all_children(z.child)
                for child in children:
                    self._add_to_root_list(child)
                    child.parent = None
            
            # Remove z from root list
            self._remove_from_list(z)
            
            if z == z.right:
                # z was the only node
                self.min_node = None
            else:
                self.min_node = z.right
                self._consolidate()  # Rebuild heap structure
            
            self.num_nodes -= 1
        
        return z.key if z else None
    
    def decrease_key(self, node, new_key):
        """Decrease key of a node - O(1) amortized"""
        if new_key > node.key:
            raise ValueError("New key is greater than current key")
        
        node.key = new_key
        parent = node.parent
        
        # If heap property violated, cut and cascade
        if parent and node.key < parent.key:
            self._cut(node, parent)
            self._cascading_cut(parent)
        
        # Update min if necessary
        if node.key < self.min_node.key:
            self.min_node = node
    
    def _add_to_root_list(self, node):
        """Add node to the root level circular list"""
        if self.min_node is None:
            return
        
        # Insert node to the right of min_node
        node.right = self.min_node.right
        node.left = self.min_node
        self.min_node.right.left = node
        self.min_node.right = node
    
    def _remove_from_list(self, node):
        """Remove node from its circular list"""
        node.left.right = node.right
        node.right.left = node.left
    
    def _get_all_children(self, child):
        """Get all children in a node's child list"""
        children = []
        if child is None:
            return children
        
        current = child
        while True:
            children.append(current)
            current = current.right
            if current == child:
                break
        return children
    
    def _cut(self, node, parent):
        """Cut node from parent and add to root list"""
        # Remove from parent's child list
        if node.right != node:
            parent.child = node.right
            self._remove_from_list(node)
        else:
            parent.child = None
        
        parent.degree -= 1
        
        # Add to root list
        self._add_to_root_list(node)
        node.parent = None
        node.mark = False
    
    def _cascading_cut(self, node):
        """Recursively cut marked nodes up the tree"""
        parent = node.parent
        if parent:
            if not node.mark:
                node.mark = True
            else:
                self._cut(node, parent)
                self._cascading_cut(parent)
    
    def _consolidate(self):
        """Merge trees of same degree to maintain heap structure"""
        # Max degree is bounded by log_phi(n) where phi is golden ratio
        import math
        max_degree = int(math.log2(self.num_nodes)) + 1
        
        # Array to track trees by degree
        degree_to_tree = [None] * (max_degree + 1)
        
        # Get all root nodes
        roots = self._get_all_children(self.min_node)
        
        for root in roots:
            x = root
            degree = x.degree
            
            # Merge trees with same degree
            while degree_to_tree[degree] is not None:
                y = degree_to_tree[degree]
                
                # Ensure x has smaller key
                if x.key > y.key:
                    x, y = y, x
                
                # Make y a child of x
                self._link(y, x)
                
                degree_to_tree[degree] = None
                degree += 1
            
            degree_to_tree[degree] = x
        
        # Rebuild root list and find new min
        self.min_node = None
        for tree in degree_to_tree:
            if tree:
                if self.min_node is None or tree.key < self.min_node.key:
                    self.min_node = tree
    
    def _link(self, y, x):
        """Make y a child of x"""
        # Remove y from root list
        self._remove_from_list(y)
        
        # Add y as child of x
        if x.child is None:
            x.child = y
            y.right = y
            y.left = y
        else:
            y.right = x.child.right
            y.left = x.child
            x.child.right.left = y
            x.child.right = y
        
        y.parent = x
        x.degree += 1
        y.mark = False

# Example usage
if __name__ == "__main__":
    heap = FibonacciHeap()
    
    # Insert elements
    nodes = {}
    for key in [10, 5, 20, 3, 15, 8]:
        nodes[key] = heap.insert(key)
        print(f"Inserted {key}, min = {heap.find_min()}")
    
    # Delete minimums
    for _ in range(3):
        min_key = heap.delete_min()
        print(f"Deleted min: {min_key}, new min = {heap.find_min()}")
    
    # Decrease key
    heap.decrease_key(nodes[20], 1)
    print(f"Decreased 20 to 1, min = {heap.find_min()}")
```

**Why**: Theoretical foundation for optimal graph algorithms. Decrease-key O(1) makes Dijkstra run in O(V log V + E). Shows advanced pointer manipulation and amortized analysis.

## Iterator Pattern

```python
# PROBLEM: Provide a way to traverse elements without exposing underlying structure
# TIME: O(1) for next/has_next, O(n) for full traversal SPACE: O(1) or O(h) for trees
from collections.abc import Iterator, Iterable

class BinaryTreeIterator(Iterator):
    """
    Iterator pattern: Traverse a collection without exposing its structure.
    
    This example implements in-order traversal for a binary tree.
    Iterators decouple traversal logic from the data structure.
    """
    
    def __init__(self, root):
        self.stack = []
        self._push_left(root)
    
    def _push_left(self, node):
        """Push all left nodes onto stack"""
        while node:
            self.stack.append(node)
            node = node.left
    
    def __next__(self):
        """Return next element in sequence"""
        if not self.stack:
            raise StopIteration
        
        # Pop the top node
        node = self.stack.pop()
        
        # Push all left nodes of right subtree
        if node.right:
            self._push_left(node.right)
        
        return node.value
    
    def has_next(self):
        """Check if more elements exist"""
        return len(self.stack) > 0


class TreeNode:
    def __init__(self, value, left=None, right=None):
        self.value = value
        self.left = left
        self.right = right


class BinarySearchTree(Iterable):
    """
    A BST that supports iteration via the Iterator pattern.
    Implements Iterable to work with Python's for loops.
    """
    
    def __init__(self):
        self.root = None
    
    def insert(self, value):
        """Insert a value into the BST"""
        if self.root is None:
            self.root = TreeNode(value)
        else:
            self._insert(self.root, value)
    
    def _insert(self, node, value):
        if value < node.value:
            if node.left is None:
                node.left = TreeNode(value)
            else:
                self._insert(node.left, value)
        else:
            if node.right is None:
                node.right = TreeNode(value)
            else:
                self._insert(node.right, value)
    
    def __iter__(self):
        """Return an iterator for in-order traversal"""
        return BinaryTreeIterator(self.root)
    
    def inorder(self):
        """Generator version - simpler but same result"""
        def _inorder(node):
            if node:
                yield from _inorder(node.left)
                yield node.value
                yield from _inorder(node.right)
        return _inorder(self.root)
    
    def preorder(self):
        """Pre-order traversal iterator"""
        def _preorder(node):
            if node:
                yield node.value
                yield from _preorder(node.left)
                yield from _preorder(node.right)
        return _preorder(self.root)
    
    def postorder(self):
        """Post-order traversal iterator"""
        def _postorder(node):
            if node:
                yield from _postorder(node.left)
                yield from _postorder(node.right)
                yield node.value
        return _postorder(self.root)
    
    def bfs(self):
        """Breadth-first (level-order) traversal iterator"""
        from collections import deque
        
        if not self.root:
            return
        
        queue = deque([self.root])
        while queue:
            node = queue.popleft()
            yield node.value
            if node.left:
                queue.append(node.left)
            if node.right:
                queue.append(node.right)


# Example usage
if __name__ == "__main__":
    # Build a BST
    bst = BinarySearchTree()
    for val in [5, 3, 7, 1, 4, 6, 9]:
        bst.insert(val)
    
    print("Using Iterator class:")
    for val in bst:
        print(val, end=" ")
    print()
    
    print("\nUsing generator methods:")
    print(f"In-order:   {list(bst.inorder())}")
    print(f"Pre-order:  {list(bst.preorder())}")
    print(f"Post-order: {list(bst.postorder())}")
    print(f"BFS:        {list(bst.bfs())}")
```

**Why**: Separates traversal from data structure. Python's generator functions make this pattern elegant. Essential for lazy evaluation and memory-efficient processing.

## Metaclasses

```python
# PROBLEM: Control class creation, enforce patterns, or inject behavior automatically
# TIME: O(1) runtime overhead (class creation is one-time) SPACE: O(1) per class
class SingletonMeta(type):
    """
    A metaclass that implements the Singleton pattern.
    
    Metaclasses control class creation - they are "classes for classes".
    Use cases:
    - Enforce coding patterns (Singleton, Abstract Factory)
    - Automatic method registration
    - Validation at class definition time
    - ORM implementation (like Django models)
    """
    
    _instances = {}
    
    def __call__(cls, *args, **kwargs):
        """Control instance creation"""
        if cls not in cls._instances:
            # Create new instance only if doesn't exist
            cls._instances[cls] = super().__call__(*args, **kwargs)
        return cls._instances[cls]


class Database(metaclass=SingletonMeta):
    """Singleton database connection - only one instance ever exists"""
    
    def __init__(self):
        self.connected = False
        print("Database initialized")
    
    def connect(self):
        self.connected = True
        print("Connected to database")
    
    def query(self, sql):
        if not self.connected:
            raise RuntimeError("Not connected")
        return f"Result of: {sql}"


class RegisteredMethodMeta(type):
    """
    Metaclass that automatically registers methods decorated with @register.
    Useful for command patterns, plugins, API routing.
    """
    
    def __new__(mcs, name, bases, namespace):
        # Create the class first
        cls = super().__new__(mcs, name, bases, namespace)
        
        # Initialize registry on the class
        cls._method_registry = {}
        
        # Find and register decorated methods
        for attr_name, attr_value in namespace.items():
            if callable(attr_value) and hasattr(attr_value, '_registered_name'):
                registered_name = attr_value._registered_name
                cls._method_registry[registered_name] = attr_name
        
        return cls


def register(name):
    """Decorator to mark methods for registration"""
    def decorator(func):
        func._registered_name = name
        return func
    return decorator


class CommandProcessor(metaclass=RegisteredMethodMeta):
    """Command processor with auto-registered commands"""
    
    @register("save")
    def save_command(self, data):
        return f"Saved: {data}"
    
    @register("load")
    def load_command(self, filename):
        return f"Loaded: {filename}"
    
    @register("delete")
    def delete_command(self, item_id):
        return f"Deleted: {item_id}"
    
    def execute(self, command_name, *args, **kwargs):
        """Execute a command by its registered name"""
        if command_name not in self._method_registry:
            raise ValueError(f"Unknown command: {command_name}")
        
        method_name = self._method_registry[command_name]
        method = getattr(self, method_name)
        return method(*args, **kwargs)
    
    def list_commands(self):
        """List all available commands"""
        return list(self._method_registry.keys())

    """Base class with validated requirements"""
    
    class Meta:
        required_methods = ['process', 'validate']
    
    def process(self, data):
        raise NotImplementedError
    
    def validate(self, data):
        raise NotImplementedError


class UserService(BaseService):
    """Valid service - implements required methods"""
    
    def process(self, data):
        return f"Processing user: {data}"
    
    def validate(self, data):
        return isinstance(data, dict) and 'user_id' in data


# Example usage
if __name__ == "__main__":
    # Singleton example
    print("=== Singleton Pattern ===")
    db1 = Database()
    db2 = Database()
    print(f"Same instance? {db1 is db2}")  # True
    
    # Registered methods example
    print("\n=== Method Registration ===")
    processor = CommandProcessor()
    print(f"Available commands: {processor.list_commands()}")
    print(processor.execute("save", {"name": "test"}))
    print(processor.execute("load", "data.json"))
    
    # Validation example
    print("\n=== Validated Class ===")
    service = UserService()
    print(f"Validates user: {service.validate({'user_id': 123})}")
    print(service.process({'user_id': 123}))
```

**Why**: Metaclasses are Python's most powerful customization hook. Understanding them explains frameworks (Django, SQLAlchemy) and enables metaprogramming. Use sparingly - often a sign of over-engineering.

## Summary

| Algorithm/Structure | Time Complexity | Space | Key Insight |
|---------------------|-----------------|-------|-------------|
| Insertion Sort | O(n²) | O(1) | Simple, adaptive, stable |
| Radix Sort | O(d·n) | O(n+k) | Non-comparative, linear time |
| Subset Sum | O(n·target) | O(target) | Classic DP, subset recovery |
| Interval Tree | O(log n + k) | O(n) | Augmented BST for queries |
| Fibonacci Heap | O(1)* amortized | O(n) | Optimal for graph algorithms |
| Iterator Pattern | O(1) per op | O(h) | Decouples traversal from structure |
| Metaclasses | O(1) overhead | O(1) | Controls class creation |

*decrease-key and insert are O(1) amortized; delete-min is O(log n)
