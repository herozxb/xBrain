# Python3 - Functions

## Defining Functions
```python
# PROBLEM: Create reusable code blocks
# APPROACH: Use def keyword to define functions
# TIME: O(1) call overhead SPACE: O(n) for local scope

# Basic function
def greet():
    print("Hello!")

# With parameters
def greet_person(name):
    print(f"Hello, {name}!")

# With return value
def add(a, b):
    return a + b

# Multiple return values
def get_stats(numbers):
    return min(numbers), max(numbers), sum(numbers)

min_val, max_val, total = get_stats([1, 2, 3, 4, 5])

# Docstring
def calculate_area(radius):
    """
    Calculate the area of a circle.
    
    Args:
        radius: The radius of the circle
    
    Returns:
        The area as a float
    """
    import math
    return math.pi * radius ** 2
```

**Explanation**: Functions are defined with def. Use docstrings for documentation.

## Arguments and Parameters
```python
# PROBLEM: Pass different types of arguments
# APPROACH: Use positional, keyword, default, *args, **kwargs
# TIME: O(1) SPACE: O(n)

# Default parameters
def greet(name, greeting="Hello"):
    print(f"{greeting}, {name}!")

greet("Alice")              # Hello, Alice!
greet("Bob", "Hi")          # Hi, Bob!

# Keyword arguments
def create_profile(name, age, city):
    return {"name": name, "age": age, "city": city}

profile = create_profile(city="NYC", name="Alice", age=30)

# *args - variable positional arguments
def sum_all(*args):
    return sum(args)

total = sum_all(1, 2, 3, 4, 5)  # 15

# **kwargs - variable keyword arguments
def print_info(**kwargs):
    for key, value in kwargs.items():
        print(f"{key}: {value}")

print_info(name="Alice", age=30, city="NYC")

# Combining all
def function(pos1, pos2, *args, default1="val", **kwargs):
    pass
```

**Explanation**: Python supports positional, keyword, default, *args and **kwargs arguments.

## Lambda Functions
```python
# PROBLEM: Create anonymous functions
# APPROACH: Use lambda keyword
# TIME: O(1) SPACE: O(1)

# Basic lambda
square = lambda x: x ** 2
result = square(5)  # 25

# Multiple parameters
add = lambda a, b: a + b
sum_result = add(3, 4)  # 7

# With conditional
is_even = lambda x: x % 2 == 0

# Sorting with lambda
pairs = [(1, 'one'), (3, 'three'), (2, 'two')]
sorted_pairs = sorted(pairs, key=lambda x: x[0])

# Map with lambda
numbers = [1, 2, 3, 4, 5]
squared = list(map(lambda x: x**2, numbers))

# Filter with lambda
evens = list(filter(lambda x: x % 2 == 0, numbers))

# Reduce with lambda
from functools import reduce
product = reduce(lambda a, b: a * b, numbers)
```

**Explanation**: Lambda creates anonymous functions for short, one-time use operations.

## Higher-Order Functions
```python
# PROBLEM: Process data functionally
# APPROACH: Use map, filter, reduce
# TIME: O(n) SPACE: O(n)

# Map - transform each element
numbers = [1, 2, 3, 4, 5]
doubled = list(map(lambda x: x * 2, numbers))
# [2, 4, 6, 8, 10]

# Filter - select elements
evens = list(filter(lambda x: x % 2 == 0, numbers))
# [2, 4]

# Reduce - combine elements
from functools import reduce
total = reduce(lambda a, b: a + b, numbers, 0)
# 15

# Chaining operations
result = (numbers
    |> map(lambda x: x * 2)
    |> filter(lambda x: x > 5)
    |> list)

# Custom higher-order function
def apply_operation(func, *args):
    return func(*args)

result = apply_operation(lambda a, b: a + b, 3, 4)

# Function returning function
def multiplier(n):
    return lambda x: x * n

double = multiplier(2)
triple = multiplier(3)
double(5)  # 10
```

**Explanation**: Higher-order functions take or return functions. map/filter/reduce are common examples.
