## Binary Search
```python
# PROBLEM: Find target in sorted array
# APPROACH: Divide and conquer
# TIME: O(log n) SPACE: O(1)

def binary_search(arr, target):
    """Find target in sorted array using binary search."""
    left, right = 0, len(arr) - 1
    while left <= right:
        mid = (left + right) // 2
        if arr[mid] == target:
            return mid
        elif arr[mid] < target:
            left = mid + 1
        else:
            right = mid - 1
    return -1
```

**Explanation**: Binary search halves the search space each iteration.

## Two Sum
```python
# PROBLEM: Find indices of two numbers that sum to target
# APPROACH: Hash map for O(1) lookups
# TIME: O(n) SPACE: O(n)

def two_sum(nums, target):
    """Find two indices whose values sum to target."""
    seen = {}
    for i, num in enumerate(nums):
        complement = target - num
        if complement in seen:
            return [seen[complement], i]
        seen[num] = i
    return []
```

**Explanation**: Use hash map to find complement in O(1) time.

## Maximum Subarray
```python
# PROBLEM: Find contiguous subarray with largest sum
# APPROACH: Kadane's algorithm
# TIME: O(n) SPACE: O(1)

def max_subarray(nums):
    """Find maximum sum of contiguous subarray."""
    max_sum = curr_sum = nums[0]
    for num in nums[1:]:
        curr_sum = max(num, curr_sum + num)
        max_sum = max(max_sum, curr_sum)
    return max_sum
```

**Explanation**: Track current and maximum sums as we iterate.

## Valid Parentheses
```python
# PROBLEM: Check if brackets are balanced
# APPROACH: Stack-based matching
# TIME: O(n) SPACE: O(n)

def is_valid(s):
    """Check if parentheses string is valid."""
    stack = []
    pairs = {')': '(', '}': '{', ']': '['}
    for char in s:
        if char in pairs.values():
            stack.append(char)
        elif char in pairs:
            if not stack or stack.pop() != pairs[char]:
                return False
    return len(stack) == 0
```

**Explanation**: Push opening brackets, pop and match closing brackets.

## Reverse Linked List
```python
# PROBLEM: Reverse a singly linked list
# APPROACH: Iterative pointer manipulation
# TIME: O(n) SPACE: O(1)

def reverse_list(head):
    """Reverse linked list in place."""
    prev = None
    curr = head
    while curr:
        next_temp = curr.next
        curr.next = prev
        prev = curr
        curr = next_temp
    return prev
```

**Explanation**: Reverse pointers one at a time while traversing.

## Merge Two Sorted Lists
```python
# PROBLEM: Merge two sorted linked lists
# APPROACH: Two-pointer merge
# TIME: O(n+m) SPACE: O(1)

def merge_lists(l1, l2):
    """Merge two sorted linked lists."""
    dummy = ListNode(0)
    curr = dummy
    while l1 and l2:
        if l1.val <= l2.val:
            curr.next = l1
            l1 = l1.next
        else:
            curr.next = l2
            l2 = l2.next
        curr = curr.next
    curr.next = l1 or l2
    return dummy.next
```

**Explanation**: Compare heads and link the smaller one.

## Best Time to Buy/Sell Stock
```python
# PROBLEM: Maximum profit from one transaction
# APPROACH: Track minimum price
# TIME: O(n) SPACE: O(1)

def max_profit(prices):
    """Find maximum profit from stock prices."""
    min_price = float('inf')
    max_profit = 0
    for price in prices:
        min_price = min(min_price, price)
        max_profit = max(max_profit, price - min_price)
    return max_profit
```

**Explanation**: Track minimum price and calculate max profit.

## Contains Duplicate
```python
# PROBLEM: Check if array has duplicates
# APPROACH: Hash set
# TIME: O(n) SPACE: O(n)

def contains_duplicate(nums):
    """Check if any value appears twice."""
    seen = set()
    for num in nums:
        if num in seen:
            return True
        seen.add(num)
    return False
```

**Explanation**: Use set to detect duplicates in O(1) time.

## Maximum Depth of Binary Tree
```python
# PROBLEM: Find tree depth
# APPROACH: Recursive DFS
# TIME: O(n) SPACE: O(h)

def max_depth(root):
    """Find maximum depth of binary tree."""
    if not root:
        return 0
    return 1 + max(max_depth(root.left), max_depth(root.right))
```

**Explanation**: Recursively find max depth of subtrees.

## Climbing Stairs
```python
# PROBLEM: Number of ways to climb n stairs
# APPROACH: Dynamic programming
# TIME: O(n) SPACE: O(1)

def climb_stairs(n):
    """Count ways to climb n stairs (1 or 2 steps)."""
    if n <= 2:
        return n
    prev, curr = 1, 2
    for _ in range(3, n + 1):
        prev, curr = curr, prev + curr
    return curr
```

**Explanation**: Each step = sum of previous two ways (Fibonacci).
