```html
            padding: 20px;
        }

            color: white;

        <p>Paragraph 3 (selected)</p>
        <span>Span (not selected - wrong type)</span>
        <p>Paragraph 4 (selected)</p>
    </div>
</body>
</html>
```

**Why**: The general sibling combinator (`~`) selects all matching siblings after a specific element, useful for conditional styling.

```html

    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>CSS Selector Grouping</title>
    <style>
        /* PROBLEM: Apply same styles to multiple selectors
           TIME: O(1) SPACE: O(1) */
        
        /* Group selectors with comma */
        h1, h2, h3 {
            color: #2c3e50;
            font-family: Arial, sans-serif;
        }
        
        /* Group class selectors */
        .highlight, .emphasis, .important {
            background: #f1c40f;
            padding: 5px 10px;
            font-weight: bold;
        }
        
        /* Group attribute selectors */
        [type="text"], [type="email"], [type="password"] {
            border: 2px solid #3498db;
            padding: 10px;
            margin: 5px;
            border-radius: 4px;
        }
        
        /* Mixed grouping */

            color: #e74c3c;
            font-weight: bold;
        }
    </style>
</head>
<body>
    <h1>Heading 1</h1>
    <h2>Heading 2</h2>
    <h3>Heading 3</h3>
    
    <p class="highlight">Highlighted text</p>

    <p class="important">Important text</p>
    
    <input type="text" placeholder="Text input">
    <input type="email" placeholder="Email input">
    <input type="password" placeholder="Password input">
    
    <p class="error">Error class</p>
    <p id="errorMessage">Error ID</p>
    <p data-status="failed">Data status failed</p>
</body>
</html>
```

**Why**: Grouping selectors with commas reduces code duplication and maintains consistent styling across multiple elements.
