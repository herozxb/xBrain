## Manacher's Algorithm

```python
# PROBLEM: Find the longest palindromic substring in O(n) time
# TIME: O(n) SPACE: O(n)
def manacher_longest_palindrome(s: str) -> str:
    """
    Manacher's Algorithm: Linear time longest palindromic substring finder.
    Uses transformed string with separators to handle even-length palindromes.
    """
    if not s:
        return ""
    
    # Transform: "abc" -> "^#a#b#c#$" 
    # ^ and $ are sentinels to avoid bounds checking
    transformed = '^#' + '#'.join(s) + '#$'
    n = len(transformed)
    p = [0] * n  # p[i] = radius of palindrome centered at i
    center = right = 0  # Current center and right boundary
    
    for i in range(1, n - 1):
        # Mirror index: symmetric to i about center
        mirror = 2 * center - i
        
        # If i is within current right boundary, use mirror's value
        if i < right:
            p[i] = min(right - i, p[mirror])
        
        # Attempt to expand palindrome centered at i
        while transformed[i + p[i] + 1] == transformed[i - p[i] - 1]:
            p[i] += 1
        
        # Update center and right boundary if expanded palindrome extends beyond right
        if i + p[i] > right:
            center = i
            right = i + p[i]
    
    # Find the maximum radius and its center
    max_len = max(p)
    center_idx = p.index(max_len)
    
    # Convert back to original string indices
    start = (center_idx - max_len) // 2
    return s[start:start + max_len]
```
**Why**: Only linear-time algorithm for longest palindromic substring. Key technique: use previously computed information to avoid redundant comparisons. The "mirror" property allows skipping unnecessary checks.

## Next Greater Element (Monotonic Stack)

```python
# PROBLEM: For each array element, find next greater element; -1 if none exists
# TIME: O(n) SPACE: O(n)
def next_greater_elements(nums: list[int]) -> list[int]:
    """
    Classic monotonic stack problem. Process elements right-to-left,
    maintaining a stack of candidates for "next greater".
    """
    n = len(nums)
    result = [-1] * n
    stack = []  # Monotonically decreasing stack
    
    # Process from right to left
    for i in range(n - 1, -1, -1):
        # Pop elements <= current (they can't be "next greater" for anything left of i)
        while stack and stack[-1] <= nums[i]:
            stack.pop()
        
        # Top of stack is now the next greater element
        if stack:
            result[i] = stack[-1]
        
        # Push current element as candidate for elements to the left
        stack.append(nums[i])
    
    return result

# Variant: Circular array
def next_greater_elements_circular(nums: list[int]) -> list[int]:
    """
    Handle circular array: next greater could be "before" current element.
    Double the array virtually by iterating 2*n times with modulo.
    """
    n = len(nums)
    result = [-1] * n
    stack = []
    
    # Process circular array (2 passes)
    for i in range(2 * n - 1, -1, -1):
        idx = i % n
        while stack and stack[-1] <= nums[idx]:
            stack.pop()
        
        # Only update result in first pass (i < n)
        if i < n and stack:
            result[idx] = stack[-1]
        
        stack.append(nums[idx])
    
    return result
```
**Why**: Monotonic stack pattern solves many "next greater/smaller" problems in O(n). Key insight: maintain invariant that stack is always sorted. Used in stock span, daily temperatures, largest rectangle in histogram.

## Sieve of Eratosthenes (Prime Generation)

```python
# PROBLEM: Generate all prime numbers up to n
# TIME: O(n log log n) SPACE: O(n)
def sieve_of_eratosthenes(n: int) -> list[int]:
    """
    Ancient but still optimal algorithm for finding all primes up to n.
    Eliminate multiples of each prime starting from p².
    """
    if n < 2:
        return []
    
    # is_prime[i] = True if i is prime
    is_prime = [True] * (n + 1)
    is_prime[0] = is_prime[1] = False
    
    # Only need to check up to sqrt(n)
    for p in range(2, int(n ** 0.5) + 1):
        if is_prime[p]:
            # Mark multiples starting from p² (smaller multiples already marked)
            # Optimizations: only odd numbers, wheel factorization
            for multiple in range(p * p, n + 1, p):
                is_prime[multiple] = False
    
    return [i for i in range(n + 1) if is_prime[i]]

# Space-optimized version: only odd numbers
def sieve_optimized(n: int) -> list[int]:
    """
    Space optimization: only store odd numbers (except 2).
    Index i represents number 2*i + 1.
    """
    if n < 2:
        return []
    if n == 2:
        return [2]
    
    sieve_size = (n - 1) // 2
    is_prime = [True] * sieve_size
    
    # Only need to check odd primes up to sqrt(n)
    for i in range(int(n ** 0.5) // 2 + 1):
        if is_prime[i]:
            # Prime is 2*i + 1, start marking from prime²
            prime = 2 * i + 1
            start = prime * prime
            if start > n:
                continue
            # Mark odd multiples only (even multiples are composite anyway)
            for j in range((start - 1) // 2, sieve_size, prime):
                is_prime[j] = False
    
    primes = [2]
    primes.extend(2 * i + 1 for i in range(sieve_size) if is_prime[i])
    return primes
```
**Why**: Fundamental algorithm in number theory. O(n log log n) is essentially linear for practical purposes. Basis for segmented sieve (memory-efficient for large ranges), prime factorization, and many competitive programming problems.

## Lazy Propagation Segment Tree

```python
# PROBLEM: Support range updates and range queries efficiently
# TIME: O(log n) per operation SPACE: O(n)
class LazySegmentTree:
    """
    Segment tree with lazy propagation for deferred range updates.
    Supports: range sum query + range addition update.
    Key idea: propagate updates only when needed (lazy).
    """
    
    def __init__(self, data: list[int]):
        self.n = len(data)
        # Tree size: 4*n is safe upper bound
        self.tree = [0] * (4 * self.n)
        self.lazy = [0] * (4 * self.n)  # Pending updates
        self._build(data, 1, 0, self.n - 1)
    
    def _build(self, data: list[int], node: int, start: int, end: int):
        """Build tree recursively. O(n)"""
        if start == end:
            self.tree[node] = data[start]
        else:
            mid = (start + end) // 2
            self._build(data, 2 * node, start, mid)
            self._build(data, 2 * node + 1, mid + 1, end)
            self.tree[node] = self.tree[2 * node] + self.tree[2 * node + 1]
    
    def _push(self, node: int, start: int, end: int):
        """Propagate lazy value to children. O(1)"""
        if self.lazy[node] != 0:
            # Apply pending update to current node
            self.tree[node] += self.lazy[node] * (end - start + 1)
            
            # Propagate to children if not leaf
            if start != end:
                self.lazy[2 * node] += self.lazy[node]
                self.lazy[2 * node + 1] += self.lazy[node]
            
            # Clear lazy value
            self.lazy[node] = 0
    
    def update_range(self, l: int, r: int, val: int):
        """Add val to all elements in [l, r]. O(log n)"""
        self._update_range(1, 0, self.n - 1, l, r, val)
    
    def _update_range(self, node: int, start: int, end: int, 
                      l: int, r: int, val: int):
        """Internal range update with lazy propagation"""
        self._push(node, start, end)
        
        # No overlap
        if start > r or end < l:
            return
        
        # Complete overlap
        if l <= start and end <= r:
            self.lazy[node] += val
            self._push(node, start, end)
            return
        
        # Partial overlap
        mid = (start + end) // 2
        self._update_range(2 * node, start, mid, l, r, val)
        self._update_range(2 * node + 1, mid + 1, end, l, r, val)
        self.tree[node] = self.tree[2 * node] + self.tree[2 * node + 1]
    
    def query_range(self, l: int, r: int) -> int:
        """Get sum of elements in [l, r]. O(log n)"""
        return self._query_range(1, 0, self.n - 1, l, r)
    
    def _query_range(self, node: int, start: int, end: int, 
                     l: int, r: int) -> int:
        """Internal range query"""
        self._push(node, start, end)
        
        # No overlap
        if start > r or end < l:
            return 0
        
        # Complete overlap
        if l <= start and end <= r:
            return self.tree[node]
        
        # Partial overlap
        mid = (start + end) // 2
        left_sum = self._query_range(2 * node, start, mid, l, r)
        right_sum = self._query_range(2 * node + 1, mid + 1, end, l, r)
        return left_sum + right_sum
```
**Why**: Essential for problems with many range updates/queries. Without lazy propagation, range updates would be O(n). With lazy, both operations are O(log n). Used in: range min/max queries, lazy propagation variants, competitive programming. Pattern: defer work until absolutely necessary.

## Circuit Breaker Pattern (State Machine)

```python
# PROBLEM: Prevent cascade failures in distributed systems
# TIME: O(1) per request check SPACE: O(1)
from enum import Enum
from time import time
from typing import Callable, Any

class CircuitState(Enum):
    CLOSED = "closed"      # Normal operation
    OPEN = "open"          # Failing, reject all requests
    HALF_OPEN = "half_open"  # Testing if recovered

class CircuitBreaker:
    """
    Circuit Breaker pattern: automatically fail fast when downstream service fails.
    States: CLOSED -> OPEN (on failures) -> HALF_OPEN (timeout) -> CLOSED/OPEN
    """
    
    def __init__(
        self,
        failure_threshold: int = 5,
        timeout: float = 60.0,
        success_threshold: int = 3
    ):
        self.failure_threshold = failure_threshold  # Failures before opening
        self.timeout = timeout  # Seconds before trying again
        self.success_threshold = success_threshold  # Successes to close
        
        self.state = CircuitState.CLOSED
        self.failure_count = 0
        self.success_count = 0
        self.last_failure_time = 0.0
    
    def call(self, func: Callable, *args, **kwargs) -> Any:
        """
        Execute function through circuit breaker.
        Raises exception if circuit is OPEN, otherwise executes function.
        """
        # Check if we should transition from OPEN to HALF_OPEN
        if self.state == CircuitState.OPEN:
            if time() - self.last_failure_time >= self.timeout:
                self.state = CircuitState.HALF_OPEN
                self.success_count = 0
            else:
                raise Exception("Circuit breaker is OPEN")
        
        try:
            result = func(*args, **kwargs)
            self._on_success()
            return result
        except Exception as e:
            self._on_failure()
            raise e
    
    def _on_success(self):
        """Handle successful call"""
        if self.state == CircuitState.HALF_OPEN:
            self.success_count += 1
            if self.success_count >= self.success_threshold:
                # Enough successes, close circuit
                self.state = CircuitState.CLOSED
                self.failure_count = 0
        elif self.state == CircuitState.CLOSED:
            # Reset failure count on success
            self.failure_count = 0
    
    def _on_failure(self):
        """Handle failed call"""
        self.failure_count += 1
        self.last_failure_time = time()
        
        if self.state == CircuitState.HALF_OPEN:
            # Even one failure in half-open -> back to open
            self.state = CircuitState.OPEN
        elif self.state == CircuitState.CLOSED:
            if self.failure_count >= self.failure_threshold:
                # Too many failures, open circuit
                self.state = CircuitState.OPEN
    
    def get_state(self) -> CircuitState:
        """Get current state for monitoring"""
        return self.state

# Usage example with fallback
def resilient_api_call(
    circuit_breaker: CircuitBreaker,
    primary_func: Callable,
    fallback_func: Callable,
    *args, **kwargs
) -> Any:
    """
    Try primary function through circuit breaker.
    If circuit is open or call fails, use fallback.
    """
    try:
        return circuit_breaker.call(primary_func, *args, **kwargs)
    except Exception:
        # Log the failure, use fallback
        return fallback_func(*args, **kwargs)
```
**Why**: Critical for microservices resilience. Prevents cascading failures by failing fast. States ensure system recovers gracefully: CLOSED (normal) → OPEN (fail fast) → HALF_OPEN (test recovery). Used in: Netflix Hystrix, Resilience4j, production systems.
