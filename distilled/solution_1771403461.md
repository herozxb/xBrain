## 问题 1：LRU 缓存（Least Recently Used Cache）

### 1.1 问题分析

**核心需求：**
- 实现 LRUCache 类，支持 get 和 put 操作
- 两个操作的时间复杂度都必须是 O(1)
- 有容量限制，超过容量时删除最久未使用的数据

**设计思路：**
为了实现 O(1) 的时间复杂度，我们需要：
1. **哈希表**：提供 O(1) 的查找能力
2. **双向链表**：提供 O(1) 的插入和删除能力

**数据结构组合：**
- 哈希表存储 `key -> 链表节点` 的映射
- 双向链表维护访问顺序（最近使用的在头部，最久未使用的在尾部）

**操作实现：**
- **get(key)**：从哈希表定位节点，移动到链表头部
- **put(key, value)**：
  - 如果 key 存在：更新值，移动到头部
  - 如果 key 不存在：创建新节点，加入头部；如果超容量，删除尾部节点

```python
from typing import Optional

class DLinkedNode:
    """双向链表节点"""
    def __init__(self, key: int = 0, value: int = 0):
        self.key = key
        self.value = value
        self.prev: Optional[DLinkedNode] = None
        self.next: Optional[DLinkedNode] = None


class LRUCache:
    """LRU 缓存实现"""
    
    def __init__(self, capacity: int):
        self.capacity = capacity
        self.size = 0
        self.cache = {}  # key -> DLinkedNode
        
        # 使用伪头部和伪尾部节点简化边界处理
        self.head = DLinkedNode()
        self.tail = DLinkedNode()
        self.head.next = self.tail
        self.tail.prev = self.head
    
    def _add_to_head(self, node: DLinkedNode) -> None:
        """将节点添加到链表头部"""
        node.prev = self.head
        node.next = self.head.next
        self.head.next.prev = node
        self.head.next = node
    
    def _remove_node(self, node: DLinkedNode) -> None:
        """从链表中删除节点"""
        node.prev.next = node.next
        node.next.prev = node.prev
    
    def _move_to_head(self, node: DLinkedNode) -> None:
        """将节点移动到头部"""
        self._remove_node(node)
        self._add_to_head(node)
    
    def _remove_tail(self) -> DLinkedNode:
        """删除链表尾部节点并返回"""
        node = self.tail.prev
        self._remove_node(node)
        return node
    
    def get(self, key: int) -> int:
        """获取缓存值，O(1) 时间复杂度"""
        if key not in self.cache:
            return -1
        
        # 如果存在，移动到头部
        node = self.cache[key]
        self._move_to_head(node)
        return node.value
    
    def put(self, key: int, value: int) -> None:
        """插入或更新缓存值，O(1) 时间复杂度"""
        if key in self.cache:
            # 更新值并移动到头部
            node = self.cache[key]
            node.value = value
            self._move_to_head(node)
        else:
            # 创建新节点
            new_node = DLinkedNode(key, value)
            self.cache[key] = new_node
            self._add_to_head(new_node)
            self.size += 1
            
            # 如果超过容量，删除尾部
            if self.size > self.capacity:
                removed = self._remove_tail()
                del self.cache[removed.key]
                self.size -= 1

    def put(self, key: int, value: int) -> None:
        if key in self.cache:
            self.cache.move_to_end(key)
        self.cache[key] = value
        if len(self.cache) > self.capacity:
            # 删除最久未使用的（队列头部）
            self.cache.popitem(last=False)
```

```typescript
/**
 * 双向链表节点
 */
class DLinkedNode {
  key: number;
  value: number;
  prev: DLinkedNode | null = null;
  next: DLinkedNode | null = null;

  constructor(key: number = 0, value: number = 0) {
    this.key = key;
    this.value = value;
  }
}

/**
 * LRU 缓存实现
 */
class LRUCache {
  private capacity: number;
  private size: number = 0;
  private cache: Map<number, DLinkedNode> = new Map();
  private head: DLinkedNode;
  private tail: DLinkedNode;

  constructor(capacity: number) {
    this.capacity = capacity;
    // 使用伪头部和伪尾部节点
    this.head = new DLinkedNode();
    this.tail = new DLinkedNode();
    this.head.next = this.tail;
    this.tail.prev = this.head;
  }

  /**
   * 将节点添加到链表头部
   */
  private addToHead(node: DLinkedNode): void {
    node.prev = this.head;
    node.next = this.head.next;
    this.head.next!.prev = node;
    this.head.next = node;
  }

  /**
   * 从链表中删除节点
   */
  private removeNode(node: DLinkedNode): void {
    node.prev!.next = node.next;
    node.next!.prev = node.prev;
  }

  /**
   * 将节点移动到头部
   */
  private moveToHead(node: DLinkedNode): void {
    this.removeNode(node);
    this.addToHead(node);
  }

  /**
   * 删除链表尾部节点并返回
   */
  private removeTail(): DLinkedNode {
    const node = this.tail.prev!;
    this.removeNode(node);
    return node;
  }

  /**
   * 获取缓存值，O(1) 时间复杂度
   */
  get(key: number): number {
    if (!this.cache.has(key)) {
      return -1;
    }

    const node = this.cache.get(key)!;
    this.moveToHead(node);
    return node.value;
  }

  /**
   * 插入或更新缓存值，O(1) 时间复杂度
   */
  put(key: number, value: number): void {
    if (this.cache.has(key)) {
      const node = this.cache.get(key)!;
      node.value = value;
      this.moveToHead(node);
    } else {
      const newNode = new DLinkedNode(key, value);
      this.cache.set(key, newNode);
      this.addToHead(newNode);
      this.size++;

      if (this.size > this.capacity) {
        const removed = this.removeTail();
        this.cache.delete(removed.key);
        this.size--;
      }
    }
  }
}
```

### 1.5 复杂度分析

#### 时间复杂度
- **get(key)**: O(1)
  - 哈希表查找：O(1)
  - 双向链表节点移动：O(1)（已有节点引用）

- **put(key, value)**: O(1)
  - 哈希表查找/插入：O(1)
  - 双向链表插入/删除：O(1)

#### 空间复杂度
- **O(capacity)**：最多存储 capacity 个键值对
- 额外空间：双向链表节点的指针（prev, next）

#### 关键点
1. 使用伪头部和伪尾部节点简化边界条件处理
2. 哈希表 + 双向链表的组合是经典设计
3. 所有操作都是指针操作，保证 O(1)

## 问题 2：线程安全队列（Thread-Safe Queue）

### 2.1 问题分析

**核心需求：**
- 阻塞式 push/pop：队列空时 pop 阻塞，队列满时 push 阻塞（可选）
- 超时支持：在指定时间内等待，超时返回
- 优雅关闭：可以关闭队列，唤醒所有等待线程

**设计思路：**
1. **互斥锁（Mutex）**：保护队列数据结构
2. **条件变量（Condition Variable）**：实现线程等待/唤醒机制
3. **关闭标志**：实现优雅关闭

**操作实现：**
- **push(item, timeout)**：
  - 加锁
  - 如果队列满，等待（带超时）
  - 插入元素，通知一个等待的消费者
  - 解锁

- **pop(timeout)**：
  - 加锁
  - 如果队列空，等待（带超时）
  - 取出元素，通知一个等待的生产者
  - 解锁

- **close()**：
  - 加锁
  - 设置关闭标志
  - 唤醒所有等待的线程
  - 解锁

```python
import threading
from typing import Generic, TypeVar, Optional
from collections import deque
from contextlib import contextmanager

T = TypeVar('T')


class QueueClosed(Exception):
    """队列已关闭异常"""
    pass


class QueueTimeout(Exception):
    """队列操作超时异常"""
    pass


class ThreadSafeQueue(Generic[T]):
    """线程安全队列实现"""
    
    def __init__(self, maxsize: int = 0):
        """
        初始化队列
        
        Args:
            maxsize: 队列最大容量，0 表示无限制
        """
        self.maxsize = maxsize
        self._queue: deque[T] = deque()
        self._lock = threading.Lock()
        self._not_empty = threading.Condition(self._lock)
        self._not_full = threading.Condition(self._lock)
        self._closed = False
    
    def push(self, item: T, timeout: Optional[float] = None) -> bool:
        """
        将元素推入队列（阻塞式）
        
        Args:
            item: 要推入的元素
            timeout: 超时时间（秒），None 表示永久等待
            
        Returns:
            True 表示成功，False 表示超时或队列已关闭
            
        Raises:
            QueueClosed: 队列已关闭
        """
        with self._not_full:
            if self._closed:
                raise QueueClosed("Queue is closed")
            
            # 如果队列满，等待
            if self.maxsize > 0:
                while len(self._queue) >= self.maxsize:
                    if not self._not_full.wait(timeout):
                        return False  # 超时
                    if self._closed:
                        raise QueueClosed("Queue is closed")
            
            self._queue.append(item)
            self._not_empty.notify()
            return True
    
    def pop(self, timeout: Optional[float] = None) -> T:
        """
        从队列弹出元素（阻塞式）
        
        Args:
            timeout: 超时时间（秒），None 表示永久等待
            
        Returns:
            弹出的元素
            
        Raises:
            QueueClosed: 队列已关闭且为空
            QueueTimeout: 操作超时
        """
        with self._not_empty:
            # 如果队列空，等待
            while len(self._queue) == 0:
                if self._closed:
                    raise QueueClosed("Queue is closed and empty")
                
                if not self._not_empty.wait(timeout):
                    raise QueueTimeout("Pop operation timeout")
            
            item = self._queue.popleft()
            self._not_full.notify()
            return item
    
    def close(self) -> None:
        """优雅关闭队列，唤醒所有等待的线程"""
        with self._lock:
            self._closed = True
            self._not_empty.notify_all()
            self._not_full.notify_all()
    
    def is_closed(self) -> bool:
        """检查队列是否已关闭"""
        with self._lock:
            return self._closed
    
    def is_empty(self) -> bool:
        """检查队列是否为空"""
        with self._lock:
            return len(self._queue) == 0
    
    def size(self) -> int:
        """获取队列大小"""
        with self._lock:
            return len(self._queue)
    
    def __len__(self) -> int:
        return self.size()


# 使用示例
if __name__ == "__main__":
    def producer(queue: ThreadSafeQueue, items: list):
        for item in items:
            try:
                queue.push(item)
                print(f"Produced: {item}")
            except QueueClosed:
                print("Queue closed, producer exiting")
                break
    
    def consumer(queue: ThreadSafeQueue, name: str):
        while True:
            try:
                item = queue.pop(timeout=1.0)
                print(f"{name} consumed: {item}")
            except QueueClosed:
                print(f"{name}: Queue closed, exiting")
                break
            except QueueTimeout:
                print(f"{name}: Timeout, checking again...")
    
    # 创建队列
    q = ThreadSafeQueue(maxsize=5)
    
    # 创建生产者和消费者线程
    producer_thread = threading.Thread(
        target=producer, args=(q, list(range(10)))
    )
    consumer_thread = threading.Thread(
        target=consumer, args=(q, "Consumer-1")
    )
    
    consumer_thread.start()
    producer_thread.start()
    
    producer_thread.join()
    q.close()  # 关闭队列
    consumer_thread.join()
```

```typescript
/**
 * 队列已关闭错误
 */
class QueueClosedError extends Error {
  constructor(message: string = "Queue is closed") {
    super(message);
    this.name = "QueueClosedError";
  }
}

/**
 * 队列操作超时错误
 */
class QueueTimeoutError extends Error {
  constructor(message: string = "Queue operation timeout") {
    super(message);
    this.name = "QueueTimeoutError";
  }
}

/**
 * 线程安全队列（异步版本）
 * 注：TypeScript/JavaScript 是单线程的，这里使用 Promise 模拟阻塞
 */
class ThreadSafeQueue<T> {
  private queue: T[] = [];
  private maxsize: number;
  private closed: boolean = false;
  
  // 等待队列非空的消费者
  private notEmptyWaiters: Array<{
    resolve: (item: T) => void;
    reject: (error: Error) => void;
    timer?: NodeJS.Timeout;
  }> = [];
  
  // 等待队列非满的生产者
  private notFullWaiters: Array<{
    resolve: () => void;
    reject: (error: Error) => void;
    timer?: NodeJS.Timeout;
  }> = [];

  constructor(maxsize: number = 0) {
    this.maxsize = maxsize;
  }

  /**
   * 将元素推入队列（阻塞式）
   * @param item 要推入的元素
   * @param timeout 超时时间（毫秒），0 表示永久等待
   * @returns Promise<boolean> 成功返回 true，超时返回 false
   */
  async push(item: T, timeout: number = 0): Promise<boolean> {
    if (this.closed) {
      throw new QueueClosedError();
    }

    // 如果队列满，等待
    if (this.maxsize > 0 && this.queue.length >= this.maxsize) {
      await this._waitNotFull(timeout);
    }

    if (this.closed) {
      throw new QueueClosedError();
    }

    this.queue.push(item);
    this._notifyNotEmpty();
    return true;
  }

  /**
   * 从队列弹出元素（阻塞式）
   * @param timeout 超时时间（毫秒），0 表示永久等待
   * @returns Promise<T> 弹出的元素
   */
  async pop(timeout: number = 0): Promise<T> {
    if (this.closed && this.queue.length === 0) {
      throw new QueueClosedError("Queue is closed and empty");
    }

    // 如果队列空，等待
    if (this.queue.length === 0) {
      await this._waitNotEmpty(timeout);
    }

    if (this.closed && this.queue.length === 0) {
      throw new QueueClosedError("Queue is closed and empty");
    }

    const item = this.queue.shift()!;
    this._notifyNotFull();
    return item;
  }

  /**
   * 优雅关闭队列，唤醒所有等待的操作
   */
  close(): void {
    this.closed = true;
    
    // 唤醒所有等待的消费者
    this.notEmptyWaiters.forEach(waiter => {
      if (waiter.timer) clearTimeout(waiter.timer);
      waiter.reject(new QueueClosedError());
    });
    this.notEmptyWaiters = [];
    
    // 唤醒所有等待的生产者
    this.notFullWaiters.forEach(waiter => {
      if (waiter.timer) clearTimeout(waiter.timer);
      waiter.reject(new QueueClosedError());
    });
    this.notFullWaiters = [];
  }

  /**
   * 检查队列是否已关闭
   */
  isClosed(): boolean {
    return this.closed;
  }

  /**
   * 检查队列是否为空
   */
  isEmpty(): boolean {
    return this.queue.length === 0;
  }

  /**
   * 获取队列大小
   */
  size(): number {
    return this.queue.length;
  }

  /**
   * 等待队列非空
   */
  private _waitNotEmpty(timeout: number): Promise<void> {
    return new Promise((resolve, reject) => {
      const waiter = { resolve: () => resolve(), reject, timer: undefined as NodeJS.Timeout | undefined };
      
      if (timeout > 0) {
        waiter.timer = setTimeout(() => {
          const index = this.notEmptyWaiters.indexOf(waiter);
          if (index > -1) {
            this.notEmptyWaiters.splice(index, 1);
            reject(new QueueTimeoutError());
          }
        }, timeout);
      }
      
      this.notEmptyWaiters.push(waiter);
    });
  }

  /**
   * 等待队列非满
   */
  private _waitNotFull(timeout: number): Promise<void> {
    return new Promise((resolve, reject) => {
      const waiter = { resolve: () => resolve(), reject, timer: undefined as NodeJS.Timeout | undefined };
      
      if (timeout > 0) {
        waiter.timer = setTimeout(() => {
          const index = this.notFullWaiters.indexOf(waiter);
          if (index > -1) {
            this.notFullWaiters.splice(index, 1);
            reject(new QueueTimeoutError());
          }
        }, timeout);
      }
      
      this.notFullWaiters.push(waiter);
    });
  }

  /**
   * 通知一个等待的消费者
   */
  private _notifyNotEmpty(): void {
    const waiter = this.notEmptyWaiters.shift();
    if (waiter) {
      if (waiter.timer) clearTimeout(waiter.timer);
      waiter.resolve(undefined as any);
    }
  }

  /**
   * 通知一个等待的生产者
   */
  private _notifyNotFull(): void {
    const waiter = this.notFullWaiters.shift();
    if (waiter) {
      if (waiter.timer) clearTimeout(waiter.timer);
      waiter.resolve();
    }
  }
}

// 使用示例
async function example() {
  const queue = new ThreadSafeQueue<number>(3);

  // 生产者
  async function producer() {
    for (let i = 0; i < 10; i++) {
      await queue.push(i);
      console.log(`Produced: ${i}`);
      await new Promise(resolve => setTimeout(resolve, 100));
    }
  }

  // 消费者
  async function consumer(name: string) {
    while (true) {
      try {
        const item = await queue.pop(1000);
        console.log(`${name} consumed: ${item}`);
      } catch (error) {
        if (error instanceof QueueClosedError) {
          console.log(`${name}: Queue closed, exiting`);
          break;
        } else if (error instanceof QueueTimeoutError) {
          console.log(`${name}: Timeout, checking again...`);
        }
      }
    }
  }

  // 并发运行
  await Promise.all([
    producer(),
```

### 2.5 复杂度分析

#### 时间复杂度
- **push(item, timeout)**: 
  - 无等待：O(1)（数组 append）
  - 有等待：取决于超时和其他线程
  
- **pop(timeout)**:
  - 无等待：O(1)（数组 shift）
  - 有等待：取决于超时和其他线程

#### 空间复杂度
- **O(n)**：n 为队列中元素数量
- 额外空间：等待队列（waiters arrays）

#### 并发性分析
- **锁粒度**：全局互斥锁保护整个队列
- **公平性**：条件变量通常提供 FIFO 公平性（取决于实现）
- **性能优化方向**：
  - 使用无锁队列（lock-free queue）减少锁竞争
  - 使用多个队列分片（sharding）提高并发度

## 总结

### LRU 缓存
- **核心思想**：哈希表 + 双向链表
- **时间复杂度**：所有操作 O(1)
- **应用场景**：缓存系统、页面置换算法

### 线程安全队列
- **核心思想**：互斥锁 + 条件变量
- **关键特性**：阻塞、超时、优雅关闭
- **应用场景**：生产者-消费者模型、任务队列
