    Click to visit Example.com (ping enabled)
  </a>
  
  <a href="https://test.com" ping="https://analytics.example.com/track?link=test" class="link">
    Click to visit Test.com (ping enabled)
  </a>
  
  <div class="ping-status">
    <strong>Note:</strong> The ping attribute sends a POST request to the specified URL when the link is clicked.
    This is useful for analytics without JavaScript. Check your network tab to see the ping request.
  </div>
  
  <script>
    // Demonstration of ping attribute behavior
    document.querySelectorAll('a[ping]').forEach(link => {
      link.addEventListener('click', (e) => {
        console.log('Link clicked:', e.target.href);

        // Ping request will be sent automatically by the browser
      });
    });
  </script>
</body>
</html>
```

**Why**: The `ping` attribute provides a native way to track link clicks without JavaScript, improving performance and reducing client-side code.

  </div>
  
  <div class="info-box">
    <strong>SEO Benefit:</strong> The hreflang attribute helps search engines understand the language of the target page, enabling proper indexing and serving to users in their preferred language.
  </div>
  
  <script>
    // Display language information on hover
    document.querySelectorAll('a[hreflang]').forEach(link => {
      const langCode = link.getAttribute('hreflang');
      link.title = `This page is in ${getLanguageName(langCode)}`;
    });
    
    function getLanguageName(code) {
      const languages = {
        'en': 'English',
        'es': 'Spanish',
        'fr': 'French',
        'zh': 'Chinese'
      };
      return languages[code] || code;
    }
  </script>
</body>
</html>
```

**Why**: The `hreflang` attribute improves SEO and user experience by helping search engines serve the correct language version to users.
