## [Maximum Sum Subarray of Size K]

```python
# PROBLEM: Find the maximum sum of any contiguous subarray of size k
# TIME: O(n) SPACE: O(1)
def max_sum_subarray_k(arr, k):
    """
    Sliding window technique - fixed window size.
    Expand window by adding new element, shrink by removing old.
    Track maximum sum seen across all windows.
    """
    if len(arr) < k:
        return None
    
    # Initialize first window
    window_sum = sum(arr[:k])
    max_sum = window_sum
    
    # Slide window across array
    for i in range(k, len(arr)):
        # Add incoming element, remove outgoing element
        window_sum += arr[i] - arr[i - k]
        max_sum = max(max_sum, window_sum)
    
    return max_sum
```
**Why**: Classic fixed-size sliding window. Essential pattern for subarray problems with size constraints.

## [Container With Most Water]

```python
# PROBLEM: Find two lines that form container holding maximum water
# TIME: O(n) SPACE: O(1)
def max_area(height):
    """
    Two pointers from both ends toward center.
    Move the shorter line inward - only way to potentially increase area.
    Area = min(height[left], height[right]) * width.
    """
    left, right = 0, len(height) - 1
    max_water = 0
    
    while left < right:
        # Calculate current container area
        width = right - left
        container_height = min(height[left], height[right])
        max_water = max(max_water, width * container_height)
        
        # Move pointer with shorter line
        if height[left] < height[right]:
            left += 1
        else:
            right -= 1
    
    return max_water
```
**Why**: Optimal two-pointer strategy. Greedy choice: always move the limiting (shorter) side.

## [Subsets (All Possible)]

```python
# PROBLEM: Generate all possible subsets of a set (power set)
# TIME: O(n * 2^n) SPACE: O(n) recursion depth
def subsets(nums):
    """
    Backtracking with choose-explore-unchoose pattern.
    At each element, we have two choices: include or exclude.
    Total of 2^n subsets for n elements.
    """
    result = []
    
    def backtrack(start, current):
        # Add copy of current subset to results
        result.append(current[:])
        
        # Try adding each remaining element
        for i in range(start, len(nums)):
            # Choose: add element to current subset
            current.append(nums[i])
            # Explore: recurse with next starting index
            backtrack(i + 1, current)
            # Unchoose: remove element (backtrack)
            current.pop()
    
    backtrack(0, [])
    return result
```
**Why**: Fundamental backtracking pattern. Demonstrates the choose-explore-unchoose paradigm used in many combinatorial problems.

## [Number of Connected Components]

```python
# PROBLEM: Count connected components in an undirected graph
# TIME: O(n * α(n)) ≈ O(n) SPACE: O(n)
class UnionFind:
    def __init__(self, n):
        self.parent = list(range(n))
        self.rank = [0] * n
        self.components = n
    
    def find(self, x):
        # Path compression: point directly to root
        if self.parent[x] != x:
            self.parent[x] = self.find(self.parent[x])
        return self.parent[x]
    
    def union(self, x, y):
        # Union by rank: attach smaller tree under larger
        px, py = self.find(x), self.find(y)
        if px == py:
            return False  # Already connected
        
        if self.rank[px] < self.rank[py]:
            px, py = py, px
        self.parent[py] = px
        if self.rank[px] == self.rank[py]:
            self.rank[px] += 1
        
        self.components -= 1
        return True

def count_components(n, edges):
    uf = UnionFind(n)
    for u, v in edges:
        uf.union(u, v)
    return uf.components
```
**Why**: Union-Find with path compression and union by rank. Essential for connectivity and cycle detection problems.

## [Longest Increasing Subsequence]

```python
# PROBLEM: Find length of longest strictly increasing subsequence
# TIME: O(n log n) SPACE: O(n)
def length_of_lis(nums):
    """
    Patience sorting approach with binary search.
    Maintain tails array where tails[i] = smallest tail for LIS of length i+1.
    Binary search finds position to extend or replace.
    """
    if not nums:
        return 0
    
    tails = []  # tails[i] = smallest ending value of LIS with length i+1
    
    for num in nums:
        # Binary search for first tails[i] >= num
        left, right = 0, len(tails)
        while left < right:
            mid = (left + right) // 2
            if tails[mid] < num:
                left = mid + 1
            else:
                right = mid
        
        # Extend or replace in tails
        if left == len(tails):
            tails.append(num)  # Extend: new longest subsequence
        else:
            tails[left] = num  # Replace: better (smaller) tail value
    
    return len(tails)
```
**Why**: Elegant DP optimization using binary search. The tails array maintains optimal substructure property.

## [Clone Graph]

```python
# PROBLEM: Deep clone a connected undirected graph
# TIME: O(V + E) SPACE: O(V)
class Node:
    def __init__(self, val=0, neighbors=None):
        self.val = val
        self.neighbors = neighbors if neighbors else []

def clone_graph(node):
    """
    BFS traversal with hash map tracking original -> clone mapping.
    Process each node once, create clone if not exists, connect neighbors.
    """
    if not node:
        return None
    
    # Map from original node to its clone
    clone_map = {}
    queue = [node]
    clone_map[node] = Node(node.val)
    
    while queue:
        current = queue.pop(0)
        
        for neighbor in current.neighbors:
            if neighbor not in clone_map:
                # First time seeing this node - create clone
                clone_map[neighbor] = Node(neighbor.val)
                queue.append(neighbor)
            
            # Connect clone's neighbors
            clone_map[current].neighbors.append(clone_map[neighbor])
    
    return clone_map[node]
```
**Why**: Graph deep copy with BFS. Hash map prevents cycles and ensures each node cloned exactly once.

## [Binary Tree Level Order Traversal]

```python
# PROBLEM: Return nodes level by level from left to right
# TIME: O(n) SPACE: O(w) where w = max width
from collections import deque

def level_order(root):
    """
    BFS using queue, process one level at a time.
    Track level size to separate levels in output.
    """
    if not root:
        return []
    
    result = []
    queue = deque([root])
    
    while queue:
        level_size = len(queue)
        current_level = []
        
        # Process all nodes at current level
        for _ in range(level_size):
            node = queue.popleft()
            current_level.append(node.val)
            
            # Add children for next level
            if node.left:
                queue.append(node.left)
            if node.right:
                queue.append(node.right)
        
        result.append(current_level)
    
    return result
```
**Why**: Level-by-level BFS pattern. Critical for tree problems requiring level information.

## [Kth Largest Element]

```python
# PROBLEM: Find the kth largest element in an unsorted array
# TIME: O(n log k) SPACE: O(k)
import heapq

def find_kth_largest(nums, k):
    """
    Min-heap of size k. Root is kth largest.
    Push elements, pop smallest if heap exceeds size k.
    Final root = kth largest element.
    """
    min_heap = []
    
    for num in nums:
        heapq.heappush(min_heap, num)
        
        # Keep heap size at k - smallest gets evicted
        if len(min_heap) > k:
            heapq.heappop(min_heap)
    
    return min_heap[0]  # Root is kth largest
```
**Why**: Heap pattern for top-k problems. Min-heap of size k efficiently tracks k largest elements.

## [Implement Trie (Prefix Tree)]

```python
# PROBLEM: Implement trie with insert, search, and startsWith
# TIME: O(m) per operation where m = word length SPACE: O(alphabet_size * total_chars)
class TrieNode:
    def __init__(self):
        self.children = {}  # Map character to child node
        self.is_end = False  # Marks complete word

class Trie:
    def __init__(self):
        self.root = TrieNode()
    
    def insert(self, word):
        """Insert word into trie, creating nodes as needed."""
        node = self.root
        for char in word:
            if char not in node.children:
                node.children[char] = TrieNode()
            node = node.children[char]
        node.is_end = True
    
    def search(self, word):
        """Return True if word exists in trie."""
        node = self._search_prefix(word)
        return node is not None and node.is_end
    
    def starts_with(self, prefix):
        """Return True if any word starts with prefix."""
        return self._search_prefix(prefix) is not None
    
    def _search_prefix(self, prefix):
        """Helper: traverse prefix, return final node or None."""
        node = self.root
        for char in prefix:
            if char not in node.children:
                return None
            node = node.children[char]
        return node
```
**Why**: Trie for prefix-based operations. Optimal for autocomplete, dictionary, and prefix matching problems.

## [Climbing Stairs with Memoization]

```python
# PROBLEM: Count ways to climb n stairs taking 1 or 2 steps
# TIME: O(n) SPACE: O(n) with cache, O(1) with tabulation
from functools import lru_cache

@lru_cache(maxsize=None)
def climb_stairs(n):
    """
    LRU cache memoization for Fibonacci-like recurrence.
    f(n) = f(n-1) + f(n-2), base cases f(1)=1, f(2)=2.
    Cache prevents exponential recomputation.
    """
    if n <= 2:
        return n
    return climb_stairs(n - 1) + climb_stairs(n - 2)

# Alternative: iterative with O(1) space
def climb_stairs_iterative(n):
    if n <= 2:
        return n
    
    prev, curr = 1, 2  # f(n-2), f(n-1)
    for i in range(3, n + 1):
        prev, curr = curr, prev + curr  # Slide window
    
    return curr
```
**Why**: Classic DP with lru_cache decorator. Shows Pythonic memoization vs manual tabulation trade-offs.
