## [Maximum Subarray Sum - Kadane's Algorithm]
```python
# PROBLEM: Find the contiguous subarray with the largest sum
# TIME: O(n) SPACE: O(1)
def max_subarray_sum(nums):
    """
    Returns the maximum sum of any contiguous subarray.
    Uses Kadane's algorithm to track local and global maxima.
    """
    if not nums:
        return 0
    
    # Initialize with first element
    current_max = global_max = nums[0]
    
    for i in range(1, len(nums)):
        # Either extend previous subarray or start new one
        current_max = max(nums[i], current_max + nums[i])
        # Update global maximum if current is larger
        global_max = max(global_max, current_max)
    
    return global_max
```
**Why**: Classic sliding_window/DP pattern. Essential for subarray optimization problems.

Topics: sliding_window, dp

## [Two Sum - Hash Map]
```python
# PROBLEM: Find two numbers that add up to target, return their indices
# TIME: O(n) SPACE: O(n)
def two_sum(nums, target):
    """
    Finds indices of two numbers that sum to target.
    Uses hash map for O(1) lookups of complement values.
    """
    # Map value -> index for O(1) complement lookup
    seen = {}
    
    for i, num in enumerate(nums):
        complement = target - num
        # Check if complement exists in map
        if complement in seen:
            return [seen[complement], i]
        # Store current number's index
        seen[num] = i
    
    return []  # No solution found
```
**Why**: Fundamental two_pointers alternative using space-time tradeoff. Interview staple.

Topics: two_pointers, hash_map

## [Merge Sorted Arrays]
```python
# PROBLEM: Merge two sorted arrays into one sorted array
# TIME: O(n + m) SPACE: O(n + m)
def merge_sorted_arrays(nums1, nums2):
    """
    Merges two sorted arrays maintaining sorted order.
    Uses two pointers to traverse both arrays simultaneously.
    """
    result = []
    i, j = 0, 0  # Pointers for nums1 and nums2
    
    # Compare elements from both arrays
    while i < len(nums1) and j < len(nums2):
        if nums1[i] <= nums2[j]:
            result.append(nums1[i])
            i += 1
        else:
            result.append(nums2[j])
            j += 1
    
    # Append remaining elements from nums1
    while i < len(nums1):
        result.append(nums1[i])
        i += 1
    
    # Append remaining elements from nums2
    while j < len(nums2):
        result.append(nums2[j])
        j += 1
    
    return result
```
**Why**: Core two_pointers technique. Foundation for merge sort and k-way merges.

Topics: two_pointers

## [Generate Parentheses]
```python
# PROBLEM: Generate all valid parentheses combinations for n pairs
# TIME: O(4^n / sqrt(n)) SPACE: O(4^n / sqrt(n))
def generate_parentheses(n):
    """
    Generates all valid combinations of n pairs of parentheses.
    Uses backtracking with pruning to ensure validity.
    """
    result = []
    
    def backtrack(current, open_count, close_count):
        # Base case: complete combination
        if len(current) == 2 * n:
            result.append(current)
            return
        
        # Add opening parenthesis if we have remaining
        if open_count < n:
            backtrack(current + '(', open_count + 1, close_count)
        
        # Add closing parenthesis only if valid (more open than close)
        if close_count < open_count:
            backtrack(current + ')', open_count, close_count + 1)
    
    backtrack('', 0, 0)
    return result
```
**Why**: Classic backtracking with constraint validation. Teaches pruning invalid branches early.

Topics: backtracking, recursion

## [Number of Islands]
```python
# PROBLEM: Count number of islands in a 2D grid (1=land, 0=water)
# TIME: O(m * n) SPACE: O(m * n) worst case for recursion stack
def num_islands(grid):
    """
    Counts connected components of '1's in the grid.
    Uses DFS to mark visited cells and explore each island fully.
    """
    if not grid or not grid[0]:
        return 0
    
    rows, cols = len(grid), len(grid[0])
    count = 0
    
    def dfs(r, c):
        # Boundary check and water/visited check
        if r < 0 or r >= rows or c < 0 or c >= cols or grid[r][c] != '1':
            return
        
        # Mark as visited by changing to '0'
        grid[r][c] = '0'
        
        # Explore all 4 directions
        dfs(r + 1, c)  # down
        dfs(r - 1, c)  # up
        dfs(r, c + 1)  # right
        dfs(r, c - 1)  # left
    
    for r in range(rows):
        for c in range(cols):
            if grid[r][c] == '1':
                count += 1
                dfs(r, c)  # Mark entire island as visited
    
    return count
```
**Why**: Essential graphs/flood-fill pattern. Applies to many grid connectivity problems.

Topics: graphs, dfs, matrix

## [LRU Cache]
```python
# PROBLEM: Implement Least Recently Used cache with O(1) get/put
# TIME: O(1) for both operations SPACE: O(capacity)
class LRUCache:
    """
    LRU Cache using OrderedDict for O(1) access and ordering.
    Automatically evicts least recently used item when at capacity.
    """
    def __init__(self, capacity):
        self.capacity = capacity
        self.cache = {}  # key -> value
    
    def get(self, key):
        """Returns value if exists, else -1. Updates access order."""
        if key not in self.cache:
            return -1
        
        # Move to end (most recently used) by re-inserting
        value = self.cache.pop(key)
        self.cache[key] = value
        return value
    
    def put(self, key, value):
        """Inserts/updates key. Evicts LRU if at capacity."""
        # Remove if exists (to update position)
        if key in self.cache:
            self.cache.pop(key)
        
        # Evict oldest (first) item if at capacity
        elif len(self.cache) >= self.capacity:
            self.cache.popitem(last=False)
        
        # Insert at end (most recent)
        self.cache[key] = value
```
**Why**: Must-know design pattern. Demonstrates lru_cache concept and hash map + ordering.

Topics: lru_cache, design, hash_map

## [Binary Tree Level Order Traversal]
```python
# PROBLEM: Return tree nodes level by level as nested lists
# TIME: O(n) SPACE: O(n)
from collections import deque

def level_order(root):
    """
    Performs BFS traversal of binary tree, grouping nodes by level.
    Returns list of lists, each containing one level's values.
    """
    if not root:
        return []
    
    result = []
    queue = deque([root])
    
    while queue:
        level_size = len(queue)
        current_level = []
        
        # Process all nodes at current level
        for _ in range(level_size):
            node = queue.popleft()
            current_level.append(node.val)
            
            # Add children to queue for next level
            if node.left:
                queue.append(node.left)
            if node.right:
                queue.append(node.right)
        
        result.append(current_level)
    
    return result
```
**Why**: Fundamental trees traversal pattern. BFS with level tracking is widely applicable.

Topics: trees, bfs, queue

## [Kth Largest Element]
```python
# PROBLEM: Find kth largest element in unsorted array
# TIME: O(n log k) SPACE: O(k)
import heapq

def find_kth_largest(nums, k):
    """
    Finds kth largest using min-heap of size k.
    Root of heap is always the kth largest element.
    """
    # Build min-heap with first k elements
    heap = nums[:k]
    heapq.heapify(heap)
    
    # Process remaining elements
    for num in nums[k:]:
        # If current number is larger than smallest in heap
        if num > heap[0]:
            heapq.heapreplace(heap, num)  # Replace and heapify
    
    # Root of heap is kth largest
    return heap[0]
```
**Why**: Key heap application. More efficient than sorting when k << n.

Topics: heap, priority_queue

## [Implement Trie]
```python
# PROBLEM: Implement a trie (prefix tree) with insert, search, startsWith
# TIME: O(m) per operation where m is word length SPACE: O(total chars)
class TrieNode:
    def __init__(self):
        self.children = {}  # char -> TrieNode
        self.is_end = False  # Marks complete word

class Trie:
    """
    Prefix tree for efficient string operations.
    Supports insert, exact search, and prefix search.
    """
    def __init__(self):
        self.root = TrieNode()
    
    def insert(self, word):
        """Inserts word into trie."""
        node = self.root
        for char in word:
            if char not in node.children:
                node.children[char] = TrieNode()
            node = node.children[char]
        node.is_end = True
    
    def search(self, word):
        """Returns True if word exists in trie."""
        node = self._traverse(word)
        return node is not None and node.is_end
    
    def starts_with(self, prefix):
        """Returns True if any word starts with prefix."""
        return self._traverse(prefix) is not None
    
    def _traverse(self, prefix):
        """Helper: returns node at end of prefix, or None."""
        node = self.root
        for char in prefix:
            if char not in node.children:
                return None
            node = node.children[char]
        return node
```
**Why**: Essential trie data structure. Powers autocomplete, spell checkers, and IP routing.

Topics: trie, string, design

## [Coin Change]
```python
# PROBLEM: Find minimum coins needed to make amount (unlimited coins)
# TIME: O(amount * n_coins) SPACE: O(amount)
def coin_change(coins, amount):
    """
    Finds minimum coins needed for target amount using DP.
    Returns -1 if amount cannot be made.
    """
    # dp[i] = min coins needed to make amount i
    dp = [float('inf')] * (amount + 1)
    dp[0] = 0  # Base case: 0 coins for amount 0
    
    # Build up solutions for each amount
    for i in range(1, amount + 1):
        for coin in coins:
            # If we can use this coin
            if coin <= i:
                # dp[i] = min(current, 1 + dp[i - coin])
                dp[i] = min(dp[i], 1 + dp[i - coin])
    
    return dp[amount] if dp[amount] != float('inf') else -1
```
**Why**: Classic unbounded knapsack dp problem. Teaches bottom-up dynamic programming.

Topics: dp, optimization
