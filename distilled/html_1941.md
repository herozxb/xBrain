    <h2>Basic Syntax</h2>

    <h2>font-display Values</h2>
    <ul>
      <li><code>swap</code> - Show fallback immediately, swap when loaded</li>

    <ul>

      <li>Subset fonts to only needed characters</li>

    </ul>

**Why**: `@font-face` enables custom web typography. Use WOFF2 format for optimal compression. The `font-display` property controls loading behavior to minimize layout shift and invisible text.
