```html
        <p>When introducing <mark class="definition">semantic HTML</mark>, it's important to understand that these elements carry meaning beyond just presentation. They describe the purpose of content, not just how it looks.</p>
        
        <blockquote class="quote">
            "The <mark>mark element</mark> represents a run of text in one document marked or highlighted for reference purposes, due to its relevance in another context."
            <footer>— HTML5 Specification</footer>
        </blockquote>
        
        <h3>Important Notes</h3>
        <p><mark class="important">Remember:</mark> The mark element is not for generic emphasis. Use <code>&lt;em&gt;</code> for emphasis and <code>&lt;strong&gt;</code> for importance. The mark element is specifically for highlighting text that's relevant in a different context.</p>
    </article>
    
    <article>
        <h2>Code Example</h2>
        <p>When showing code, mark can highlight specific parts:</p>
        
        <div class="code-block">
            <pre><code>&lt;!DOCTYPE html&gt;
&lt;html lang="en"&gt;
&lt;head&gt;
    &lt;meta charset="UTF-8"&gt;
    &lt;title&gt;<mark>Mark Element Demo</mark>&lt;/title&gt;
&lt;/head&gt;
&lt;body&gt;
    &lt;p&gt;Search results: &lt;mark&gt;<mark>HTML5</mark>&lt;/mark&gt;&lt;/p&gt;

        // Dynamic search highlighting example
        const searchInput = document.getElementById('searchInput');
        const articles = document.querySelectorAll('article');
        
        searchInput.addEventListener('input', function() {
            const searchTerm = this.value.toLowerCase().trim();
            
            // Remove all existing highlights
            document.querySelectorAll('mark.search-result').forEach(mark => {
                const text = document.createTextNode(mark.textContent);
                mark.parentNode.replaceChild(text, mark);
            });
            
            if (searchTerm.length > 0) {
                // Simple highlight implementation
                articles.forEach(article => {
                    const walker = document.createTreeWalker(
                        article,
                        NodeFilter.SHOW_TEXT,
                        null,
                        false
                    );
                    
                    const textNodes = [];
                    while (walker.nextNode()) {
                        textNodes.push(walker.currentNode);
                    }
                    
                    textNodes.forEach(node => {
                        const text = node.textContent;
                        const lowerText = text.toLowerCase();
                        const index = lowerText.indexOf(searchTerm);
                        
                        if (index !== -1) {
                            const mark = document.createElement('mark');
                            mark.className = 'search-result';
                            mark.textContent = text.substr(index, searchTerm.length);
                            
                            const range = document.createRange();
                            range.setStart(node, index);
                            range.setEnd(node, index + searchTerm.length);
                            range.surroundContents(mark);
                        }
                    });
                });
            }
        });
        
        // Trigger initial search
        searchInput.dispatchEvent(new Event('input'));
    </script>
</body>
</html>
```
**Why**: The `<mark>` element represents highlighted text for reference purposes due to its relevance in another context. Perfect for search results highlighting, emphasizing terms in quotations, or marking important passages. Unlike `<em>` or `<strong>`, it's context-dependent highlighting.

```html
            dialog.addEventListener('click', function(e) {
                const dialogDimensions = this.getBoundingClientRect();
                if (
                    e.clientX < dialogDimensions.left ||
                    e.clientX > dialogDimensions.right ||
                    e.clientY < dialogDimensions.top ||
                    e.clientY > dialogDimensions.bottom
                ) {
                    this.close();
                }
            });
        });
        
        // Handle dialog close events
        document.querySelectorAll('dialog').forEach(dialog => {
            dialog.addEventListener('close', function() {
                const returnValue = this.returnValue;
                const dialogId = this.id;

                // Handle confirmation dialog
                if (dialogId === 'confirmDialog' && returnValue === 'confirmed') {
                    alert('Item deleted successfully!');
                }
                
                // Handle form dialog
                if (dialogId === 'formDialog' && returnValue === 'submitted') {

                    alert('Form submitted successfully!');
                    form.reset();
                }
            });

        document.addEventListener('keydown', function(e) {

            }
        });
```

## Summary

These 10 HTML elements demonstrate modern semantic markup:

1. **`<aside>`** - Tangentially related content (sidebars)
2. **`<footer>`** - Document/section footer
3. **`<figure>`** - Self-contained content with optional caption
4. **`<figcaption>`** - Caption for figure content
5. **`<address>`** - Contact information
6. **`<time>`** - Machine-readable dates/times
7. **`<mark>`** - Highlighted text for reference
8. **`<details>`** - Expandable disclosure widget
9. **`<summary>`** - Summary/legend for details
10. **`<dialog>`** - Native modal/non-modal dialogs

All elements are accessible, semantic, and require minimal JavaScript for basic functionality.
