## [html_anchor_ping]

```html
<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>Anchor Ping Attribute</title>
</head>
<body>
    <!--
        PROBLEM: Track link clicks without JavaScript
        TIME: O(1) SPACE: O(1)
        
        The ping attribute specifies URLs to notify when the user follows
        the hyperlink. Browsers send POST requests to these URLs.
        Useful for analytics and click tracking without JS overhead.
    -->
    
    <h1>Anchor Ping Attribute Demo</h1>
    
    <!-- Basic ping example -->
    <a href="https://example.com" ping="https://analytics.example.com/click">
        Click to visit example.com (ping sent)
    </a>
    
    <!-- Multiple ping URLs (space-separated) -->
    <a href="https://example.org" 
       ping="https://analytics.example.com/click https://tracking.example.org/log">
        Multiple ping URLs
    </a>
    
    <!-- Practical use case: outbound link tracking -->
    <section>
        <h2>External Links</h2>
        <a href="https://developer.mozilla.org" 
           ping="/api/outbound-click"
           target="_blank"
           rel="noopener">
            MDN Web Docs
        </a>
    </section>
</body>
</html>
```

**Why**: The `ping` attribute provides a declarative, privacy-respecting way to track link clicks without JavaScript. Unlike onclick handlers, it's handled by the browser and doesn't block navigation.

```html
        h1, h2, h3 {

        .highlight, .important, .notice {

        /* Group pseudo-classes */
        a:hover, a:focus, button:hover, button:focus {
            outline: 2px solid #007bff;
            outline-offset: 2px;
        }
        
        /* Complex grouping with combinators */
        nav ul li a, .sidebar .menu-item, footer a {
            text-decoration: none;
```

## [css_font_size]

```html
<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>CSS font-size Property</title>
    <style>
        /*
            PROBLEM: Control text size with various units
            TIME: O(1) SPACE: O(1)
            
            font-size accepts: px, em, rem, %, vw, keywords
            Each has different inheritance and scaling behavior.
        */
        
        body {
            font-size: 16px; /* Base size for rem calculations */
        }
        
        /* Absolute keywords */
        .xx-small { font-size: xx-small; }
        .x-small { font-size: x-small; }
        .small { font-size: small; }
        .medium { font-size: medium; }
        .large { font-size: large; }
        .x-large { font-size: x-large; }
        .xx-large { font-size: xx-large; }
        
        /* Relative keywords */
        .smaller { font-size: smaller; }
        .larger { font-size: larger; }
        
        /* Pixel units (absolute) */
        .px-12 { font-size: 12px; }
        .px-16 { font-size: 16px; }
        .px-24 { font-size: 24px; }
        
        /* em units (relative to parent) */
        .em-demo {
            font-size: 20px; /* Parent size */
        }
        .em-demo .child {
            font-size: 1.5em; /* 20px * 1.5 = 30px */
        }
        .em-demo .grandchild {
            font-size: 0.8em; /* 30px * 0.8 = 24px */
        }
        
        /* rem units (relative to root/html) */
        .rem-1 { font-size: 1rem; }   /* 16px */
        .rem-1-5 { font-size: 1.5rem; } /* 24px */

        .percent-75 { font-size: 75%; }

        .percent-150 { font-size: 150%; }
        
        /* Viewport units */
        .vw-demo { font-size: 5vw; }
        .vh-demo { font-size: 3vh; }
        
        /* clamp() for responsive text */
        .clamp-demo {
            font-size: clamp(1rem, 2.5vw, 2rem);

        .typography-scale {
            --base: 1rem;

        .typography-scale h2 { font-size: calc(var(--base) * 2); }
        .typography-scale h3 { font-size: calc(var(--base) * 1.5); }
        .typography-scale p { font-size: var(--base); }
        .typography-scale small { font-size: calc(var(--base) * 0.875); }
    </style>
</head>
```

## [css_transform_translateX]

```html
<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>CSS transform: translateX()</title>
    <style>
        /*
            PROBLEM: Move elements horizontally without affecting layout
            TIME: O(1) SPACE: O(1)
            
            translateX() moves elements along the X-axis.
            Unlike margin/left, it doesn't affect document flow
            and triggers GPU acceleration for smooth animations.
        */
        
        .container {
            border: 2px dashed #ccc;
            padding: 20px;
            margin: 20px 0;
            position: relative;
            overflow: hidden;
        }
        
        .box {
            width: 100px;
            height: 100px;
            background: linear-gradient(135deg, #667eea 0%, #764ba2 100%);
            color: white;
            display: flex;
            align-items: center;
            justify-content: center;
            margin: 10px 0;
            transition: transform 0.3s ease;
        }
        
        /* Basic translations */
        .translate-50 { transform: translateX(50px); }
        .translate-100 { transform: translateX(100px); }
        .translate-neg { transform: translateX(-50px); }
        
        /* Percentage - relative to element width */
        .translate-percent { transform: translateX(50%); }
        .translate-100percent { transform: translateX(100%); }
        
        /* Animation example */
        @keyframes slide-in {
            from { transform: translateX(-100%); }
            to { transform: translateX(0); }
        }
        
        .slide-in {
            animation: slide-in 0.5s ease-out;
        }
        
        /* Hover effect */
        .hover-slide:hover {
            transform: translateX(20px);
        }
        
        /* Off-screen element (accessibility) */
        .off-screen {
            position: absolute;
            transform: translateX(-200%);
        }
        
        /* Center technique */
        .center-wrapper {
            position: relative;
            height: 150px;
            border: 1px solid #333;
        }
        
        .center-absolute {
            position: absolute;
            left: 50%;
            transform: translateX(-50%);
        }
        
        /* Practical: sliding drawer */
        .drawer {
            position: fixed;
            top: 0;
            right: 0;
            width: 300px;
            height: 100vh;
            background: #2c3e50;
            transform: translateX(100%);
            transition: transform 0.3s ease;
        }
        
        .drawer.open {
            transform: translateX(0);
        }
        
        /* Performance comparison */
        .gpu-accelerated {
            will-change: transform;
            transform: translateX(50px);
        }
    </style>
</head>
<body>
    <h1>CSS transform: translateX()</h1>
    
    <h2>Basic Translations</h2>
    <div class="container">
        <div class="box">Original</div>
        <div class="box translate-50">+50px</div>
        <div class="box translate-100">+100px</div>

    <h2>Centering with translateX</h2>
    <div class="container center-wrapper">
        <div class="box center-absolute">Centered!</div>

    <button onclick="toggleDrawer()">Toggle Drawer</button>
    
    <div class="drawer" id="drawer">
        <h2 style="color: white; padding: 20px;">Drawer Menu</h2>
    </div>
    
    <script>
        // Toggle drawer
        function toggleDrawer() {
            const drawer = document.getElementById('drawer');
            drawer.classList.toggle('open');
        }
        
        // Get computed transform
        const box = document.querySelector('.translate-50');
        const style = getComputedStyle(box);
        console.log('Transform:', style.transform);

    </script>
</body>

```

**Why**: `translateX()` is GPU-accelerated for smooth animations. Unlike `left` or `margin`, it doesn't trigger reflow. Combined with `left: 50%`, it's a common centering technique.

```html
        }
        
        /* Combined with width condition */
```

## [js_arrow_this_binding]

```html
<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>JavaScript Arrow Function this Binding</title>
</head>
<body>
    <h1>Arrow Function this Binding</h1>
    
    <div id="output" style="font-family: monospace; white-space: pre-wrap;"></div>
    
    <script>
        /*
            PROBLEM: Preserve outer this context in callbacks
            TIME: O(1) SPACE: O(1)
            
            Arrow functions don't have their own 'this'.
            They inherit 'this' from the enclosing scope (lexical binding).
            This solves the classic callback 'this' problem.
        */
        
        const output = document.getElementById('output');
        
        function log(...args) {
            const text = args.map(a => 
                typeof a === 'object' ? JSON.stringify(a) : a
            ).join(' ');
            output.textContent += text + '\n';
            console.log(...args);
        }
        
        log('=== Arrow Function this Binding Demo ===\n');
        
        // Problem: Regular function loses 'this' in callback
        const obj1 = {
            name: 'Object1',
            items: [1, 2, 3],
            regularForEach: function() {
                // 'this' is obj1 here
                log('\nRegular forEach (broken):');
                this.items.forEach(function(item) {
                    // 'this' is undefined (strict mode) or window
                    // log(this.name); // undefined!
                    log('  item:', item, '| this.name:', this?.name);
                });
            }
        };
        
        obj1.regularForEach();
        
        // Solution: Arrow function preserves 'this'
        const obj2 = {
            name: 'Object2',
            items: [1, 2, 3],
            arrowForEach: function() {
                log('\nArrow forEach (works):');
                this.items.forEach((item) => {
                    // 'this' is inherited from arrowForEach's 'this'
                    log('  item:', item, '| this.name:', this.name);
                });
            }
        };
        
        obj2.arrowForEach();
        
        // setTimeout example
        const timer = {
            seconds: 0,
            startRegular: function() {
                log('\nRegular setTimeout (broken):');
                setTimeout(function() {
                    // 'this' is window, not timer
                    log('  this.seconds:', this?.seconds);
                }, 100);
            },
            startArrow: function() {
                log('\nArrow setTimeout (works):');
                setTimeout(() => {
                    // 'this' is timer
                    log('  this.seconds:', this.seconds);
                }, 100);
            }
        };
        
        timer.startRegular();
        timer.startArrow();
        
        // Event listener example
        const button = {
            clicked: false,
            init: function() {
                log('\nEvent listener binding:');
                
                // Arrow preserves 'this'
                document.addEventListener('click', (e) => {
                    this.clicked = true;
                    log('  Document clicked! this.clicked:', this.clicked);
                });
            }
        };
        
        button.init();
        
        // Class method example
        class Counter {
            constructor() {
                this.count = 0;
            }
            
            // Arrow property (class field)
            increment = () => {
                this.count++;
                log('\nCounter.increment():', this.count);
            }
            
            // Regular method
            decrement() {
                this.count--;
                log('Counter.decrement():', this.count);
            }
            
            // Destructured method (loses this)
            demo() {
                log('\nMethod extraction demo:');
                
                const { increment, decrement } = this;
                
                increment(); // Works (arrow)
                // decrement(); // TypeError: this is undefined
                
                log('  Arrow method extracted: works!');
                log('  Regular method extracted: would fail');
            }
        }
        
        const counter = new Counter();
        counter.demo();
        
        // Comparison table
        log('\n=== Summary ===');
        log('Regular function: this = caller (dynamic)');
        log('Arrow function: this = outer scope (lexical)');
        log('Use arrow for: callbacks, event handlers, array methods');
        log('Avoid arrow for: object methods needing this, constructors');
    </script>
</body>
</html>
```

**Why**: Arrow functions solve the callback `this` problem without `.bind()` or `const self = this`. They inherit `this` lexically, making them ideal for callbacks, array methods, and event handlers.

## [js_promise_then]

```html
<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>JavaScript Promise.then()</title>
</head>
<body>
    <h1>Promise.then() Method</h1>
    
    <div id="output" style="font-family: monospace; white-space: pre-wrap;"></div>
    
    <script>
        /*
            PROBLEM: Handle async values with promise chain
            TIME: O(1) per then SPACE: O(1)
            
            .then() registers callbacks for promise resolution.
            Returns a new promise, enabling chaining.
            Takes two args: onFulfilled, onRejected
        */
        
        const output = document.getElementById('output');
        
        function log(...args) {
            const text = args.join(' ');
            output.textContent += text + '\n';
            console.log(...args);
        }
        
        log('=== Promise.then() Demo ===\n');
        
        // Basic then usage
        const promise1 = Promise.resolve(42);
        
        promise1.then(value => {
            log('Basic then:', value);
        });
        
        // Chaining - each then returns new promise
        Promise.resolve(1)
            .then(x => x + 1)        // 2
            .then(x => x * 2)        // 4
            .then(x => x + 3)        // 7
            .then(x => log('Chained:', x));
        
        // Value transformation
        const fetchUser = () => Promise.resolve({ id: 1, name: 'Alice' });
        
        fetchUser()
            .then(user => user.name)         // Extract name
            .then(name => name.toUpperCase()) // Transform
            .then(upper => log('Uppercase:', upper));
        
        // Error handling with second argument
        const promiseWithError = Promise.reject('Error occurred');
        
        promiseWithError.then(
            value => log('Success:', value),
            error => log('Error handler:', error)
        );
        
        // Propagating errors through chain
        Promise.resolve('start')
            .then(x => {
                throw new Error('Chain broken!');
            })
            .then(x => log('Skipped:', x)) // Skipped
            .catch(err => log('Caught:', err.message));
        
        // Returning promises from then
        const fetchPosts = (userId) => {
            log('Fetching posts for user:', userId);
            return Promise.resolve(['post1', 'post2', 'post3']);
        };
        
        Promise.resolve(1)
            .then(userId => fetchPosts(userId))
            .then(posts => log('Posts:', posts.join(', ')));
        
        // Parallel vs Sequential
        log('\n--- Sequential Execution ---');
        
        const delay = (ms, value) => new Promise(r => setTimeout(() => r(value), ms));
        
        delay(100, 'A')
            .then(v => { log('Step 1:', v); return delay(100, 'B'); })
            .then(v => { log('Step 2:', v); return delay(100, 'C'); })
            .then(v => { log('Step 3:', v); });
        
        // Practical example: API chain
        const mockAPI = {
            getUser: (id) => Promise.resolve({ id, name: 'User' + id }),
            getPermissions: (user) => Promise.resolve(['read', 'write']),
            getSettings: (perms) => Promise.resolve({ theme: 'dark' })
        };
        
        setTimeout(() => {
            log('\n--- API Chain Example ---');
            
            mockAPI.getUser(1)
                .then(user => {
                    log('User:', user);
                    return mockAPI.getPermissions(user);
                })
                .then(perms => {
                    log('Permissions:', perms);
                    return mockAPI.getSettings(perms);
                })
                .then(settings => {
                    log('Settings:', settings);
                });
        }, 500);
        
        // then vs finally
        log('\n--- then vs finally ---');
        
        Promise.resolve('data')
            .then(v => { log('then:', v); return 'transformed'; })
            .finally(() => log('finally: (no access to value)'))
            .then(v => log('after finally:', v));
        
        // Summary
        setTimeout(() => {
            log('\n=== Summary ===');
            log('then(onFulfilled, onRejected)');
            log('- Returns new Promise for chaining');
            log('- Transforms values through chain');
            log('- Catches thrown errors');
            log('- Unwraps returned promises');
        }, 1000);
    </script>
</body>
</html>
```

**Why**: `.then()` is the core of promise chaining. It transforms values, handles errors, and flattens nested promises. Understanding `.then()` is essential for async JavaScript and forms the foundation for `async/await`.
