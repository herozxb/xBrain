## css_grid_place_items

```html
<!-- PROBLEM: Center items both horizontally and vertically in grid -->
<!-- TIME: O(1) SPACE: O(1) -->
<!DOCTYPE html>
<html lang="en">
<head>
  <style>
    /* place-items is shorthand for align-items and justify-items */
    .grid-container {
      display: grid;
      grid-template-columns: repeat(3, 100px);
      grid-template-rows: repeat(2, 100px);
      gap: 10px;
      
      /* Center all items in their cells */
      place-items: center;
      
      /* Equivalent to:
         align-items: center;
         justify-items: center;
      */
      
      background: #f0f0f0;
      padding: 10px;
    }
    
    .grid-item {
      background: #3498db;
      color: white;
      padding: 10px;
    }
  </style>
</head>
<body>
  <div class="grid-container">
    <div class="grid-item">1</div>
    <div class="grid-item">2</div>
    <div class="grid-item">3</div>
    <div class="grid-item">4</div>
    <div class="grid-item">5</div>
    <div class="grid-item">6</div>
  </div>
</body>
</html>
```
**Why**: `place-items` provides a concise way to align grid items in both axes simultaneously, perfect for centering content in grid cells.

## css_grid_place_content

```html
<!-- PROBLEM: Align the entire grid within its container -->
<!-- TIME: O(1) SPACE: O(1) -->
<!DOCTYPE html>
<html lang="en">

    </div>
  </div>

</html>
```
**Why**: `place-content` controls how the grid tracks are distributed within the grid container, useful when the grid is smaller than its parent.

## css_grid_column_start

```html
<!-- PROBLEM: Control where a grid item starts horizontally -->
<!-- TIME: O(1) SPACE: O(1) -->
<!DOCTYPE html>
<html lang="en">
<head>
  <style>

      display: grid;

    .item {
      background: #9b59b6;
      color: white;
```

**Why**: `grid-column-start` allows precise control over item placement in the grid, enabling complex layouts without nested containers.

## css_selector_attribute_ends

```html
<!-- PROBLEM: Select elements whose attribute ends with a specific value -->
<!-- TIME: O(1) SPACE: O(1) -->
<!DOCTYPE html>
<html lang="en">
<head>
  <style>
    /* Select all links ending with .pdf */
    a[href$=".pdf"] {
      background: url('data:image/svg+xml,<svg xmlns="http://www.w3.org/2000/svg" viewBox="0 0 24 24" fill="%23e74c3c"><path d="M14 2H6a2 2 0 0 0-2 2v16a2 2 0 0 0 2 2h12a2 2 0 0 0 2-2V8l-6-6z"/></svg>') no-repeat left center;
      background-size: 16px;

      color: #e74c3c;
    }
    
    /* Select all inputs whose name ends with '_email' */
    input[name$="_email"] {
      border: 2px solid #3498db;
    }
    
    /* Select all classes ending with '-primary' */
    [class$="-primary"] {
      font-weight: bold;
      color: #2c3e50;
    }
  </style>
</head>
<body>
  <a href="document.pdf">Download PDF</a><br>
  <a href="report.pdf">Annual Report</a><br>
  <a href="page.html">HTML Page</a>

  </form>
  
  <p class="btn-primary">Primary Button Text</p>
  <p class="link-primary">Primary Link Text</p>
</body>
</html>
```
**Why**: Attribute ends-with selector `[attr$="value"]` enables targeted styling based on file extensions, naming conventions, or URL patterns.

## css_selector_adjacent_sibling

```html
<!-- TIME: O(1) SPACE: O(1) -->
<!DOCTYPE html>
<html lang="en">

      color: #2980b9;
      margin-top: 0;
    }
    
    /* Add icon before first list item after a heading */
    h3 + ul li:first-child::before {
      content: "→ ";
      color: #e74c3c;
    }
    
    /* Style input that follows a label */

      margin-left: 10px;
      border-color: #3498db;
    }
  </style>

  <h2>Section Title</h2>

    <li>Bread</li>

    <input type="email">
  </form>
</body>
</html>
```
**Why**: The adjacent sibling combinator (`+`) targets only the immediately following element, perfect for contextual styling without adding classes.

## css_pseudo_class_focus

```html
<!-- PROBLEM: Style elements when they receive keyboard focus -->
<!-- TIME: O(1) SPACE: O(1) -->
<!DOCTYPE html>
<html lang="en">
<head>
  <style>
    input[type="text"],
    input[type="email"],
    textarea {
      padding: 10px;
      border: 2px solid #ddd;
      border-radius: 4px;
      font-size: 16px;
      transition: border-color 0.2s, box-shadow 0.2s;
      outline: none;
    }
    
    /* Style when input has focus */
    input:focus,
    textarea:focus {
      border-color: #3498db;
      box-shadow: 0 0 0 3px rgba(52, 152, 219, 0.3);
    }
    
    /* Focus with visible outline for accessibility */
    button:focus {
      outline: 2px solid #3498db;
      outline-offset: 2px;
    }
    
    /* Focus-within for parent styling */
    .form-group {
      padding: 10px;
      border-radius: 4px;
      transition: background 0.2s;
    }
    
    .form-group:focus-within {
      background: #f0f8ff;
    }
  </style>
</head>
<body>
  <div class="form-group">
    <label>Username:</label><br>
    <input type="text" placeholder="Enter username">
  </div>
  
  <div class="form-group">
    <label>Email:</label><br>
    <input type="email" placeholder="Enter email">
  </div>
  
  <div class="form-group">
    <label>Message:</label><br>
    <textarea rows="3" placeholder="Type message"></textarea>
  </div>
  
  <button>Submit</button>
</body>
</html>
```
**Why**: `:focus` styling is essential for accessibility, indicating which element will receive keyboard input and improving form usability.

## css_margin_shorthand

```html
<!-- PROBLEM: Set all margins in one declaration -->
<!-- TIME: O(1) SPACE: O(1) -->
<!DOCTYPE html>
<html lang="en">
<head>
  <style>
    .box {
      background: #3498db;
      color: white;
      padding: 10px;
      display: inline-block;
    }
    
    .container {
      background: #f0f0f0;
      padding: 10px;
      margin: 10px;
    }
    
    /* margin: top right bottom left (clockwise) */
    .box-4-values {
      margin: 10px 20px 30px 40px;
    }
    
    /* margin: vertical horizontal */
    .box-2-values {
      margin: 20px 40px;
    }
    
    /* margin: all sides */
    .box-1-value {
      margin: 30px;
    }
    
    /* margin: top horizontal bottom */
    .box-3-values {
      margin: 10px 20px 30px;
    }
    
    /* Auto centering (block elements) */
    .box-center {
      display: block;
      width: 200px;
      margin: 0 auto;
    }
    
    /* Negative margin */
    .box-negative {
      margin-top: -15px;
      background: #e74c3c;
    }
  </style>
</head>
<body>
  <div class="container">
    <span class="box box-4-values">4 values: 10 20 30 40</span>
  </div>
  
  <div class="container">
    <span class="box box-2-values">2 values: 20 40</span>
  </div>
  
  <div class="container">
    <span class="box box-1-value">1 value: 30</span>
  </div>
  
  <div class="container">
    <span class="box box-3-values">3 values: 10 20 30</span>
  </div>
  
  <div class="container">
    <div class="box box-center">Centered Block</div>
  </div>
  
  <div class="container">
    <span class="box">Normal</span>
    <span class="box box-negative">Negative margin</span>
  </div>
</body>
</html>
```
**Why**: Margin shorthand reduces code verbosity and follows a logical clockwise pattern (top, right, bottom, left), while `auto` enables horizontal centering.
