# Python3 - Basic Syntax and Data Types

## Variables and Data Types
```python
# PROBLEM: Understanding Python variables and basic data types
# APPROACH: Demonstrate type declarations and conversions
# TIME: O(1) SPACE: O(1)

# Integer
age: int = 25
count: int = -10

# Float
price: float = 19.99
temperature: float = -3.14

# String
name: str = "Alice"
message: str = '''Multi-line
string example'''

# Boolean
is_active: bool = True
is_valid: bool = False

# Type checking
print(type(age))      # <class 'int'>
print(type(price))    # <class 'float'>
print(type(name))     # <class 'str'>
```

**Explanation**: Python supports int, float, str, bool with automatic type inference.
---

## Lists - Ordered Mutable Collections
```python
# PROBLEM: Working with lists in Python
# APPROACH: Demonstrate list operations
# TIME: O(n) for most operations SPACE: O(n)

# Create lists
numbers: list = [1, 2, 3, 4, 5]
mixed: list = [1, "hello", 3.14, True]

# Access elements
first = numbers[0]      # 1
last = numbers[-1]      # 5
slice_part = numbers[1:3]  # [2, 3]

# Modify lists
numbers.append(6)           # Add to end
numbers.insert(0, 0)        # Insert at index
numbers.extend([7, 8])      # Add multiple
removed = numbers.pop()     # Remove last
numbers.remove(3)           # Remove by value

# List operations
length = len(numbers)
contains = 5 in numbers
index = numbers.index(4)
count = numbers.count(2)
```

**Explanation**: Lists are ordered, mutable collections that can hold mixed types.
---

## Tuples - Immutable Sequences
```python
# PROBLEM: Working with tuples in Python
# APPROACH: Demonstrate tuple creation and unpacking
# TIME: O(1) for access SPACE: O(n)

# Create tuples
coordinates: tuple = (10, 20)
single_item: tuple = (42,)  # Comma required for single item
mixed: tuple = (1, "hello", 3.14)

# Tuple unpacking
x, y = coordinates
first, *rest = (1, 2, 3, 4)  # first=1, rest=[2,3,4]

# Named tuples
from collections import namedtuple
Point = namedtuple('Point', ['x', 'y'])
p = Point(10, 20)
print(p.x, p.y)  # 10 20

# Tuple methods
count = coordinates.count(10)
index = coordinates.index(20)
```

**Explanation**: Tuples are immutable, ordered sequences. Use for fixed collections.
---

## Dictionaries - Key-Value Pairs
```python
# PROBLEM: Working with dictionaries in Python
# APPROACH: Demonstrate dict operations and methods
# TIME: O(1) average for lookup/insert SPACE: O(n)

# Create dictionaries
person: dict = {
    "name": "Alice",
    "age": 30,
    "city": "NYC"
}

# Access values
name = person["name"]
age = person.get("age", 0)
country = person.get("country", "Unknown")

# Modify dictionaries
person["email"] = "alice@example.com"
person.update({"age": 31, "phone": "123-456"})
del person["city"]

# Dictionary operations
keys = person.keys()
values = person.values()
items = person.items()

# Dictionary comprehension
squares = {x: x**2 for x in range(5)}
# {0: 0, 1: 1, 2: 4, 3: 9, 4: 16}

# Iteration
for key, value in person.items():
    print(f"{key}: {value}")
```

**Explanation**: Dictionaries store key-value pairs with O(1) average access time.
---

## Sets - Unique Elements
```python
# PROBLEM: Working with sets in Python
# APPROACH: Demonstrate set operations and methods
# TIME: O(1) average for membership SPACE: O(n)

# Create sets
numbers: set = {1, 2, 3, 4, 5}
from_list = set([1, 2, 2, 3, 3])  # {1, 2, 3}

# Set operations
numbers.add(6)
numbers.remove(1)    # Raises KeyError if not found
numbers.discard(10)  # No error if not found
numbers.pop()        # Remove arbitrary element

# Set mathematics
a = {1, 2, 3}
b = {3, 4, 5}

union = a | b           # {1, 2, 3, 4, 5}
intersection = a & b    # {3}
difference = a - b      # {1, 2}
symmetric = a ^ b       # {1, 2, 4, 5}

# Set comprehension
evens = {x for x in range(10) if x % 2 == 0}
```

**Explanation**: Sets store unique elements and support mathematical set operations.
---

## Type Casting
```python
# PROBLEM: Converting between data types
# APPROACH: Use built-in conversion functions
# TIME: O(n) for sequences SPACE: O(n)

# String to number
num_str = "42"
num_int = int(num_str)      # 42
num_float = float(num_str)  # 42.0

# Number to string
age = 25
age_str = str(age)  # "25"

# List to tuple
my_list = [1, 2, 3]
my_tuple = tuple(my_list)  # (1, 2, 3)

# Tuple to list
my_list = list(my_tuple)   # [1, 2, 3]

# List to set (removes duplicates)
duplicates = [1, 2, 2, 3, 3, 3]
unique = set(duplicates)    # {1, 2, 3}

# String to list
text = "hello"
chars = list(text)  # ['h', 'e', 'l', 'l', 'o']

# Boolean conversion
bool(1)      # True
bool(0)      # False
bool("")     # False
bool("text") # True
```

**Explanation**: Python provides int(), float(), str(), list(), tuple(), set() for type conversion.
